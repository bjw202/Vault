# 모듈 7: 베벨/내접/랙 기어 (Bevel / Internal / Rack Gear)

> **선수 지식**: M03 (단일 치형 좌표 생성), M05 (스퍼 기어 3D 모델링)
> **학습 시간**: 약 2.0시간
> **난이도**: 중급-고급

이 모듈에서는 스퍼 기어 이외의 세 가지 주요 기어 유형을 다룹니다. 교차축 전동을 위한 **베벨 기어(bevel gear)**, 동축 역방향 전동을 위한 **내접 기어(internal gear)**, 회전-직선 변환을 위한 **랙 앤 피니언(rack and pinion)** 의 고유 수학과 3D 모델링 방법을 배웁니다.

## 7.1 직선 베벨 기어 기초

> **이 섹션에서 배우는 것**
> - 피치 원추(pitch cone)와 원추각의 정의
> - Tredgold 근사를 이용한 등가 스퍼 기어
> - 원추면 매핑의 원리

### 7.1.1 왜 베벨 기어가 필요한가

스퍼 기어와 헬리컬 기어는 **평행한 두 축** 사이에서 동력을 전달합니다. 하지만 실제 기계에서는 **교차하는 두 축** 사이에서 동력을 전달해야 하는 경우가 많습니다(예: 자동차 차동장치, 직각 감속기). 이때 사용하는 것이 **베벨 기어(bevel gear)** 입니다.

스퍼 기어가 원통(cylinder) 위에 치형을 만드는 것이라면, 베벨 기어는 **원뿔(cone)** 위에 치형을 만듭니다.

### 7.1.2 피치 원추(Pitch Cone) 기하학

베벨 기어의 참조면은 **피치 원추(pitch cone)** 입니다. 두 기어의 피치 원추가 맞닿는 면에서 동력이 전달됩니다.

| 원추 | 기호 | 설명 |
|------|------|------|
| 피치 원추 | $\delta$ | 맞물림 기준면, 피치 원추각 |
| 이끝 원추 | $\delta_a$ | 이끝이 놓이는 원추 |
| 이뿌리 원추 | $\delta_f$ | 이뿌리가 놓이는 원추 |
| 배면 원추(back cone) | — | 피치 원추에 수직. Tredgold 근사 기준 |

**피치 원추각** (직교 축, 축 교차각 $\Sigma = 90°$):

$$\tan\delta_1 = \frac{z_1}{z_2}, \qquad \tan\delta_2 = \frac{z_2}{z_1}$$

여기서:
- $\delta_1$: 피니언(작은 기어)의 피치 원추각
- $\delta_2$: 기어(큰 기어)의 피치 원추각
- $z_1, z_2$: 각 기어의 잇수

직교 축에서는 $\delta_1 + \delta_2 = 90°$입니다.

**원뿔 거리(cone distance)**:

$$R = \frac{m \cdot z_1}{2 \sin\delta_1} = \frac{d_1}{2 \sin\delta_1}$$

여기서:
- $R$: 원뿔 꼭짓점에서 외단까지의 거리 [mm]
- $d_1 = m z_1$: 피니언의 피치원 지름

**이끝/이뿌리 원추각**:

$$\delta_a = \delta + \theta_a, \qquad \theta_a = \arctan\left(\frac{h_a}{R}\right)$$

$$\delta_f = \delta - \theta_f, \qquad \theta_f = \arctan\left(\frac{h_f}{R}\right)$$

여기서 $h_a = m$ (어덴덤), $h_f = 1.25m$ (디덴덤)입니다.

### 7.1.3 Tredgold 근사

정확한 베벨 기어 치형은 **구면 인벌류트(spherical involute)** 곡선이지만, 계산이 매우 복잡합니다. 실용적인 대안이 **Tredgold 근사**입니다.

Tredgold 근사의 핵심 아이디어: **배면 원추(back cone) 위에 등가 스퍼 기어를 배치**하면 충분히 정확한 치형을 얻을 수 있습니다.

**등가 잇수(virtual number of teeth)**:

$$z_v = \frac{z}{\cos\delta}$$

여기서:
- $z_v$: 등가 잇수 (보통 소수점 값)
- $z$: 실제 잇수
- $\delta$: 피치 원추각

이 $z_v$로 인벌류트 스퍼 기어 치형을 생성한 후, 배면 원추 위에 배치합니다.

**배면 원추 반지름**:

$$r_{back} = R \cdot \sin\delta + h_a \cos\delta$$

**Tredgold 근사 구현 절차**:

1. 피치 원추각 $\delta$ 계산
2. 등가 잇수 $z_v = z / \cos\delta$ 계산
3. $z_v$에 대한 인벌류트 스퍼 기어 치형 생성 (M03의 방법)
4. 배면 원추 위에 치형 배치
5. 원뿔 꼭짓점 방향으로 치형을 선형 스케일링 (내측으로 갈수록 작아짐)
6. 이폭 방향으로 원추면을 따라 치형 생성

```python
"""
베벨 기어의 피치 원추와 Tredgold 등가를 보여줍니다.
"""
import numpy as np
import matplotlib.pyplot as plt

# --- 매개변수 ---
z1, z2 = 20, 30  # 잇수
m = 3             # 모듈 [mm]

# --- 기본 계산 ---
delta1 = np.arctan(z1 / z2)   # 피니언 원추각
delta2 = np.pi / 2 - delta1    # 기어 원추각
R = m * z1 / (2 * np.sin(delta1))  # 원뿔 거리
z_v1 = z1 / np.cos(delta1)    # 피니언 등가 잇수
z_v2 = z2 / np.cos(delta2)    # 기어 등가 잇수

print(f'베벨 기어 파라미터:')
print(f'  피니언 원추각 delta1 = {np.degrees(delta1):.2f} deg')
print(f'  기어 원추각   delta2 = {np.degrees(delta2):.2f} deg')
print(f'  원뿔 거리     R = {R:.2f} mm')
print(f'  피니언 등가 잇수 z_v1 = {z_v1:.2f}')
print(f'  기어 등가 잇수   z_v2 = {z_v2:.2f}')

# --- 시각화: 피치 원추 단면도 ---
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# 원추 단면 (측면도)
ax = axes[0]

# 피니언 원추 (위쪽)
x_cone1 = [0, R * np.sin(delta1), 0]
y_cone1 = [0, R * np.cos(delta1), 0]
ax.plot(x_cone1, y_cone1, 'b-', linewidth=2, label=f'피니언 ($\\delta_1$={np.degrees(delta1):.1f}$^\\circ$)')
ax.plot([-x for x in x_cone1], y_cone1, 'b-', linewidth=2)

# 기어 원추 (오른쪽)
x_cone2 = [0, R * np.cos(delta2), 0]
y_cone2 = [0, -R * np.sin(delta2), 0]
ax.plot(x_cone2[:2], y_cone2[:2], 'r-', linewidth=2, label=f'기어 ($\\delta_2$={np.degrees(delta2):.1f}$^\\circ$)')
ax.plot(x_cone2[:2], [-y for y in y_cone2[:2]], 'r-', linewidth=2)

# 원뿔 꼭짓점
ax.plot(0, 0, 'ko', markersize=8, label='원뿔 꼭짓점')

# 치수 표시
ax.annotate(f'R = {R:.1f} mm', xy=(R*np.sin(delta1)/2, R*np.cos(delta1)/2),
            fontsize=10, ha='left')

ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.set_title('베벨 기어 피치 원추 단면', fontsize=13)
ax.set_aspect('equal')
ax.legend(fontsize=10)
ax.grid(True, alpha=0.3)

# Tredgold 등가 잇수 그래프
ax = axes[1]
z_range = np.arange(10, 61)
gear_ratios = [1.0, 1.5, 2.0, 3.0]
for ratio in gear_ratios:
    delta = np.arctan(1 / ratio)
    z_v = z_range / np.cos(delta)
    ax.plot(z_range, z_v, linewidth=2, label=f'기어비 1:{ratio:.1f} ($\\delta$={np.degrees(delta):.1f}$^\\circ$)')

ax.plot(z_range, z_range, 'k--', alpha=0.3, label='스퍼 기어 ($z_v = z$)')
ax.axhline(y=17, color='r', linestyle=':', alpha=0.5, label='$z_v = 17$ (언더컷 한계)')

ax.set_xlabel('실제 잇수 $z$')
ax.set_ylabel('등가 잇수 $z_v$')
ax.set_title('Tredgold 등가 잇수: $z_v = z / \\cos\\delta$', fontsize=13)
ax.legend(fontsize=9)
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

> **결과 해석**: 왼쪽에 두 피치 원추의 단면을 보여줍니다. 원뿔 꼭짓점에서 두 원추가 만나며, 기어비에 따라 원추각이 달라집니다. 오른쪽에서 Tredgold 등가 잇수는 항상 실제 잇수보다 크며, 기어비가 클수록(원추각이 작을수록) 등가 잇수가 증가합니다. 빨간 점선(17개) 아래이면 언더컷 위험이 있습니다.

> **핵심 정리**
> - 피치 원추각: $\tan\delta_1 = z_1/z_2$, 직교 축에서 $\delta_1 + \delta_2 = 90°$
> - 원뿔 거리: $R = mz_1 / (2\sin\delta_1)$
> - Tredgold 등가 잇수: $z_v = z / \cos\delta$
> - 배면 원추 위의 등가 스퍼 기어로 치형을 근사합니다

## 7.2 베벨 기어 3D 좌표

> **이 섹션에서 배우는 것**
> - 원추면 위의 3D 좌표 변환 (수정된 정확 투영)
> - 이폭 방향 스케일링
> - 구면 인벌류트 접근법 개요

### 7.2.1 원추면 위의 좌표 변환

M05에서 스퍼 기어는 2D 프로파일을 단순 압출했습니다. 베벨 기어에서는 2D 치형을 **원추면 위에 투영**해야 합니다. 핵심은 치형 크기가 원뿔 꼭짓점 방향으로 **선형으로 축소**된다는 것입니다.

좌표계: 원뿔 꼭짓점 = 원점, 원뿔 축 = Z축

원추면 위의 점은 다음과 같이 표현됩니다.

$$\begin{pmatrix} x \\ y \\ z \end{pmatrix} = \rho \begin{pmatrix} \sin\delta \cdot \cos\theta \\ \sin\delta \cdot \sin\theta \\ \cos\delta \end{pmatrix}$$

여기서:
- $\rho$: 원뿔 꼭짓점에서의 거리 [mm]
- $\delta$: 원추 반각 (피치 원추각)
- $\theta$: 원주 방향 각도

### 7.2.2 수정된 3D 좌표 생성 함수

소스 문서의 원래 코드(R2 S4.4)에는 원통 오프셋을 사용하는 오류가 있었습니다[^1]. 아래는 **원추면 정확 투영**을 사용하는 수정된 코드입니다.

[^1]: [참고] R2 S4.4의 원래 코드는 `scaled_profile[:, 1] + r_pos`로 원통 오프셋을 적용했으나, R4 SF.2에서 원추면 투영으로 수정되었습니다.

```python
def straight_bevel_tooth_3d_corrected(
    profile_2d_outer,  # 외단(large end) 치형 프로파일 (N, 2)
    delta,              # 피치 원추각 [rad]
    R_cone,             # 외단 원뿔 거리 [mm]
    face_width,         # 이폭 [mm]
    n_slices=20,
):
    """직선 베벨 기어 치형 3D 좌표 (원추면 정확 투영)
    
    좌표계: 원뿔 꼭짓점 = 원점, 원뿔 축 = Z축
    profile_2d_outer[:, 0] = 반경 방향 편차 [mm]
    profile_2d_outer[:, 1] = 접선 방향 편차 [mm]
    """
    import numpy as np
    import math
    
    layers = []
    for i in range(n_slices):
        # 내단(i=0)에서 외단(i=n_slices-1)까지
        t_ratio = i / (n_slices - 1)
        rho = R_cone - face_width * (1 - t_ratio)  # 현재 원뿔 거리
        scale = rho / R_cone  # Tredgold 스케일링 비율

        # 치형 스케일링 (치형 크기는 원뿔 거리에 비례)
        scaled_profile = profile_2d_outer * scale

        # 피치원 반지름 (이 슬라이스에서)
        r_pitch = rho * math.sin(delta)
        z_center = rho * math.cos(delta)

        # 치형 점의 원추면 좌표 변환
        r_radial_offset = scaled_profile[:, 0]   # 반경 방향 편차
        r_tangential = scaled_profile[:, 1]       # 접선 방향 편차

        r_total = r_pitch + r_radial_offset       # 총 반경
        theta = np.where(r_pitch > 1e-10,
                         r_tangential / r_pitch,  # 호도 = 호길이/반경
                         0.0)

        # 원추면 위의 3D 좌표
        rho_i = np.sqrt(r_total**2 + z_center**2)
        phi_cone = np.arctan2(r_total, z_center)  # Z축에서의 각도

        x_3d = rho_i * np.sin(phi_cone) * np.cos(theta)
        y_3d = rho_i * np.sin(phi_cone) * np.sin(theta)
        z_3d = rho_i * np.cos(phi_cone)

        layers.append(np.column_stack([x_3d, y_3d, z_3d]))

    return np.array(layers)  # (n_slices, N, 3)
```

### 7.2.3 이폭 방향 스케일링

베벨 기어의 핵심 특성은 **치형 크기가 원뿔 꼭짓점 방향으로 선형 축소**된다는 것입니다.

$$\text{scale}(\rho) = \frac{\rho}{R_{cone}}$$

외단($\rho = R_{cone}$)에서 scale = 1.0, 내단($\rho = R_{cone} - b$)에서 scale = $(R_{cone} - b)/R_{cone}$입니다.

> **시각화**: 베벨 기어의 3D 형상을 렌더링합니다.

```python
"""
직선 베벨 기어의 3D 형상을 보여줍니다.
"""
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D
import math

# --- 매개변수 ---
z1, z2 = 20, 30
m = 3
alpha_0 = np.radians(20)

delta1 = np.arctan(z1 / z2)
R_cone = m * z1 / (2 * np.sin(delta1))
face_width = min(10 * m, R_cone / 3)  # 이폭 (R의 1/3 이하 권장)
z_v1 = z1 / np.cos(delta1)

# 등가 스퍼 기어 치형 (외단 기준)
r_0_eq = m * z_v1 / 2
r_b_eq = r_0_eq * np.cos(alpha_0)
r_a_eq = r_0_eq + m
r_f_eq = r_0_eq - 1.25 * m

# 간략화된 치형 프로파일 (반경/접선 편차로)
n_pts = 20
inv_a0 = np.tan(alpha_0) - alpha_0
theta_offset = np.pi / (2 * z_v1) + inv_a0

t_arr = np.linspace(0, np.sqrt((r_a_eq / r_b_eq)**2 - 1), n_pts)
x_inv = r_b_eq * (np.cos(t_arr) + t_arr * np.sin(t_arr))
y_inv = r_b_eq * (np.sin(t_arr) - t_arr * np.cos(t_arr))

# 회전
x_r = x_inv * np.cos(theta_offset) - y_inv * np.sin(theta_offset)
y_r = x_inv * np.sin(theta_offset) + y_inv * np.cos(theta_offset)

# 반경/접선 편차로 변환
r_points = np.sqrt(x_r**2 + y_r**2) - r_0_eq  # 반경 편차
theta_points = np.arctan2(y_r, x_r) * r_0_eq   # 접선 편차

# 좌우 합치기
r_all = np.concatenate([r_points[::-1], r_points])
t_all = np.concatenate([-theta_points[::-1], theta_points])
profile_outer = np.column_stack([r_all, t_all])

# 여러 이를 배치
profiles_all = []
for k in range(z1):
    angle_shift = k * 2 * np.pi * r_0_eq / z1  # 접선 방향 이동
    p = profile_outer.copy()
    p[:, 1] += angle_shift
    profiles_all.append(p)

# 3D 변환
fig = plt.figure(figsize=(10, 8))
ax = fig.add_subplot(111, projection='3d')

n_slices = 8
for prof_outer in profiles_all[:6]:  # 6개 이만 표시
    layers = []
    for i in range(n_slices):
        t_ratio = i / (n_slices - 1)
        rho = R_cone - face_width * (1 - t_ratio)
        scale = rho / R_cone
        
        scaled = prof_outer * scale
        r_pitch = rho * math.sin(delta1)
        z_center = rho * math.cos(delta1)
        
        r_total = r_pitch + scaled[:, 0]
        theta = np.where(r_pitch > 1e-10, scaled[:, 1] / r_pitch, 0.0)
        
        rho_i = np.sqrt(r_total**2 + z_center**2)
        phi_cone = np.arctan2(r_total, z_center)
        
        x_3d = rho_i * np.sin(phi_cone) * np.cos(theta)
        y_3d = rho_i * np.sin(phi_cone) * np.sin(theta)
        z_3d = rho_i * np.cos(phi_cone)
        
        layers.append(np.column_stack([x_3d, y_3d, z_3d]))
    
    # 각 레이어 윤곽
    for layer in layers:
        ax.plot(layer[:, 0], layer[:, 1], layer[:, 2], 'b-', linewidth=0.5, alpha=0.6)
    # 이폭 방향 연결
    for j in range(0, len(prof_outer), 5):
        xs = [l[j, 0] for l in layers]
        ys = [l[j, 1] for l in layers]
        zs = [l[j, 2] for l in layers]
        ax.plot(xs, ys, zs, 'b-', linewidth=0.3, alpha=0.4)

# 원뿔 축
ax.plot([0, 0], [0, 0], [0, R_cone * 1.1], 'k--', alpha=0.3, label='원뿔 축')
ax.plot([0], [0], [0], 'ko', markersize=5)  # 꼭짓점

ax.set_title(f'직선 베벨 기어 ($z_1$={z1}, $z_2$={z2}, $\\delta_1$={np.degrees(delta1):.1f}$^\\circ$)', 
             fontsize=14)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.set_zlabel('Z [mm]')
ax.view_init(elev=25, azim=-50)
ax.legend()

plt.tight_layout()
plt.show()
```

> **결과 해석**: 베벨 기어의 치형이 원뿔 꼭짓점(원점) 방향으로 갈수록 작아지는 것을 확인할 수 있습니다. 이것이 스퍼 기어와의 가장 큰 차이점입니다. 이폭 방향(내단 → 외단)을 따라 치형이 선형적으로 확대됩니다.

### 7.2.4 구면 인벌류트(Spherical Involute) 접근법

Tredgold 근사보다 정확한 치형을 구하려면 **구면 인벌류트(spherical involute)** 를 사용합니다. 기초 원추(base cone)의 접평면이 구름운동할 때 구면 위에 생기는 곡선입니다.

**기초 원추각**:

$$\cos\delta_b = \cos\delta \cdot \cos\alpha_n$$

구면 인벌류트 좌표 (구면 위, 반지름 $R$의 구):

$$\mathbf{r}(R, \beta) = R\begin{pmatrix} \sin\psi\cos\lambda \\ \sin\psi\sin\lambda \\ \cos\psi \end{pmatrix}$$

여기서 $\psi$, $\lambda$는 기초 원추의 구름운동에서 파생되며, Litvin(2004)의 벡터 형식으로 완전히 표현됩니다.

> Tredgold 근사는 이폭이 작을 때($b < 0.3R$) 충분히 정확합니다. 이폭이 크거나 큰 압력각에서는 구면 인벌류트가 필요하지만, 계산 비용이 높습니다.

> **핵심 정리**
> - 원추면 좌표: $\rho \sin\delta\cos\theta$, $\rho\sin\delta\sin\theta$, $\rho\cos\delta$
> - 치형 스케일링: scale = $\rho / R_{cone}$ (꼭짓점 방향 축소)
> - Tredgold 근사: $b < 0.3R$에서 충분히 정확
> - 구면 인벌류트: 정밀 해석 시 사용 (Litvin 2004)

## 7.3 스파이럴 베벨 기어

> **이 섹션에서 배우는 것**
> - 스파이럴 베벨의 복잡성과 프로젝트 범위

### 7.3.1 참고 사항

**스파이럴 베벨 기어(spiral bevel gear)** 는 치면이 원호 커터(face mill)의 운동으로 생성되는 비평면 곡면입니다. 직선 베벨이 이 방향이 원뿔 모선(generatrix)과 평행한 것과 달리, 스파이럴 베벨은 나선형입니다.

주요 특징:

- Gleason 독점 소프트웨어 없이는 근사에 그침

> 스파이럴 베벨 기어의 정밀 구현은 본 프로젝트의 범위를 벗어나며, 직선 베벨 기어까지만 다룹니다. 스파이럴 베벨이 필요한 경우 KISSsoft 등 전문 소프트웨어를 사용하세요.

## 7.4 내접(Internal) 기어

> **이 섹션에서 배우는 것**
> - 외접 기어와 내접 기어의 차이 (부호 반전)
> - 내접 기어의 중심 거리와 물림 압력각
> - 세 가지 간섭 조건

### 7.4.1 왜 내접 기어가 필요한가

내접 기어는 **이가 안쪽을 향하는 링 형태의 기어**입니다. 외접 기어(피니언)와 맞물려 동력을 전달합니다. 유성 기어 장치(planetary gear system), 소형 감속기 등에서 널리 사용됩니다.

내접 기어의 가장 큰 장점은 **컴팩트한 설계**입니다. 외접 기어 쌍은 두 기어가 나란히 배치되지만, 내접 기어는 피니언이 링 기어 안에 들어가므로 전체 크기가 줄어듭니다.

### 7.4.2 외접 기어와의 차이 (부호 반전)

내접 기어는 외접 기어와 여러 파라미터의 **부호가 반전**됩니다.

| 파라미터 | 외접 기어 | 내접 기어 |
|---------|---------|---------|
| 이끝원 반지름 | $r_a = r + m$ | $r_a = r - m$ (피치원보다 **작음**) |
| 이뿌리원 반지름 | $r_f = r - 1.25m$ | $r_f = r + 1.25m$ (피치원보다 **큼**) |
| 인벌류트 방향 | 바깥쪽 볼록 | 안쪽 오목 |
| 이끝원 위치 | 피치원 바깥 | 피치원 안쪽 |

직관적으로, 외접 기어의 어덴덤(이끝)과 디덴덤(이뿌리)의 역할이 **뒤바뀌는** 것입니다. 내접 기어에서 이끝은 안쪽으로 향하고, 이뿌리는 바깥쪽으로 향합니다.

이를 수식으로 표현하면:

$$d_a = m(z - 2) \qquad \text{(이끝원 — 내접, 표준)}$$
$$d_f = m(z + 2.5) \qquad \text{(이뿌리원 — 내접, 표준)}$$

### 7.4.3 중심 거리

**외접 기어 쌍**: $a = \frac{m(z_1 + z_2)}{2}$

**내접 기어 쌍**: $a = \frac{m(z_2 - z_1)}{2}$

여기서 $z_2$는 내접(링) 기어의 잇수, $z_1$은 피니언의 잇수입니다. 부호가 **+에서 -**로 바뀐 것에 주목하세요.

### 7.4.4 물림 압력각

내접 기어 쌍의 물림 압력각:

$$\text{inv}(\alpha_w) = \text{inv}(\alpha_0) + \frac{2(x_1 - x_2)}{z_2 - z_1}\tan\alpha_0$$

여기서:
- $\alpha_w$: 물림 압력각
- $\alpha_0$: 기준 압력각
- $x_1, x_2$: 각 기어의 전위 계수
- $z_1, z_2$: 각 기어의 잇수

외접 기어 쌍에서는 $(x_1 + x_2)/(z_1 + z_2)$였던 것이 $(x_1 - x_2)/(z_2 - z_1)$으로 바뀝니다.

### 7.4.5 세 가지 간섭 조건

내접 기어는 외접 기어보다 간섭 문제가 복잡합니다. 세 가지 간섭을 모두 확인해야 합니다.

**1. 인벌류트 간섭**: 내접 기어의 이끝이 기초원 안쪽으로 들어가면 인벌류트가 정의되지 않습니다.
- 조건: $z_2 > 34$ (표준 20° 압력각, 전위 없음)

**2. 트로코이드 간섭**: 피니언의 이끝이 내접 기어의 이뿌리(트로코이드 곡선)에 간섭합니다.
- 잇수 차이가 작을수록 위험: $z_2 - z_1 > 3 \sim 5$ (경험치)

**3. 조립 간섭**: 기어를 조립할 때 이가 통과할 수 있어야 합니다. 잇수 차이가 너무 작으면 물리적으로 조립이 불가능합니다.

> 이 수치들은 표준 20° 압력각, 전위계수 0의 조건입니다. 압력각이 크거나 전위를 적용하면 한계가 변합니다.

### 7.4.6 간섭 검사 코드

```python
import numpy as np

def check_internal_gear_interference(z1, z2, alpha0=np.radians(20), x1=0, x2=0):
    """내접 기어 간섭 체크
    z1: 피니언 잇수
    z2: 링 기어 잇수 (z2 > z1)
    반환: 간섭 유형별 결과 딕셔너리
    """
    results = {}
    
    # 기본 조건: z2 > z1
    if z2 <= z1:
        results['basic'] = '오류: 링 기어 잇수(z2)가 피니언(z1)보다 커야 합니다'
        return results
    
    # 1. 인벌류트 간섭: 링 기어 이끝이 기초원 안쪽이면 간섭
    r_02 = z2 / 2  # 정규화 (m=1)
    r_b2 = r_02 * np.cos(alpha0)
    r_a2 = r_02 - 1 + x2  # 내접 이끝원 (정규화)
    
    if r_a2 < r_b2:
        results['involute'] = f'인벌류트 간섭: r_a2={r_a2:.2f} < r_b2={r_b2:.2f}'
    else:
        results['involute'] = '통과'
    
    # 2. 트로코이드 간섭: 잇수 차이 확인
    diff = z2 - z1
    if diff < 5:
        results['trochoid'] = f'트로코이드 간섭 위험: z2-z1={diff} < 5'
    elif diff < 10:
        results['trochoid'] = f'주의: z2-z1={diff}. 10 이상 권장'
    else:
        results['trochoid'] = '통과'
    
    # 3. 조립 간섭
    if diff < 3:
        results['assembly'] = f'조립 불가: z2-z1={diff} < 3'
    else:
        results['assembly'] = '통과'
    
    return results
```

> **핵심 정리**
> - 내접 기어는 어덴덤/디덴덤이 **반전**: $d_a = m(z-2)$, $d_f = m(z+2.5)$
> - 중심 거리: $a = m(z_2 - z_1)/2$ (외접과 부호 차이)
> - 세 가지 간섭 확인 필수: 인벌류트, 트로코이드, 조립

## 7.5 랙 앤 피니언 (Rack and Pinion)

> **이 섹션에서 배우는 것**
> - 랙의 치형이 직선인 이유 (무한 잇수의 극한)
> - 랙 치형 좌표 생성
> - 피니언과의 물림 관계

### 7.5.1 랙의 치형은 왜 직선인가

**랙(rack)** 은 잇수가 **무한대**인 기어의 극한입니다. 잇수가 무한대이면 피치원 반지름도 무한대가 되므로, 인벌류트 곡선이 **직선**으로 수렴합니다.

$$\lim_{z \to \infty} \text{인벌류트 곡선} = \text{직선 (압력각 } \alpha_0 \text{의 경사)}$$

따라서 랙의 치형은 압력각 $\alpha_0$만큼 기울어진 직선입니다.

### 7.5.2 랙 치형 좌표

랙 좌표계: 피치선을 X축, 높이를 Y축으로 설정합니다.

하나의 이에 대해 (모듈 $m$, 압력각 $\alpha_0$, 원호 피치 $p = \pi m$):

| 구간 | 방정식 |
|------|--------|
| 우측 플랭크 | $x(h) = \dfrac{p}{4} + h\tan\alpha_0$, $\; y(h) = h$ |
| 좌측 플랭크 | $x(h) = -\dfrac{p}{4} - h\tan\alpha_0$, $\; y(h) = h$ |
| 이끝 | $y = h_a = m$, $\; x \in [-x_{tip}, +x_{tip}]$ |
| 이뿌리 | $y = -h_f = -1.25m$, $\; x \in [-p/2, +p/2]$ |

여기서 $h \in [-1.25m, +m]$ ($h = 0$이 피치선 위치).

### 7.5.3 피니언과의 물림 관계

피니언이 각도 $\theta$만큼 회전하면, 랙은 선형 이동합니다.

$$\Delta x_{rack} = r_{pinion} \cdot \theta = \frac{m \cdot z_{pinion}}{2} \cdot \theta$$

**물림선(line of action)**: 피치점을 지나고 압력각 $\alpha_0$만큼 기울어진 직선입니다.

> **시각화**: 랙과 피니언의 물림 도해를 보여줍니다.

```python
"""
랙과 피니언의 물림 관계를 보여줍니다.
"""
import numpy as np
import matplotlib.pyplot as plt

# --- 매개변수 ---
m = 3
z_pinion = 20
alpha_0 = np.radians(20)

r_0 = m * z_pinion / 2
r_a = r_0 + m
r_f = r_0 - 1.25 * m

# --- 랙 치형 생성 ---
def rack_tooth_profile(m, alpha=np.radians(20), n_points=20):
    """랙 치형 2D 프로파일 생성 (한 이)"""
    p = np.pi * m     # 원호 피치
    h_a = m            # 이끝 높이
    h_f = 1.25 * m     # 이뿌리 깊이
    r_fillet = 0.38 * m  # 필렛 반지름

    h = np.linspace(-h_f, h_a, n_points)

    # 우측 플랭크
    x_right = p / 4 + h * np.tan(alpha)
    y_right = h

    # 좌측 플랭크 (대칭)
    x_left = -p / 4 - h * np.tan(alpha)
    y_left = h

    # 이끝 (수평선)
    x_top = np.linspace(x_left[-1], x_right[-1], 5)
    y_top = np.full(5, h_a)

    # 치형 조립 (CCW 방향)
    profile = np.vstack([
        np.column_stack([x_left[::-1], y_left[::-1]]),
        np.column_stack([x_top, y_top]),
        np.column_stack([x_right, y_right])
    ])
    return profile

# --- 피니언 치형 (간략화) ---
def generate_pinion_profile(r_b, r_a, r_f, z_teeth, alpha_0, n_pts=30):
    inv_a0 = np.tan(alpha_0) - alpha_0
    theta_offset = np.pi / (2 * z_teeth) + inv_a0
    
    t = np.linspace(0, np.sqrt((r_a / r_b)**2 - 1), n_pts)
    x_inv = r_b * (np.cos(t) + t * np.sin(t))
    y_inv = r_b * (np.sin(t) - t * np.cos(t))
    
    x_r = x_inv * np.cos(theta_offset) - y_inv * np.sin(theta_offset)
    y_r = x_inv * np.sin(theta_offset) + y_inv * np.cos(theta_offset)
    
    all_x, all_y = [], []
    for k in range(z_teeth):
        angle = k * 2 * np.pi / z_teeth
        c, s = np.cos(angle), np.sin(angle)
        xr = x_r * c - y_r * s
        yr = x_r * s + y_r * c
        xl = xr[::-1]
        yl = -yr[::-1]  # 미러링 후 역회전
        # 다시 회전
        xl2 = xl * c - yl * s
        yl2 = xl * s + yl * c
        all_x.extend(xr)
        all_y.extend(yr)
    return np.array(all_x), np.array(all_y)

r_b = r_0 * np.cos(alpha_0)
px, py = generate_pinion_profile(r_b, r_a, r_f, z_pinion, alpha_0)

# --- 시각화 ---
fig, ax = plt.subplots(figsize=(14, 8))

# 피니언 (피치선에서 r_0 만큼 위에 중심)
pinion_cy = r_0
ax.plot(px, py + pinion_cy, 'b-', linewidth=0.5)

# 피치원
theta = np.linspace(0, 2*np.pi, 200)
ax.plot(r_0*np.cos(theta), r_0*np.sin(theta) + pinion_cy, 'b--', alpha=0.3, 
        label=f'피니언 피치원 ($r_0$={r_0:.0f}mm)')

# 랙 (피치선 = y=0)
n_teeth_rack = 7
p = np.pi * m
single_tooth = rack_tooth_profile(m, alpha_0)

for k in range(-n_teeth_rack//2, n_teeth_rack//2 + 1):
    shifted = single_tooth.copy()
    shifted[:, 0] += k * p
    ax.plot(shifted[:, 0], shifted[:, 1], 'r-', linewidth=1.5)

# 피치선
rack_extent = (n_teeth_rack//2 + 1) * p
ax.axhline(y=0, color='g', linestyle='--', alpha=0.5, label='피치선')

# 이끝선, 이뿌리선
ax.axhline(y=m, color='r', linestyle=':', alpha=0.3, label=f'랙 이끝선 (y={m})')
ax.axhline(y=-1.25*m, color='r', linestyle=':', alpha=0.3, label=f'랙 이뿌리선 (y={-1.25*m})')

# 물림선 (압력각 방향)
loa_length = 25
loa_x = np.linspace(-loa_length, loa_length, 50)
loa_y = loa_x * np.tan(np.pi/2 - alpha_0)  # 압력각 방향
ax.plot(loa_x, loa_y, 'm-', linewidth=1.5, alpha=0.5, label=f'물림선 ($\\alpha_0$={np.degrees(alpha_0):.0f}$^\\circ$)')

# 피치점
ax.plot(0, 0, 'ko', markersize=8, label='피치점')

# 운동 표시
ax.annotate('피니언 회전', xy=(15, pinion_cy + 5), fontsize=11, color='blue',
            arrowprops=dict(arrowstyle='->', color='blue'),
            xytext=(25, pinion_cy + 15))
ax.annotate('랙 직선 이동', xy=(rack_extent*0.3, -6), fontsize=11, color='red')
ax.annotate('', xy=(rack_extent*0.5, -5), xytext=(rack_extent*0.1, -5),
            arrowprops=dict(arrowstyle='->', color='red', lw=2))

ax.set_xlabel('X [mm]', fontsize=12)
ax.set_ylabel('Y [mm]', fontsize=12)
ax.set_title(f'랙-피니언 물림 도해 (m={m}mm, $z_{{pinion}}$={z_pinion})', fontsize=14)
ax.set_aspect('equal')
ax.legend(fontsize=9, loc='upper left')
ax.grid(True, alpha=0.3)
ax.set_xlim(-rack_extent*0.6, rack_extent*0.6)
ax.set_ylim(-15, pinion_cy + r_a + 5)

plt.tight_layout()
plt.show()
```

> **결과 해석**: 위쪽의 파란색 원형이 피니언, 아래쪽의 빨간색 직선 형태가 랙입니다. 랙의 치형이 직선인 것을 확인할 수 있습니다. 녹색 점선이 피치선이며, 피니언의 피치원이 랙의 피치선 위를 구릅니다. 피니언이 회전하면 랙이 직선으로 이동합니다. 보라색 선은 물림선(line of action)으로, 접촉점이 항상 이 선 위를 따라 이동합니다.

> **핵심 정리**
> - 랙 = 잇수 무한대인 기어의 극한 → 치형이 **직선**
> - 랙 치형: 압력각 $\alpha_0$의 경사면 + 이끝/이뿌리 수평면
> - 피니언 회전 $\theta$ → 랙 이동 $\Delta x = r_0 \theta$
> - 물림선: 피치점을 지나며 $\alpha_0$ 기울기

## 7.6 3D 모델링 통합

> **이 섹션에서 배우는 것**
> - 각 기어 유형별 3D 변환 방법 요약
> - M05에서 배운 기법의 적용

### 7.6.1 유형별 3D 변환 요약

| 기어 유형 | 3D 변환 방법 | 핵심 특징 |
|---------|-------------|---------|
| **베벨 기어** | 원추면 스위프(cone surface sweep) | 치형 크기가 꼭짓점 방향 축소 |
| **내접 기어** | 내부 보어 + 외부 링 압출 | 링 형태 원통에서 내부 치형 CSG 차집합 |
| **랙** | 직선 압출 (유한 길이) | 치형 방향 = 피치선, 압출 방향 = 이폭 |

### 7.6.2 베벨 기어 3D

M05의 로프트(Loft) 기법 적용: 외단(큰 단면)과 내단(작은 단면)을 원뿔면을 따라 보간합니다. 스케일링 비율 = $\rho / R_{cone}$으로 내측으로 갈수록 치형이 작아집니다.

### 7.6.3 내접 기어 3D

**링(ring) 형태의 원통**에서 내부 치형을 CSG 차집합으로 제거합니다.

```
링 원통 = 외경 원통(이뿌리원 기준) - 내경 원통(이끝원 기준)
각 치 공간 = 인벌류트 프로파일 단면의 압출
내접 기어 = 링 원통 - sum(각 치 공간)
```

### 7.6.4 랙 3D

랙은 치형 프로파일을 **이동 방향(X축)으로 반복**하고 **이폭 방향(Z축)으로 압출**합니다. 유한한 길이로 잘라냅니다.

$$P_{3D}(x, y, z) = (x_{rack}, y_{profile}, z_{face\_width})$$

여기서 $x_{rack}$은 원호 피치 $p = \pi m$ 간격으로 반복됩니다.

> **핵심 정리**
> - **베벨**: 원추면 위 로프트 (치형 크기 선형 축소)
> - **내접**: 링 원통에서 내부 CSG 차집합
> - **랙**: 직선 프로파일의 반복 + Z방향 압출

## 핵심 수식 정리

| 수식 | 설명 | 적용 |
|------|------|------|
| $\tan\delta_1 = z_1/z_2$ | 피치 원추각 | 베벨 기어 |
| $R = mz_1/(2\sin\delta_1)$ | 원뿔 거리 | 베벨 기어 |
| $z_v = z/\cos\delta$ | Tredgold 등가 잇수 | 베벨 기어 치형 |
| $\cos\delta_b = \cos\delta\cos\alpha_n$ | 기초 원추각 | 구면 인벌류트 |
| $d_a = m(z - 2)$ | 내접 이끝원 | 내접 기어 |
| $d_f = m(z + 2.5)$ | 내접 이뿌리원 | 내접 기어 |
| $a = m(z_2 - z_1)/2$ | 내접 중심 거리 | 내접 기어 |
| $x(h) = p/4 + h\tan\alpha_0$ | 랙 플랭크 | 랙 기어 |
| $\Delta x = r_0\theta$ | 랙 이동량 | 랙-피니언 |
| scale $= \rho / R_{cone}$ | 이폭 방향 스케일링 | 베벨 3D |
