# AI Agency란 무엇인가?

## 한 줄 요약

**AI Agency는 "웹사이트 만들어줘"라고 말하면, 6명의 AI 전문가가 기획부터 코딩, 품질 검증까지 자동으로 처리하는 시스템이다.**

---

## 쉬운 비유: 실제 웹 에이전시와 비교

실제 웹 에이전시에서 프로젝트가 진행되는 과정을 생각해보자:

```
클라이언트: "우리 회사 랜딩페이지 만들어주세요"

    1. 기획자가 클라이언트를 인터뷰하고 기획서를 쓴다
    2. 카피라이터가 웹사이트에 들어갈 문구를 작성한다
    3. 디자이너가 레이아웃과 색상 체계를 설계한다
    4. 개발자가 코드로 구현한다
    5. QA가 테스트하고 피드백을 준다
    6. 피드백을 반영해서 수정하고, 다시 QA를 반복한다
```

**AI Agency는 이 과정을 그대로 AI 에이전트로 자동화한 것이다.**

| 실제 에이전시 | AI Agency | 역할 |
| --- | --- | --- |
| 기획자/PM | **Planner** | 클라이언트 인터뷰 → 기획서(BRIEF) 작성 |
| 카피라이터 | **Copywriter** | 헤드라인, 본문, CTA 등 모든 텍스트 작성 |
| UI/UX 디자이너 | **Designer** | 색상, 타이포, 레이아웃, 컴포넌트 스펙 설계 |
| 프론트엔드 개발자 | **Builder** | Next.js + Tailwind로 실제 코드 구현 |
| QA 엔지니어 | **Evaluator** | Playwright로 테스트하고 4차원 품질 점수 매김 |
| 팀 리드/매니저 | **Learner** | 피드백을 축적하고 팀 역량을 점진적으로 개선 |

## MoAI와의 관계

```
┌─────────────────────────────────────────────────────┐
│  MoAI-ADK (범용 개발 오케스트레이터)                     │
│  - 24개 에이전트, 52개 스킬                              │
│  - TDD/DDD 개발 방법론                                  │
│  - SPEC 기반 워크플로우                                  │
│  - TRUST 5 품질 프레임워크                               │
│                                                         │
│  ┌──────────────────────────────────────────────┐       │
│  │  AI Agency (웹 제작 특화 하네스)                │       │
│  │  - 6개 전용 에이전트                           │       │
│  │  - GAN Loop (Builder ↔ Evaluator)            │       │
│  │  - 자기진화 시스템 (Learner)                   │       │
│  │  - 브랜드 컨텍스트 관리                        │       │
│  └──────────────────────────────────────────────┘       │
└─────────────────────────────────────────────────────────┘
```

- **MoAI**는 범용 소프트웨어 개발 프레임워크 (백엔드, 프론트엔드, 데이터베이스, 보안 등 모든 개발)
- **Agency**는 MoAI 위에 얹은 **웹/앱 제작 전문 레이어** (랜딩페이지, SaaS 웹사이트, 웹앱 등)
- Agency는 MoAI의 에이전트와 스킬을 **포크(fork)** 해서 웹 제작에 맞게 커스터마이징한 것

## 핵심 차별점: 왜 "그냥 Claude한테 시키면 되지?"가 아닌가

### 1. 역할 분리 = 품질 향상

Claude에게 "웹사이트 만들어줘"라고 하면, 하나의 대화에서 기획 + 카피 + 디자인 + 코딩을 전부 한다. 문제는 **한 번에 모든 걸 잘하기 어렵다**는 것이다.

Agency에서는 각 에이전트가 **자기 전문 분야에만 집중**한다:

- Copywriter는 카피만 쓴다 (디자인은 신경 안 쓴다)
- Designer는 디자인 시스템만 설계한다 (코드는 안 쓴다)
- Builder는 카피와 디자인 스펙을 **그대로** 코드로 옮긴다

### 2. 품질 검증 루프 (GAN Loop)

Builder가 만들면, Evaluator가 **회의적으로** 평가한다:

- "아마 괜찮을 거야"는 허용 안 됨
- 의심스러우면 FAIL
- 최대 5번 반복하면서 품질 0.75 이상 될 때까지 개선

### 3. 브랜드 일관성

`.agency/context/` 폴더에 브랜드 보이스, 비주얼 아이덴티티, 타겟 오디언스를 정의해두면, 모든 에이전트가 이 컨텍스트를 참조하여 **일관된** 결과물을 만든다.

### 4. 자기진화

Learner가 프로젝트마다 패턴을 학습하고, 에이전트의 동작을 점진적으로 개선한다. 5번 이상 같은 패턴이 관찰되면 규칙으로 승격된다.

## 어떤 프로젝트에 쓰면 되는가?

### 적합한 프로젝트

| 유형 | 예시 |
| --- | --- |
| **랜딩페이지** | SaaS 제품 소개 페이지, 이벤트 프로모션 페이지 |
| **기업 웹사이트** | 회사 소개, 서비스 안내, 포트폴리오 사이트 |
| **웹 애플리케이션** | 대시보드, 관리자 패널, 사용자 포탈 |
| **컴포넌트 라이브러리** | 디자인 시스템, UI 킷 |
| **리디자인** | 기존 사이트의 UI/UX 개편 |

### 적합하지 않은 프로젝트

| 유형 | 대신 사용할 도구 |
| --- | --- |
| 백엔드 API 개발 | MoAI `/moai run` (expert-backend) |
| 모바일 앱 | MoAI + Flutter/React Native 에이전트 |
| 데이터 파이프라인 | MoAI `/moai run` (expert-backend) |
| ML/AI 모델 개발 | 별도 워크플로우 |
| 이미 코드가 있는 버그 수정 | MoAI `/moai fix` |

## 요약

AI Agency는 **"웹 에이전시의 작업 방식을 AI로 자동화한 시스템"** 이다.

- 6명의 전문 에이전트가 역할을 분담한다
- GAN Loop로 품질을 반복 검증한다
- 브랜드 컨텍스트로 일관성을 유지한다
- Learner로 프로젝트마다 점점 더 좋아진다
- MoAI-ADK 위에서 동작하는 웹 제작 특화 하네스이다
