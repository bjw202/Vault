## 5.1 스퍼 기어 3D 확장: 압출 (Extrusion)

> **이 섹션에서 배우는 것**
> - 2D 프로파일을 Z축 방향으로 압출하여 3D 형상을 만드는 원리
> - 이폭(face width)의 개념과 3D 좌표 변환
> - 축 구멍(bore) 처리 방법

### 5.1.1 왜 3D 확장이 필요한가

M03에서 생성한 기어 프로파일은 2D 평면 위의 좌표입니다. 실제 기어는 일정한 두께(이폭, face width)를 가진 3차원 물체입니다. 스퍼 기어는 치형이 축 방향으로 일정하므로, 2D 프로파일을 Z축 방향으로 단순히 "밀어내는" **압출(extrusion)** 방식으로 3D 형상을 만들 수 있습니다.

### 5.1.2 압출의 수학

2D 프로파일의 점 $(x_{profile}, y_{profile})$를 Z축 방향으로 밀어내면 3D 좌표가 됩니다.

$$P_{3D}(x, y, z) = (x_{profile}, y_{profile}, z), \quad z \in [0, b]$$

여기서:
- $b$: **이폭(face width)** — 기어의 축 방향 두께 [mm]
- $z$: 축 방향 위치 (0에서 $b$까지)

스퍼 기어의 경우 모든 Z 위치에서 단면이 동일하므로, 최소 2개의 레이어(앞면과 뒷면)만 있으면 3D 형상을 정의할 수 있습니다. 하지만 메시 품질을 위해 중간 레이어를 추가할 수 있습니다.

### 5.1.3 3D 좌표 생성 코드

> **시각화**: 2D 프로파일을 Z축 방향으로 압출하여 3D 와이어프레임 기어를 생성합니다.

```python
"""
스퍼 기어 2D 프로파일을 3D로 압출하는 과정을 보여줍니다.
"""
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

# --- 매개변수 설정 ---
m = 3            # 모듈 [mm]
z_teeth = 20     # 잇수
alpha_0 = np.radians(20)  # 압력각 [rad]
x = 0            # 전위 계수 (표준 기어)
face_width = 15  # 이폭 [mm]

# --- 기어 기본 원 계산 ---
r_0 = m * z_teeth / 2              # 피치원 반지름
r_b = r_0 * np.cos(alpha_0)        # 기초원 반지름
r_a = r_0 + m * (1 + x)            # 이끝원 반지름
r_f = r_0 - m * (1.25 - x)         # 이뿌리원 반지름

# --- 인벌류트 치형 생성 (단순화된 한 개 이) ---
def involute_function(alpha):
    """inv(alpha) = tan(alpha) - alpha"""
    return np.tan(alpha) - alpha

def generate_tooth_profile(r_b, r_a, r_f, r_0, z_teeth, alpha_0, x=0, n_pts=40):
    """단일 이 프로파일 생성 (오른쪽 + 왼쪽 플랭크)
    x: 전위 계수 (profile shift coefficient), 기본값 0 (표준 기어)
    """
    # 파라미터 범위
    t_start = np.sqrt(max(0, (max(r_f, r_b) / r_b)**2 - 1))
    t_tip = np.sqrt((r_a / r_b)**2 - 1)
    
    # 이두께 반각 (전위 항 포함)
    inv_a0 = involute_function(alpha_0)
    theta_offset = np.pi / (2 * z_teeth) + inv_a0 + 2 * x * np.tan(alpha_0) / z_teeth
    
    # 오른쪽 플랭크
    t = np.linspace(t_start, t_tip, n_pts)
    x_inv = r_b * (np.cos(t) + t * np.sin(t))
    y_inv = r_b * (np.sin(t) - t * np.cos(t))
    
    # 회전 적용
    x_r = x_inv * np.cos(theta_offset) - y_inv * np.sin(theta_offset)
    y_r = x_inv * np.sin(theta_offset) + y_inv * np.cos(theta_offset)
    
    # 왼쪽 플랭크 (Y축 반전 후 역순)
    x_l = x_r[::-1]
    y_l = -y_r[::-1]
    
    # 이끝 원호 (두 플랭크 상단 연결)
    theta_tip_r = np.arctan2(y_r[-1], x_r[-1])
    theta_tip_l = np.arctan2(y_l[0], x_l[0])
    theta_tip = np.linspace(theta_tip_l, theta_tip_r, 5)
    x_tip = r_a * np.cos(theta_tip)
    y_tip = r_a * np.sin(theta_tip)
    
    # 조립
    x_tooth = np.concatenate([x_l, x_tip, x_r])
    y_tooth = np.concatenate([y_l, y_tip, y_r])
    
    return np.column_stack([x_tooth, y_tooth])

# --- 전체 기어 프로파일 생성 ---
single_tooth = generate_tooth_profile(r_b, r_a, r_f, r_0, z_teeth, alpha_0, x)

all_x, all_y = [], []
for k in range(z_teeth):
    angle = k * 2 * np.pi / z_teeth
    c, s = np.cos(angle), np.sin(angle)
    x_rot = single_tooth[:, 0] * c - single_tooth[:, 1] * s
    y_rot = single_tooth[:, 0] * s + single_tooth[:, 1] * c
    all_x.extend(x_rot)
    all_y.extend(y_rot)

profile_2d = np.column_stack([all_x, all_y])

# --- 3D 압출 ---
def extrude_profile_to_3d(profile_2d, face_width, z_slices=2):
    """2D 프로파일을 Z방향으로 압출하여 3D 정점 생성
    profile_2d: (N, 2) 배열
    face_width: 이폭 [mm]
    z_slices: Z방향 분할 수 (최소 2: 앞면/뒷면)
    반환: (z_slices, N, 3) 배열
    """
    z_vals = np.linspace(0, face_width, z_slices)
    vertices = []
    for z_val in z_vals:
        layer = np.column_stack([
            profile_2d,
            np.full(len(profile_2d), z_val)
        ])
        vertices.append(layer)
    return np.array(vertices)

layers_3d = extrude_profile_to_3d(profile_2d, face_width, z_slices=2)

# --- 시각화 ---
fig = plt.figure(figsize=(12, 5))

# 2D 프로파일
ax1 = fig.add_subplot(121)
ax1.plot(profile_2d[:, 0], profile_2d[:, 1], 'b-', linewidth=0.5)
circle_theta = np.linspace(0, 2*np.pi, 200)
ax1.plot(r_a * np.cos(circle_theta), r_a * np.sin(circle_theta), 
         'r--', alpha=0.3, label='이끝원')
ax1.plot(r_f * np.cos(circle_theta), r_f * np.sin(circle_theta), 
         'g--', alpha=0.3, label='이뿌리원')
ax1.set_aspect('equal')
ax1.set_title('2D 기어 프로파일', fontsize=14)
ax1.set_xlabel('X [mm]')
ax1.set_ylabel('Y [mm]')
ax1.legend(fontsize=9)
ax1.grid(True, alpha=0.3)

# 3D 와이어프레임
ax2 = fig.add_subplot(122, projection='3d')
for layer in layers_3d:
    ax2.plot(layer[:, 0], layer[:, 1], layer[:, 2], 'b-', linewidth=0.3)
# 축 방향 연결선 (일부만)
step = max(1, len(profile_2d) // 40)
for i in range(0, len(profile_2d), step):
    xs = [layers_3d[0][i, 0], layers_3d[-1][i, 0]]
    ys = [layers_3d[0][i, 1], layers_3d[-1][i, 1]]
    zs = [layers_3d[0][i, 2], layers_3d[-1][i, 2]]
    ax2.plot(xs, ys, zs, 'b-', linewidth=0.2, alpha=0.5)

ax2.set_title('3D 스퍼 기어 (압출)', fontsize=14)
ax2.set_xlabel('X [mm]')
ax2.set_ylabel('Y [mm]')
ax2.set_zlabel('Z [mm]')
ax2.view_init(elev=25, azim=-60)

plt.tight_layout()
plt.show()
```

> **결과 해석**: 왼쪽에 2D 기어 프로파일이, 오른쪽에 Z축 방향으로 압출된 3D 와이어프레임 기어가 나타납니다. 스퍼 기어는 모든 Z 위치에서 단면이 동일하므로 앞면과 뒷면의 형상이 같습니다.

### 5.1.4 전위 기어 프로파일 검증

전위 계수 $x \neq 0$인 기어에서 `generate_tooth_profile()` 함수가 올바른 치형을 생성하는지 검증합니다. 소스 문서(01-involute-gear-fundamentals.md S3.4)에 따르면, 전위가 적용된 기어의 $\theta_{offset}$은 다음과 같습니다.

$$\theta_{offset} = \frac{\pi}{2z} + \text{inv}(\alpha_0) + \frac{2x\tan(\alpha_0)}{z}$$

전위가 없는 기어($x = 0$)와 양전위 기어($x = 0.4$)의 치형을 비교하여, 전위 항이 이두께와 이끝원/이뿌리원 크기에 미치는 영향을 확인합니다.

> **시각화**: 표준 기어(x=0)와 전위 기어(x=0.4)의 치형을 겹쳐 비교합니다. 전위 기어는 이끝원이 커지고 이뿌리원이 작아지며, 이두께가 두꺼워지는 것을 확인할 수 있습니다.

```python
"""
전위 계수가 치형에 미치는 영향을 비교 검증합니다.
x=0 (표준)과 x=0.4 (양전위)의 치형을 겹쳐 그립니다.
"""
import numpy as np
import matplotlib.pyplot as plt

# --- 공통 함수 ---
def involute_function(alpha):
    """inv(alpha) = tan(alpha) - alpha"""
    return np.tan(alpha) - alpha

def generate_tooth_profile(r_b, r_a, r_f, r_0, z_teeth, alpha_0, x=0, n_pts=40):
    """단일 이 프로파일 생성 (전위 계수 x 포함)"""
    t_start = np.sqrt(max(0, (max(r_f, r_b) / r_b)**2 - 1))
    t_tip = np.sqrt((r_a / r_b)**2 - 1)
    
    # theta_offset: 전위 항 2*x*tan(alpha_0)/z 포함
    inv_a0 = involute_function(alpha_0)
    theta_offset = np.pi / (2 * z_teeth) + inv_a0 + 2 * x * np.tan(alpha_0) / z_teeth
    
    # 오른쪽 플랭크
    t = np.linspace(t_start, t_tip, n_pts)
    x_inv = r_b * (np.cos(t) + t * np.sin(t))
    y_inv = r_b * (np.sin(t) - t * np.cos(t))
    
    x_r = x_inv * np.cos(theta_offset) - y_inv * np.sin(theta_offset)
    y_r = x_inv * np.sin(theta_offset) + y_inv * np.cos(theta_offset)
    
    # 왼쪽 플랭크 (Y축 반전 후 역순)
    x_l = x_r[::-1]
    y_l = -y_r[::-1]
    
    # 이끝 원호
    theta_tip_r = np.arctan2(y_r[-1], x_r[-1])
    theta_tip_l = np.arctan2(y_l[0], x_l[0])
    theta_tip = np.linspace(theta_tip_l, theta_tip_r, 5)
    x_tip = r_a * np.cos(theta_tip)
    y_tip = r_a * np.sin(theta_tip)
    
    x_tooth = np.concatenate([x_l, x_tip, x_r])
    y_tooth = np.concatenate([y_l, y_tip, y_r])
    return np.column_stack([x_tooth, y_tooth])

# --- 매개변수 ---
m = 3
z_teeth = 12       # 잇수가 적어 전위 효과가 뚜렷함
alpha_0 = np.radians(20)

# --- 표준 기어 (x=0) ---
x_std = 0
r_0 = m * z_teeth / 2
r_b = r_0 * np.cos(alpha_0)
r_a_std = r_0 + m * (1 + x_std)
r_f_std = r_0 - m * (1.25 - x_std)
tooth_std = generate_tooth_profile(r_b, r_a_std, r_f_std, r_0, z_teeth, alpha_0, x_std)

# --- 전위 기어 (x=0.4) ---
x_shift = 0.4
r_a_shift = r_0 + m * (1 + x_shift)
r_f_shift = r_0 - m * (1.25 - x_shift)
tooth_shift = generate_tooth_profile(r_b, r_a_shift, r_f_shift, r_0, z_teeth, alpha_0, x_shift)

# --- 이두께 검증 (피치원 위) ---
def measure_tooth_thickness_at_r(tooth_profile, r_target, tol=0.3):
    """프로파일 점들 중 반지름 r_target 근처의 이두께(원호 길이)를 추정"""
    dists = np.sqrt(tooth_profile[:, 0]**2 + tooth_profile[:, 1]**2)
    mask = np.abs(dists - r_target) < tol
    if np.sum(mask) < 2:
        return None
    angles = np.arctan2(tooth_profile[mask, 1], tooth_profile[mask, 0])
    return r_target * (np.max(angles) - np.min(angles))

s_std = measure_tooth_thickness_at_r(tooth_std, r_0)
s_shift = measure_tooth_thickness_at_r(tooth_shift, r_0)

# 이론값: s_0 = m * (pi/2 + 2*x*tan(alpha_0))
s_theory_std = m * (np.pi / 2 + 2 * x_std * np.tan(alpha_0))
s_theory_shift = m * (np.pi / 2 + 2 * x_shift * np.tan(alpha_0))

print(f"=== 이두께 검증 (피치원 r_0 = {r_0:.1f} mm) ===")
print(f"표준 기어 (x=0):   측정 s = {s_std:.3f} mm, 이론 s = {s_theory_std:.3f} mm")
print(f"전위 기어 (x=0.4): 측정 s = {s_shift:.3f} mm, 이론 s = {s_theory_shift:.3f} mm")
print(f"\n전위에 의한 이두께 증가: {s_theory_shift - s_theory_std:.3f} mm")

# --- 시각화 ---
fig, axes = plt.subplots(1, 2, figsize=(14, 6))

# 왼쪽: 치형 비교
ax = axes[0]
ax.plot(tooth_std[:, 0], tooth_std[:, 1], 'b-', linewidth=1.5, label=f'표준 (x={x_std})')
ax.plot(tooth_shift[:, 0], tooth_shift[:, 1], 'r-', linewidth=1.5, label=f'전위 (x={x_shift})')

# 기준원들
theta_arc = np.linspace(-0.3, 0.3, 100)
ax.plot(r_0 * np.cos(theta_arc), r_0 * np.sin(theta_arc), 'k--', alpha=0.3, label='피치원')
ax.plot(r_b * np.cos(theta_arc), r_b * np.sin(theta_arc), 'g--', alpha=0.3, label='기초원')

ax.set_aspect('equal')
ax.set_title('치형 비교: 표준 vs 전위', fontsize=13)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.legend(fontsize=9)
ax.grid(True, alpha=0.3)

# 오른쪽: 전체 기어 프로파일 비교
ax = axes[1]
for label, tooth, x_val, color, r_a_val in [
    ('표준', tooth_std, x_std, 'blue', r_a_std),
    ('전위', tooth_shift, x_shift, 'red', r_a_shift)
]:
    all_x, all_y = [], []
    for k in range(z_teeth):
        angle = k * 2 * np.pi / z_teeth
        c, s = np.cos(angle), np.sin(angle)
        x_rot = tooth[:, 0] * c - tooth[:, 1] * s
        y_rot = tooth[:, 0] * s + tooth[:, 1] * c
        all_x.extend(x_rot)
        all_y.extend(y_rot)
    ax.plot(all_x, all_y, color=color, linewidth=0.5, alpha=0.7, label=f'x={x_val}')

ax.set_aspect('equal')
ax.set_title(f'전체 기어 비교 (z={z_teeth}, m={m})', fontsize=13)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.legend(fontsize=9)
ax.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

> **예상 출력**:
> ```
> === 이두께 검증 (피치원 r_0 = 18.0 mm) ===
> 표준 기어 (x=0):   측정 s ~ 4.712 mm, 이론 s = 4.712 mm
> 전위 기어 (x=0.4): 측정 s ~ 5.586 mm, 이론 s = 5.586 mm
>
> 전위에 의한 이두께 증가: 0.874 mm
> ```

> **결과 해석**: 전위 계수 $x = 0.4$를 적용하면 피치원 위에서 이두께가 $2xm\tan(\alpha_0) = 2 \times 0.4 \times 3 \times \tan(20°) \approx 0.874$ mm 증가합니다. 그래프에서 빨간색(전위) 치형이 파란색(표준) 치형보다 이끝원이 크고($r_a$: 21.0 mm $\to$ 22.2 mm) 이뿌리원이 올라간($r_f$: 14.25 mm $\to$ 15.45 mm) 것을 확인할 수 있습니다. 이것은 $\theta_{offset}$ 공식에서 전위 항 $2x\tan(\alpha_0)/z$가 올바르게 반영된 결과입니다.

### 5.1.5 축 구멍(Bore)과 키홈(Keyway)

실제 기어에는 축이 지나가는 **보어(bore)** 구멍이 있습니다. 보어는 반지름 $r_{bore}$의 원형 구멍으로, CSG(Constructive Solid Geometry)의 **차집합(Boolean difference)** 연산으로 처리합니다.

**키홈(keyway)** 은 축과 기어를 고정하는 홈으로, DIN 6885 등의 표준 치수에 따라 직사각형으로 정의합니다.

$$\text{키홈 좌표}: \quad x \in \left[-\frac{b_k}{2}, +\frac{b_k}{2}\right], \quad y \in [r_{bore}, r_{bore} + t_k]$$

여기서:
- $b_k$: 키홈 폭 [mm]
- $t_k$: 키홈 깊이 [mm]

> **핵심 정리**
> - 스퍼 기어의 3D 형상은 2D 프로파일의 **Z축 압출**로 생성합니다
> - $P_{3D} = (x_{2D}, y_{2D}, z)$, 여기서 $z \in [0, b]$ ($b$: 이폭)
> - 보어와 키홈은 CSG 차집합으로 처리합니다

## 5.2 3D 솔리드 모델링 기법

> **이 섹션에서 배우는 것**
> - 기어 3D 모델링에 사용되는 4가지 기본 기법
> - 각 기법의 수학적 원리와 적용 시나리오
> - Frenet-Serret 프레임을 이용한 스위프(Sweep) 기법

### 5.2.1 4가지 기본 기법 개요

기어의 2D 치형 단면을 3D 솔리드로 변환하는 핵심 질문은 **"2D 단면을 3D 공간에서 어떻게 이동시키는가"** 입니다. 기어 유형에 따라 적합한 기법이 다릅니다.

| 기법 | 적용 기어 | 원리 |
|------|---------|------|
| **압출(Extrusion)** | 스퍼 기어, 내접 기어, 랙 | 2D 단면을 직선 방향으로 밀어냄 |
| **스위프(Sweep)** | 헬리컬 기어 | 2D 단면을 곡선 경로를 따라 이동 |
| **로프트(Loft)** | 베벨 기어 | 크기가 다른 여러 단면을 보간 |
| **CSG(Constructive Solid Geometry)** | 모든 기어 | 기본 형상의 합집합/차집합/교집합 |

### 5.2.2 압출(Extrusion)

가장 단순한 기법입니다. 2D 단면을 일정한 방향(보통 Z축)으로 선형 이동합니다. 스퍼 기어, 내접 기어, 랙이 이에 해당합니다.

$$P_{3D}(u, v, w) = P_{2D}(u, v) + w \cdot \hat{d}$$

여기서 $\hat{d}$는 압출 방향 단위벡터(스퍼 기어에서는 $\hat{z}$), $w \in [0, b]$입니다.

### 5.2.3 스위프(Sweep)와 Frenet-Serret 프레임

스위프는 2D 단면을 **경로 곡선(path curve)** 을 따라 이동시키는 기법입니다. 헬리컬 기어에서는 경로가 나선(helix)입니다.

경로 곡선 $\mathbf{C}(t)$ 위에서 Frenet-Serret 프레임은 세 개의 직교 단위벡터를 정의합니다.

$$\mathbf{T} = \frac{d\mathbf{C}/dt}{|d\mathbf{C}/dt|} \quad \text{(접선 벡터)}$$

$$\mathbf{N} = \frac{d\mathbf{T}/dt}{|d\mathbf{T}/dt|} \quad \text{(법선 벡터)}$$

$$\mathbf{B} = \mathbf{T} \times \mathbf{N} \quad \text{(종법선 벡터)}$$

2D 단면의 점 $\mathbf{p}_{2D} = (u, v)$는 경로 위의 각 위치에서 3D로 변환됩니다.

$$\mathbf{P}_{3D}(t) = \mathbf{C}(t) + u \cdot \mathbf{N}(t) + v \cdot \mathbf{B}(t)$$

헬리컬 기어에서 경로 곡선은 나선입니다.

$$\mathbf{C}(t) = \begin{pmatrix} r\cos t \\ r\sin t \\ \frac{L}{2\pi}t \end{pmatrix}$$

여기서 $L = \pi d \cot\beta$는 **리드(lead)** 입니다.

이 경로에서의 접선 벡터:

$$\mathbf{T}(t) = \frac{(-r\sin t, \; r\cos t, \; L/(2\pi))}{\sqrt{r^2 + (L/2\pi)^2}}$$

> 스위프에 대한 상세한 내용은 **[M06: 헬리컬 기어 수학]** 에서 다룹니다.

### 5.2.4 로프트(Loft)

로프트는 **크기가 다른 여러 단면**을 부드럽게 보간하는 기법입니다. 베벨 기어에서 치형 크기가 원뿔 꼭짓점 방향으로 점차 작아지므로, 외단(큰 단면)과 내단(작은 단면) 사이를 로프트로 연결합니다.

> 로프트에 대한 상세한 내용은 **[M07: 베벨/내접/랙 기어]** 에서 다룹니다.

### 5.2.5 CSG (Constructive Solid Geometry)

CSG는 기본 형상(원통, 직육면체 등)에 **부울 연산(Boolean operation)** 을 적용하여 복잡한 형상을 만드는 기법입니다.

기어 3D 모델에서의 주요 CSG 연산:

```
기어 솔리드 = 원통(이끝원 반지름)
              - 각 치 홈(인벌류트 프로파일 압출)
              - 보어(bore)
              - 키홈(keyway)
              + 허브(hub)  (필요 시)
```

ax = axes[2]
for k in range(z_teeth):

    tooth_width = np.pi / (2 * z_teeth)
    th_range = np.linspace(ang - tooth_width, ang + tooth_width, 20)
    ax.fill_between(r_a * np.cos(th_range), r_a * np.sin(th_range),

ax.fill(r_bore * np.cos(theta), r_bore * np.sin(theta), color='white')

## 5.3 메시 생성과 법선 벡터

> **이 섹션에서 배우는 것**
> - 3D 기어 형상을 삼각형 메시로 분할하는 전략
> - 면 법선과 정점 법선의 계산 방법
> - 메시 품질 지표와 권장 해상도

### 5.3.1 왜 메시가 필요한가

3D 형상을 화면에 렌더링하거나 3D 프린터로 출력하려면, 연속적인 곡면을 **삼각형(triangle)** 의 집합으로 근사해야 합니다. 이를 **메시(mesh)** 또는 **삼각분할(tessellation)** 이라고 합니다. 삼각형 수가 많을수록 형상이 정밀해지지만, 파일 크기와 렌더링 시간이 증가합니다.

### 5.3.2 삼각형 메시 분할 전략

기어 메시에서는 부위별로 다른 분해능이 필요합니다.

| 기어 부위 | 권장 간격 | 이유 |
|---------|----------|------|
| 인벌류트 플랭크(치면) | 0.1~0.5 mm | 부드러운 곡면 표현 |
| 이뿌리 필렛 | 0.05~0.2 mm | 곡률이 큰 부분, 세밀한 분할 필요 |
| 이끝 원호 | 0.1~0.5 mm | 비교적 단순한 곡면 |
| Z방향 (이폭) | 스퍼: 2레이어, 헬리컬: 5도당 1레이어 | 스퍼는 단면 일정 |

**레이어 간 삼각분할**: 연속된 두 단면 레이어 $L_k$, $L_{k+1}$ (각각 $N$개 정점) 사이를 삼각형으로 연결합니다. 하나의 사각형을 두 개의 삼각형으로 분할합니다.

```python
def triangulate_between_layers(layer0, layer1):
    """두 레이어 사이를 삼각형으로 연결
    layer0, layer1: (N, 3) 배열
    반환: 삼각형 인덱스 리스트
    """
    N = len(layer0)
    triangles = []
    for i in range(N - 1):
        # 사각형을 두 삼각형으로 분할
        tri1 = (i, i + 1, i + N)       # 하단 삼각형
        tri2 = (i + 1, i + N + 1, i + N)  # 상단 삼각형
        triangles.extend([tri1, tri2])
    return triangles
```

### 5.3.3 삼각형 품질 지표

좋은 메시를 만들기 위해 삼각형의 품질을 평가하는 지표가 있습니다.

$$Q(t) = \frac{6\sqrt{3} \cdot S_t}{p_t \cdot h_t}$$

여기서:
- $S_t$: 삼각형의 넓이
- $p_t$: 반둘레(semi-perimeter)
- $h_t$: 최장 변의 길이
- $Q = 1$이면 정삼각형 (이상적)

기어 치면에서는 **종횡비(aspect ratio)를 1:5 이내**로 유지하는 것이 권장됩니다.

### 5.3.4 법선 벡터 계산

법선 벡터(normal vector)는 삼각형이 어느 방향을 향하고 있는지를 나타냅니다. 올바른 법선은 조명 계산과 STL 출력에 필수적입니다.

**면 법선(face normal)** — 하나의 삼각형의 법선:

$$\mathbf{n}_{face} = \frac{(\mathbf{v}_1 - \mathbf{v}_0) \times (\mathbf{v}_2 - \mathbf{v}_0)}{|(\mathbf{v}_1 - \mathbf{v}_0) \times (\mathbf{v}_2 - \mathbf{v}_0)|}$$

여기서 $\mathbf{v}_0, \mathbf{v}_1, \mathbf{v}_2$는 삼각형의 세 꼭짓점입니다.

**정점 법선(vertex normal)** — 한 정점에 인접한 삼각형 법선들의 **면적 가중 평균**:

$$\mathbf{n}_{vertex} = \frac{\sum_i A_i \mathbf{n}_i}{|\sum_i A_i \mathbf{n}_i|}$$

여기서 $A_i$는 인접 삼각형의 면적, $\mathbf{n}_i$는 인접 삼각형의 법선입니다. 면적 가중을 사용하면 큰 삼각형이 더 많은 영향을 미쳐 자연스러운 법선이 됩니다.

> **시각화**: 메시 분할 결과와 법선 벡터를 함께 보여줍니다.

```python
"""
간단한 기어 단면에 대한 메시 분할과 법선 벡터를 보여줍니다.
"""
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

# --- 간단한 기어 치 형상 (3개 이만 생성) ---
m = 3
z_teeth = 20
alpha_0 = np.radians(20)
r_0 = m * z_teeth / 2
r_b = r_0 * np.cos(alpha_0)
r_a = r_0 + m
r_f = r_0 - 1.25 * m
face_width = 10

# 인벌류트 한 이의 프로파일 (간략화)
def tooth_section(r_b, r_a, z_teeth, alpha_0, x_shift=0, n=15):
    inv_a0 = np.tan(alpha_0) - alpha_0
    theta_off = np.pi / (2 * z_teeth) + inv_a0 + 2 * x_shift * np.tan(alpha_0) / z_teeth
    t = np.linspace(0, np.sqrt((r_a / r_b)**2 - 1), n)
    x = r_b * (np.cos(t) + t * np.sin(t))
    y = r_b * (np.sin(t) - t * np.cos(t))
    xr = x * np.cos(theta_off) - y * np.sin(theta_off)
    yr = x * np.sin(theta_off) + y * np.cos(theta_off)
    # 좌우 합치기
    profile = np.column_stack([
        np.concatenate([xr[::-1], xr]),
        np.concatenate([-yr[::-1], yr])
    ])
    return profile

profile = tooth_section(r_b, r_a, z_teeth, alpha_0, n=10)
N = len(profile)

# 두 레이어 (Z=0, Z=face_width)
layer0 = np.column_stack([profile, np.zeros(N)])
layer1 = np.column_stack([profile, np.full(N, face_width)])

# 삼각분할
vertices = np.vstack([layer0, layer1])
triangles = []
for i in range(N - 1):
    triangles.append([i, i + 1, i + N])
    triangles.append([i + 1, i + N + 1, i + N])
triangles = np.array(triangles)

# 법선 벡터 계산
def compute_face_normals(verts, faces):
    normals = []
    for f in faces:
        v0, v1, v2 = verts[f[0]], verts[f[1]], verts[f[2]]
        e1 = v1 - v0
        e2 = v2 - v0
        n = np.cross(e1, e2)
        norm = np.linalg.norm(n)
        if norm > 1e-12:
            n = n / norm
        normals.append(n)
    return np.array(normals)

# 면 중심과 법선
face_normals = compute_face_normals(vertices, triangles)
face_centers = np.mean(vertices[triangles], axis=1)

# --- 시각화 ---
fig = plt.figure(figsize=(10, 8))
ax = fig.add_subplot(111, projection='3d')

# 메시 와이어프레임
for tri in triangles:
    tri_verts = vertices[tri]
    # 삼각형 외곽선
    for j in range(3):
        p1 = tri_verts[j]
        p2 = tri_verts[(j + 1) % 3]
        ax.plot([p1[0], p2[0]], [p1[1], p2[1]], [p1[2], p2[2]], 
                'b-', linewidth=0.5, alpha=0.6)

# 법선 화살표 (간격 두고 표시)
scale = 2.0
step = 3
for i in range(0, len(face_centers), step):
    c = face_centers[i]
    n = face_normals[i]
    ax.quiver(c[0], c[1], c[2], n[0]*scale, n[1]*scale, n[2]*scale,
              color='red', arrow_length_ratio=0.3, linewidth=1)

ax.set_title('메시 분할 + 법선 벡터 (빨간 화살표)', fontsize=14)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.set_zlabel('Z [mm]')
ax.view_init(elev=20, azim=-50)

plt.tight_layout()
plt.show()
```

> **결과 해석**: 파란색 와이어프레임이 삼각형 메시를, 빨간색 화살표가 각 삼각형의 면 법선 벡터를 나타냅니다. 법선 벡터는 곡면의 바깥 방향을 가리키며, 이 방향이 올바르지 않으면 렌더링 시 표면이 검게 보이거나 STL 파일이 올바르게 출력되지 않습니다.

### 5.3.5 정점 법선 계산 코드

```python
def compute_vertex_normals(vertices, faces):
    """정점 법선 계산 (면적 가중 평균)
    vertices: (V, 3) 배열 — 정점 좌표
    faces: (F, 3) 배열 — 삼각형 인덱스
    반환: (V, 3) 배열 — 각 정점의 법선 벡터
    """
    normals = np.zeros_like(vertices)
    for f in faces:
        v0, v1, v2 = vertices[f[0]], vertices[f[1]], vertices[f[2]]
        edge1 = v1 - v0
        edge2 = v2 - v0
        face_normal = np.cross(edge1, edge2)
        area = np.linalg.norm(face_normal) / 2
        face_normal_unit = face_normal / (np.linalg.norm(face_normal) + 1e-12)
        # 면적 가중으로 인접 정점에 누적
        normals[f[0]] += area * face_normal_unit
        normals[f[1]] += area * face_normal_unit
        normals[f[2]] += area * face_normal_unit
    # 정규화
    norms = np.linalg.norm(normals, axis=1, keepdims=True)
    return normals / (norms + 1e-12)
```

> **핵심 정리**
> - 3D 기어를 렌더링/출력하려면 곡면을 **삼각형 메시**로 근사해야 합니다
> - **면 법선**: $\mathbf{n} = (\mathbf{v}_1 - \mathbf{v}_0) \times (\mathbf{v}_2 - \mathbf{v}_0)$ (정규화)
> - **정점 법선**: 인접 삼각형 법선의 면적 가중 평균
> - 치면은 곡률에 비례한 세분화, 이뿌리 필렛은 가장 조밀하게

### 5.4.1 STL 포맷

**STL(Stereolithography)** 은 3D 프린팅에서 가장 널리 사용되는 포맷입니다. 각 삼각형의 법선 벡터와 세 꼭짓점으로 구성됩니다.

**ASCII STL 구조**:
```
solid gear
  facet normal nx ny nz
    outer loop
      vertex x1 y1 z1
      vertex x2 y2 z2
      vertex x3 y3 z3
    endloop
  endfacet
  ...
endsolid gear
```

**Binary STL**: ASCII보다 파일 크기가 작고 읽기 빠릅니다. 80바이트 헤더 + 삼각형 수(4바이트) + 각 삼각형(50바이트)으로 구성됩니다.

**STL 출력 시 필수 조건**:
1. 모든 삼각형의 법선이 솔리드 **바깥**을 향해야 합니다 (outward-pointing normals)
2. 인접 삼각형은 두 꼭짓점을 공유해야 합니다 (shared vertices)
3. **워터타이트 메시(watertight mesh)**: 구멍이 없어야 합니다
4. 뒤집힌 삼각형 없음 (consistent winding order)
5. T-junction 없음 (인접 삼각형이 완전한 변을 공유)

### 5.4.2 STL 출력 코드

```python
"""
삼각형 메시를 ASCII STL 파일로 출력하는 함수입니다.
"""
import numpy as np

def write_stl_ascii(filename, vertices, faces, solid_name='gear'):
    """삼각형 메시를 ASCII STL 파일로 저장
    filename: 출력 파일 경로
    vertices: (V, 3) 배열 — 정점 좌표
    faces: (F, 3) 배열 — 삼각형 인덱스 (정수)
    solid_name: 솔리드 이름
    """
    with open(filename, 'w') as f:
        f.write(f'solid {solid_name}\n')
        for face in faces:
            v0 = vertices[face[0]]
            v1 = vertices[face[1]]
            v2 = vertices[face[2]]
            # 면 법선 계산
            edge1 = v1 - v0
            edge2 = v2 - v0
            normal = np.cross(edge1, edge2)
            norm_len = np.linalg.norm(normal)
            if norm_len > 1e-12:
                normal = normal / norm_len
            else:
                normal = np.array([0, 0, 1])
            f.write(f'  facet normal {normal[0]:.6e} {normal[1]:.6e} {normal[2]:.6e}\n')
            f.write('    outer loop\n')
            f.write(f'      vertex {v0[0]:.6e} {v0[1]:.6e} {v0[2]:.6e}\n')
            f.write(f'      vertex {v1[0]:.6e} {v1[1]:.6e} {v1[2]:.6e}\n')
            f.write(f'      vertex {v2[0]:.6e} {v2[1]:.6e} {v2[2]:.6e}\n')
            f.write('    endloop\n')
            f.write('  endfacet\n')
        f.write(f'endsolid {solid_name}\n')
    print(f'STL 파일 저장 완료: {filename} ({len(faces)}개 삼각형)')

# 사용 예시
# write_stl_ascii('spur_gear.stl', vertices, faces)
```

### 5.4.3 STEP 포맷

**STEP (Standard for the Exchange of Product Data)** 은 CAD 소프트웨어 간 데이터 교환을 위한 표준 포맷입니다. STL과 달리 **B-Rep(Boundary Representation)** 방식으로, 삼각형 근사가 아닌 NURBS/B-spline **곡면** 으로 형상을 표현합니다.

| 특성 | STL | STEP |
|------|-----|------|
| 곡면 표현 | 삼각형 근사 | 정확한 곡면 (NURBS) |
| 파일 크기 | 작음 (메시 해상도에 비례) | 상대적으로 큼 |
| 정밀도 | 메시 해상도에 의존 | 수학적으로 정확 |
| 용도 | 3D 프린팅, 시각화 | CAD 데이터 교환, 가공 |
| 라이브러리 | 직접 구현 가능 | Open CASCADE (PythonOCC) 필요 |

기어 플랭크를 하나의 NURBS 패치로 표현하려면 **곡면 피팅(surface fitting)** 이 필요합니다. Python에서는 CadQuery나 PythonOCC를 통해 STEP 출력이 가능합니다.

### 5.4.4 Three.js 렌더링 연동

웹 브라우저에서 기어를 3D로 프리뷰하려면 **Three.js (WebGL)** 를 사용합니다. Python에서 생성한 메시 데이터(정점, 법선, 인덱스)를 JSON으로 내보내고, Three.js에서 `BufferGeometry`로 로드합니다.

```javascript
// Three.js에서 기어 메시 렌더링 (참고용)
const geometry = new THREE.BufferGeometry();
geometry.setAttribute('position', new THREE.Float32BufferAttribute(vertices, 3));
geometry.setAttribute('normal', new THREE.Float32BufferAttribute(normals, 3));
geometry.setIndex(indices);
const material = new THREE.MeshStandardMaterial({
    color: 0x888888, metalness: 0.8, roughness: 0.3
});
const gear = new THREE.Mesh(geometry, material);
```

**실시간 렌더링 최적화 팁**:
1. **LOD (Level of Detail)**: 카메라 거리에 따라 메시 해상도 동적 변경
2. **IndexedBufferGeometry**: 정점 중복 없이 인덱스 배열로 면 정의
3. **Flat vs Smooth 법선**: 치면은 smooth, 이끝/이뿌리 모서리는 flat 법선 사용
4. **Instancing**: 동일 기어 여러 개 렌더링 시 `InstancedMesh` 사용

> **핵심 정리**
> - **STL**: 삼각형 기반, 3D 프린팅 표준, ASCII/Binary 두 형식
> - **STEP**: B-Rep 기반, 정확한 곡면 표현, CAD 데이터 교환
> - **Three.js**: 웹 기반 3D 프리뷰, BufferGeometry + MeshStandardMaterial
