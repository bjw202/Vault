## 4.1 전위의 필요성

> **이 섹션에서 배우는 것**
> - 언더컷(undercut) 현상이 왜 발생하는지 이해합니다
> - 전위(profile shift)의 목적과 효과를 파악합니다

### 4.1.1 언더컷 현상

**왜 중요한가**: 잇수가 적은 기어를 표준 조건($x = 0$)으로 만들면, 이뿌리 부근에서 인볼류트 프로파일이 잘려나가는 **언더컷(undercut)** 현상이 발생합니다. 언더컷은 이의 단면적을 줄여 강도를 약화시키고, 물림률을 감소시킵니다.

**언더컷 발생 조건**:

$$
z < z_{min} = \frac{2}{\sin^2(\alpha_0)}
$$

여기서:
- $z_{min}$: 언더컷이 발생하지 않는 최소 잇수
- $\alpha_0$: 기준 압력각 [rad]

$\alpha_0 = 20°$에서: $z_{min} = 2/\sin^2(20°) = 2/0.1170 \approx 17.1$

따라서 **$z \geq 17$이면 언더컷 없음**, $z < 17$이면 언더컷이 발생합니다.

**물리적 의미**: 절삭 공구(호브나 랙 커터)가 기어를 깎을 때, 잇수가 적으면 공구의 이끝이 기어 이뿌리의 인볼류트 영역을 침범하여 과도하게 깎아냅니다.

### 4.1.2 전위의 목적

**전위(profile shift)**는 절삭 공구를 기어 블랭크로부터 $x \cdot m$만큼 멀리(양전위) 또는 가까이(음전위) 이동시켜 절삭하는 것입니다.

전위의 주요 목적:
1. **언더컷 방지**: 양전위($x > 0$)를 적용하면 잇수가 적어도 언더컷을 방지할 수 있습니다
2. **중심 거리 조정**: 기어 쌍의 중심 거리를 표준값에서 변경할 수 있습니다
3. **물림률 최적화**: 전위 배분을 통해 물림률을 개선할 수 있습니다
4. **이 강도 균형**: 피니언과 기어의 이뿌리 굽힘 강도를 균형시킬 수 있습니다

> **시각화**: 언더컷 발생 치형과 전위로 보정된 치형을 비교합니다.

```python
"""
언더컷 비교: z=12에서 x=0 (언더컷 발생) vs x=0.4 (전위로 보정)
"""
import numpy as np
import matplotlib.pyplot as plt
import math

def generate_tooth(m, z, alpha0_deg, x, n_pts=60):
    """단일 이의 오른쪽 + 왼쪽 인볼류트 플랭크 좌표를 반환합니다."""
    alpha0 = math.radians(alpha0_deg)
    r0 = m * z / 2
    rb = r0 * math.cos(alpha0)
    ra = m * (z + 2 + 2*x) / 2
    rf = m * (z - 2.5 + 2*x) / 2

    t_start = max(0, math.sqrt(max(0, (max(rf, rb)/rb)**2 - 1)))
    t_tip = math.sqrt((ra/rb)**2 - 1)
    inv_a0 = math.tan(alpha0) - alpha0
    theta_off = math.pi/(2*z) + inv_a0 + 2*x*math.tan(alpha0)/z

    t = np.linspace(t_start, t_tip, n_pts)
    xi = rb * (np.cos(t) + t * np.sin(t))
    yi = rb * (np.sin(t) - t * np.cos(t))
    xr = xi * math.cos(theta_off) - yi * math.sin(theta_off)
    yr = xi * math.sin(theta_off) + yi * math.cos(theta_off)

    return xr, yr, rb, r0, ra, rf

# --- 매개변수 ---
m = 3
z = 12
alpha0_deg = 20

fig, axes = plt.subplots(1, 2, figsize=(14, 7))

for ax, x_val, title in zip(axes, [0.0, 0.4],
                               ['x=0 (언더컷 발생)', 'x=0.4 (전위 보정)']):
    xr, yr, rb, r0, ra, rf = generate_tooth(m, z, alpha0_deg, x_val)
    xl, yl = xr, -yr

    # 치형 그리기
    ax.plot(xr, yr, 'b-', linewidth=2, label='오른쪽 플랭크')
    ax.plot(xl, yl, 'r-', linewidth=2, label='왼쪽 플랭크')

    # 원 그리기
    theta_c = np.linspace(-0.3, 0.3, 200)
    for r, name, color in [(rb, '기초원', '#2ecc71'), (r0, '기준원', '#3498db'),
                             (ra, '이끝원', '#e74c3c'), (rf, '이뿌리원', '#9b59b6')]:
        ax.plot(r*np.cos(theta_c), r*np.sin(theta_c), '--', color=color, alpha=0.5)

    # 언더컷 영역 강조 (x=0일 때)
    if x_val == 0:
        ax.annotate('언더컷 영역\n(이뿌리가\n파인 부분)', xy=(rb*0.98, 2),
                    fontsize=10, color='red', fontweight='bold',
                    bbox=dict(boxstyle='round', facecolor='lightyellow'))

    ax.set_aspect('equal')
    ax.set_title(f'z={z}, {title}', fontsize=13)
    ax.set_xlabel('X [mm]')
    ax.set_ylabel('Y [mm]')
    ax.legend(fontsize=9)
    ax.grid(True, alpha=0.3)

plt.suptitle(f'언더컷 vs 전위 비교 (m={m}, z={z})', fontsize=14, y=1.02)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 왼쪽($x=0$)에서는 잇수가 17 미만이므로 이뿌리 부근에서 인볼류트가 잘려나갑니다. 오른쪽($x=0.4$)에서는 양전위를 적용하여 인볼류트가 이뿌리까지 온전히 유지됩니다. 단, 양전위를 하면 이끝원이 커지고 이끝 이두께가 감소하므로, 과도한 전위는 이끝이 뾰족해지는 문제를 일으킵니다.

> **핵심 정리**
> - 언더컷 조건: $z < 2/\sin^2(\alpha_0)$ ($\alpha_0 = 20°$에서 $z < 17$)
> - 전위: 절삭 공구를 $xm$만큼 이동시켜 언더컷 방지
> - 전위의 목적: 언더컷 방지, 중심 거리 조정, 물림률 최적화

## 4.2 전위 파라미터 수학

> **이 섹션에서 배우는 것**
> - 전위에 의해 변경되는 기어 매개변수를 계산할 수 있습니다
> - 물림 압력각과 전위 중심 거리를 구하는 방법을 배웁니다

### 4.2.1 전위 시 변경되는 파라미터

전위 계수 $x$를 적용하면 다음 파라미터가 변합니다:

$$
\begin{aligned}
d_a &= m(z + 2 + 2x) & &\text{이끝원 지름} \\
d_f &= m(z - 2.5 + 2x) & &\text{이뿌리원 지름} \\
s_0 &= m\left(\frac{\pi}{2} + 2x\tan(\alpha_0)\right) & &\text{기준원 이두께}
\end{aligned}
$$

**변하지 않는 파라미터**: 기준원 지름($d_0 = mz$), 기초원 지름($d_b = d_0\cos\alpha_0$)

### 4.2.2 물림 압력각

전위 기어 쌍에서 실제 맞물림 시의 압력각(물림 압력각, working pressure angle):

$$
\text{inv}(\alpha_w) = \text{inv}(\alpha_0) + \frac{2(x_1 + x_2)\tan(\alpha_0)}{z_1 + z_2}
$$

여기서:
- $\alpha_w$: 물림 압력각 [rad]
- $x_1, x_2$: 각 기어의 전위 계수
- $z_1, z_2$: 각 기어의 잇수

이 식의 좌변 $\text{inv}(\alpha_w)$ 값을 알면, $\alpha_w$는 inv 함수의 역함수를 수치적으로 풀어서 구해야 합니다 (4.4절 참조).

### 4.2.3 물림 중심 거리

$$
a_w = \frac{m(z_1 + z_2)\cos(\alpha_0)}{2\cos(\alpha_w)}
$$

표준 기어($x_1 = x_2 = 0$)에서는 $\alpha_w = \alpha_0$이므로 $a_w = m(z_1+z_2)/2$가 됩니다.

### 4.2.4 전위 계수 합의 배분

기어 쌍에서 전위 계수의 합 $x_1 + x_2$는 물림 압력각(따라서 중심 거리)을 결정합니다. 이 합을 두 기어에 어떻게 배분할지는 설계자의 판단에 달려 있으며, 주요 고려 사항은:

- **이뿌리 강도 균형**: 작은 기어(피니언)에 더 많은 양전위를 배분
- **물림률 유지**: 전위 합이 너무 크면 물림률이 감소
- **이끝 이두께**: 각 기어의 이끝 이두께가 $s_a \geq 0.3m$ 이상 유지

> **핵심 정리**
> - 전위 시 변경: $d_a, d_f, s_0$ (기준원, 기초원은 불변)
> - 물림 압력각: $\text{inv}(\alpha_w) = \text{inv}(\alpha_0) + 2(x_1+x_2)\tan(\alpha_0)/(z_1+z_2)$
> - 물림 중심 거리: $a_w = m(z_1+z_2)\cos(\alpha_0)/(2\cos(\alpha_w))$

## 4.3 전위 한계와 에지 케이스

> **이 섹션에서 배우는 것**
> - 최소/최대 전위 계수를 계산하는 방법을 배웁니다
> - 극소 잇수에서의 특수 문제를 이해합니다

### 4.3.1 최소 전위 계수 (언더컷 방지)

$$
x_{min} = 1 - \frac{z}{z_{min}} = 1 - \frac{z\sin^2(\alpha_0)}{2} = \frac{z_{min} - z}{z_{min}}
$$

$\alpha_0 = 20°$에서: $x_{min} = (17 - z)/17$

| $z$ | $x_{min}$ | 설명 |
|-----|-----------|------|
| 17 | 0.00 | 전위 불필요 |
| 14 | 0.18 | 약간의 양전위 필요 |
| 12 | 0.29 | 중간 양전위 |
| 10 | 0.41 | 큰 양전위 필요 |
| 7 | 0.59 | 상당한 양전위 |

### 4.3.2 최대 전위 계수 (이끝 뾰족 방지)

양전위를 과도하게 적용하면 이끝이 뾰족해집니다. 이끝원에서의 이두께 $s_a$:

$$
s_a = d_a\left(\frac{s_0}{d_0} + \text{inv}(\alpha_0) - \text{inv}(\alpha_a)\right)
$$

여기서 $\alpha_a = \arccos(r_b/r_a)$는 이끝원에서의 압력각입니다.

$s_a \leq 0$이면 이끝이 뾰족해지며, **실용적으로 $s_a < 0.3m$이면 경고**가 필요합니다.

최대 전위 계수 $x_{max}$는 $s_a = 0$ 조건에서 해석적으로 구하기 어려우므로, **이분법(bisection method)**으로 수치적으로 구합니다.

### 4.3.3 극소 잇수 처리 (z < 5)

| $z$ | 문제 | 조치 |
|-----|------|------|
| 1 | $r_f < 0$ (이뿌리원 음수) | 물리적으로 불가능 |
| 2 | $r_f < 0$ ($x=0$일 때) | 큰 양전위 필요 |
| 3-4 | 인볼류트 플랭크 거의 없음 | 특수 설계만 가능 |
| 5-16 | 언더컷 발생 | $x \geq x_{min}$ 전위 |
| $\geq 17$ | 정상 | 전위 불필요 |

KHK 산업 권고: **실용 하한 $z \geq 5$**. $z < 5$는 핀 휠(pin wheel) 등 특수 설계에만 사용됩니다.

```python
"""
전위 계수의 허용 범위를 잇수별로 시각화합니다.
"""
import numpy as np
import matplotlib.pyplot as plt
import math

def involute_function(alpha):
    return math.tan(alpha) - alpha

def profile_shift_limits(z, alpha0_deg=20.0):
    """전위 계수의 최소/최대값을 계산합니다."""
    alpha0 = math.radians(alpha0_deg)
    x_min = 1.0 - z * math.sin(alpha0)**2 / 2

    # 이끝 뾰족 상한: 이분법으로 탐색
    def tip_thickness(x_val):
        r0 = z / 2
        rb = r0 * math.cos(alpha0)
        ra = r0 + 1 + x_val
        if ra <= rb:
            return float('inf')
        alpha_a = math.acos(rb / ra)
        s_a = 2 * ra * (math.pi/(2*z) + involute_function(alpha0)
                         - involute_function(alpha_a) + x_val*math.tan(alpha0)/z)
        return s_a

    x_lo, x_hi = 0.0, 5.0
    for _ in range(60):
        x_mid = (x_lo + x_hi) / 2
        if tip_thickness(x_mid) > 0:
            x_lo = x_mid
        else:
            x_hi = x_mid
    x_max = (x_lo + x_hi) / 2

    return x_min, x_max

# --- 계산 ---
z_range = np.arange(5, 51)
x_mins = []
x_maxs = []
for z in z_range:
    x_min, x_max = profile_shift_limits(z)
    x_mins.append(x_min)
    x_maxs.append(x_max)

x_mins = np.array(x_mins)
x_maxs = np.array(x_maxs)

# --- 시각화 ---
fig, ax = plt.subplots(figsize=(12, 6))

ax.fill_between(z_range, x_mins, x_maxs, alpha=0.3, color='green', label='허용 범위')
ax.plot(z_range, x_mins, 'b-', linewidth=2, label='$x_{min}$ (언더컷 방지)')
ax.plot(z_range, x_maxs, 'r-', linewidth=2, label='$x_{max}$ (이끝 뾰족 방지)')
ax.axhline(y=0, color='gray', linestyle='--', alpha=0.5, label='x=0 (표준)')
ax.axvline(x=17, color='orange', linestyle=':', alpha=0.7, label='z=17 (언더컷 한계)')

ax.set_xlabel('잇수 z', fontsize=12)
ax.set_ylabel('전위 계수 x', fontsize=12)
ax.set_title('잇수별 전위 계수 허용 범위 ($\\alpha_0 = 20°$)', fontsize=14)
ax.legend(fontsize=11)
ax.grid(True, alpha=0.3)
ax.set_xlim(5, 50)
ax.set_ylim(-0.5, 3.0)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 녹색 영역이 전위 계수의 허용 범위입니다. $z < 17$에서는 $x_{min} > 0$이므로 양전위가 필수입니다(파란 선). $x_{max}$(빨간 선)는 이끝 뾰족 한계로, 잇수에 관계없이 대략 1.5~2.5 사이입니다. 잇수가 적을수록 허용 범위가 좁아지며, $z = 5$ 근방에서는 매우 좁은 범위만 허용됩니다.

> **핵심 정리**
> - 최소 전위: $x_{min} = (z_{min} - z)/z_{min}$ ($\alpha_0 = 20°$에서 $(17-z)/17$)
> - 최대 전위: 이끝 이두께 $s_a \to 0$ 조건에서 수치적으로 결정
> - 실용 하한: $z \geq 5$ (KHK 권고)

## 4.4 수치 안전 함수

> **이 섹션에서 배우는 것**
> - `safe_inv()` 함수로 특이점을 방지하는 방법을 배웁니다
> - inv() 역함수를 Newton-Raphson과 Brent 방법으로 수치적으로 푸는 알고리즘을 익힙니다

### 4.4.1 safe_inv(): 특이점 방지

인볼류트 함수 $\text{inv}(\alpha) = \tan(\alpha) - \alpha$에는 두 가지 수치적 위험이 있습니다:

1. **소각도 문제** ($\alpha \approx 0$): $\tan(\alpha) \approx \alpha$이므로 뺄셈 소거(cancellation)가 발생하여 정밀도가 떨어집니다
2. **대각도 문제** ($\alpha \to \pi/2$): $\tan(\alpha)$가 발산합니다

**소각도 테일러 전개**:

$$
\text{inv}(\alpha) \approx \frac{\alpha^3}{3} + \frac{2\alpha^5}{15} + \frac{17\alpha^7}{315} \quad (|\alpha| < 0.01 \text{ rad})
$$

이 전개는 $|\alpha| < 0.1$ rad에서 상대 오차 $< 10^{-9}$를 보장합니다.

```python
"""
안전한 인볼류트 함수 구현: 특이점 방지 및 테일러 전개를 포함합니다.
"""
import math

def safe_inv(alpha_rad: float) -> float:
    """
    안전한 인볼류트 함수.
    - alpha ~ 0: 테일러 전개로 뺄셈 소거 방지
    - alpha ~ pi/2: 오류 발생으로 발산 방지
    """
    if abs(alpha_rad) < 1e-10:
        return 0.0

    if abs(alpha_rad) < 0.01:
        # 테일러 전개: alpha^3/3 + 2*alpha^5/15 + 17*alpha^7/315
        a2 = alpha_rad * alpha_rad
        return alpha_rad * a2 * (1.0/3 + a2 * (2.0/15 + a2 * 17.0/315))

    if alpha_rad >= math.pi/2 - 1e-9:
        raise ValueError(
            f'압력각 {math.degrees(alpha_rad):.2f}도는 90도에 너무 근접합니다. '
            '기어 설계에서 압력각은 45도 미만이어야 합니다.')

    return math.tan(alpha_rad) - alpha_rad

# 검증
print(f"inv(0.001) 직접계산 = {math.tan(0.001) - 0.001:.15e}")
print(f"inv(0.001) 테일러   = {safe_inv(0.001):.15e}")
print(f"inv(20도) = {safe_inv(math.radians(20)):.10f}")
```

> **결과 해석**: 소각도에서 직접 계산과 테일러 전개 결과가 일치함을 확인할 수 있습니다. 테일러 전개는 뺄셈 소거를 피하므로 소각도에서 더 안정적입니다.

### 4.4.2 inv_involute(): inv() 역함수

**왜 중요한가**: 물림 압력각을 구할 때, $\text{inv}(\alpha_w) = C$ (알려진 상수)에서 $\alpha_w$를 구해야 합니다. 해석적 역함수가 없으므로 수치적으로 풀어야 합니다.

**전략**: 
1. **Newton-Raphson** 시도 (빠른 2차 수렴)
2. 실패 시 **Brent's method**로 폴백 (보장된 수렴, 초선형 수렴)

#### 이분법(Bisection)과 Brent's method의 차이

수치적 근 탐색에서 가장 단순한 방법은 **이분법(bisection)**입니다. 구간 $[a, b]$에서 $f(a) \cdot f(b) < 0$이면 중간값 정리에 의해 근이 존재하고, 매 반복마다 구간을 절반으로 줄입니다. 수렴은 **보장**되지만, 수렴 속도가 **선형(linear)**이며 매 반복마다 정확한 자릿수가 약 1비트(0.3자리)씩만 증가합니다.

**Brent's method**(Brent, 1973)는 이분법의 안전성을 유지하면서 **역이차 보간(inverse quadratic interpolation)**과 **할선법(secant method)**을 결합하여 수렴을 가속합니다.

| 특성 | 이분법 (Bisection) | Brent's Method |
|------|-------------------|----------------|
| 수렴 보장 | 예 | 예 |
| 수렴 차수 | 선형 ($O(\log n)$, 매 반복 1비트) | 초선형 (약 $1.618$차) |
| 함수 평가 횟수 (14자리 정밀도) | ~47회 | ~8-12회 |
| 핵심 아이디어 | 구간 이등분 | 보간 시도 + 조건 불만족 시 이분법 대체 |
| 추가 복잡도 | 없음 | 5개의 Brent 조건 검사 |

Brent's method의 핵심은 **적응적 전환**입니다. 세 점 $(a, f_a)$, $(b, f_b)$, $(c, f_c)$가 모두 다른 함수값을 가지면 역이차 보간으로 다음 근사를 계산하고, 그렇지 않으면 할선법을 사용합니다. 계산된 후보 점이 현재 구간 안에 있고 충분히 빠르게 수렴하는지 5가지 조건으로 검사하며, **어느 하나라도 불만족이면 안전한 이분법으로 대체**합니다. 이 설계 덕분에 최악의 경우에도 이분법과 같은 수렴이 보장됩니다.

**Newton-Raphson 반복**:

$$
\alpha_{n+1} = \alpha_n - \frac{\text{inv}(\alpha_n) - \text{target}}{\tan^2(\alpha_n)}
$$

여기서 $d(\text{inv}(\alpha))/d\alpha = \tan^2(\alpha)$입니다.

**초기 추정**: 소각도 근사 $\text{inv}(\alpha) \approx \alpha^3/3$에서 $\alpha_0 \approx (3 \cdot \text{target})^{1/3}$

```python
"""
inv() 역함수: Newton-Raphson + Brent 폴백 구현입니다.
"""
import math

def inv_involute(target: float, tol: float = 1e-12, max_iter: int = 100) -> float:
    """
    인볼류트 함수의 역함수: inv(alpha) = target --> alpha를 반환합니다.

    전략:
    1. Newton-Raphson (빠른 수렴, 2차)
    2. 실패 시 Brent's method (보장된 수렴)
    """
    if target < 0:
        raise ValueError(f'target은 0 이상이어야 합니다 (입력: {target})')
    if target < 1e-15:
        return 0.0

    # --- Newton-Raphson ---
    alpha = min((3.0 * target) ** (1.0/3.0), math.pi/2 - 0.01)
    newton_ok = False

    for i in range(max_iter):
        tan_a = math.tan(alpha)
        f = tan_a - alpha - target
        df = tan_a * tan_a  # 도함수
        if abs(df) < 1e-30:
            break
        delta = f / df
        alpha -= delta
        alpha = max(1e-10, min(alpha, math.pi/2 - 1e-9))
        if abs(delta) < tol:
            newton_ok = True
            break

    if newton_ok and abs(math.tan(alpha) - alpha - target) < tol * 1000:
        return alpha

    # --- Brent's method (폴백) ---
    # inv(alpha)는 [0, pi/2)에서 순증가이므로 이분법 계열이 항상 수렴
    a_lo, a_hi = 1e-10, math.pi/2 - 1e-9
    f_lo = math.tan(a_lo) - a_lo - target
    f_hi = math.tan(a_hi) - a_hi - target

    if f_lo > 0:
        return a_lo
    if f_hi < 0:
        raise ValueError(
            f'inv_involute: target={target}이 너무 큽니다 '
            f'(최대 허용 ≈ {math.tan(a_hi) - a_hi:.4f})')

    # Brent's method 완전 구현
    # (역이차 보간 + 할선법 + 이분법 폴백)
    a, b = a_lo, a_hi
    fa, fb = f_lo, f_hi
    c, fc = a, fa          # c: 이전 반대쪽 경계
    mflag = True            # 직전 반복이 이분법이었는지 표시
    s = a                   # 새 후보 점
    d = 0.0                 # 두 반복 전의 구간 크기

    for _ in range(100):
        # 수렴 판정
        if abs(fb) < tol:
            return b
        if abs(b - a) < tol:
            return (a + b) / 2

        if fa != fc and fb != fc:
            # 역이차 보간 (inverse quadratic interpolation)
            # 세 점 (a,fa), (b,fb), (c,fc)를 지나는 역이차 다항식의 근
            s = (a * fb * fc / ((fa - fb) * (fa - fc))
                 + b * fa * fc / ((fb - fa) * (fb - fc))
                 + c * fa * fb / ((fc - fa) * (fc - fb)))
        else:
            # 할선법 (secant method)
            s = b - fb * (b - a) / (fb - fa)

        # === Brent 조건 5가지 ===
        # 후보 s가 충분히 좋지 않으면 이분법으로 대체
        cond1 = not ((3 * a + b) / 4 < s < b or b < s < (3 * a + b) / 4)
        cond2 = mflag and abs(s - b) >= abs(b - c) / 2
        cond3 = not mflag and abs(s - b) >= abs(c - d) / 2
        cond4 = mflag and abs(b - c) < tol
        cond5 = not mflag and abs(c - d) < tol

        if cond1 or cond2 or cond3 or cond4 or cond5:
            s = (a + b) / 2   # 이분법으로 대체
            mflag = True
        else:
            mflag = False

        fs = math.tan(s) - s - target
        d, c, fc = c, b, fb  # 이전 값 저장

        # 구간 갱신: 부호가 다른 쪽으로 경계 이동
        if fa * fs < 0:
            b, fb = s, fs
        else:
            a, fa = s, fs

        # |fa| < |fb|이면 a와 b를 교환 (b가 항상 최선 근사)
        if abs(fa) < abs(fb):
            a, b = b, a
            fa, fb = fb, fa

    return b  # 최대 반복 후 최선 근사

# --- 검증 ---
print("=== inv_involute 검증 ===")
test_angles = [5, 10, 15, 20, 25, 30, 40, 50, 60]
for deg in test_angles:
    alpha_true = math.radians(deg)
    target = math.tan(alpha_true) - alpha_true
    alpha_recovered = inv_involute(target)
    error = abs(alpha_recovered - alpha_true)
    print(f"  alpha={deg:3d}도: target={target:.8f}, 복원={math.degrees(alpha_recovered):.8f}도, 오차={error:.2e}")
```

> **결과 해석**: 모든 테스트 각도에서 오차가 $10^{-12}$ rad 이하임을 확인할 수 있습니다. Newton-Raphson은 대부분의 경우 5-10회 반복으로 수렴하며, 극단적인 경우에만 Brent's method 폴백이 동작합니다. Brent's method는 역이차 보간과 할선법을 적응적으로 전환하므로, 단순 이분법 대비 약 4-5배 적은 함수 평가로 같은 정밀도에 도달합니다.

## 4.5 검증 알고리즘

> **이 섹션에서 배우는 것**
> - 생성된 인볼류트 좌표를 검증하는 방법을 배웁니다
> - 물림률(contact ratio)을 계산하고 판정합니다
> - 언더컷/이끝 간섭을 자동으로 검사합니다

### 4.5.1 인볼류트 좌표 검증

생성된 좌표가 실제로 인볼류트 위에 있는지 확인합니다.

**검증 원리**: 인볼류트 위의 모든 점은 $|P|^2 = r_b^2(1 + t^2)$을 만족해야 합니다. 반지름 $r$에서 파라미터 $t$를 역산하고, 이를 이용해 좌표를 재생성하여 원래 점과 비교합니다.

### 4.5.2 물림률 계산

**물림률(contact ratio)** $\varepsilon$:

$$
\varepsilon = \frac{\sqrt{r_{a1}^2 - r_{b1}^2} + \sqrt{r_{a2}^2 - r_{b2}^2} - a_w\sin(\alpha_w)}{\pi m \cos(\alpha_0)}
$$

여기서:
- $r_{a1}, r_{a2}$: 각 기어의 이끝원 반지름
- $r_{b1}, r_{b2}$: 각 기어의 기초원 반지름
- $a_w$: 실제 중심 거리
- $\alpha_w$: 물림 압력각
- $m$: 모듈, $\alpha_0$: 기준 압력각

**판정 기준**:
- $\varepsilon < 1.0$: **불가** -- 연속 맞물림 불가
- $1.0 \leq \varepsilon < 1.2$: **경고** -- 소음/진동 위험
- $\varepsilon \geq 1.2$: **양호**

### 4.5.3 언더컷 검증

단일 기어의 언더컷 발생 여부:

$$
\text{언더컷 조건: } x < 1 - \frac{z\sin^2(\alpha_0)}{2}
$$

### 4.5.4 이끝 간섭 검증

기어 쌍에서 한 기어의 이끝원이 상대 기어의 기초원 한계를 넘는지 확인:

$$
\sqrt{r_{a2}^2 - r_{b2}^2} \leq a_w\sin(\alpha_w) \quad \text{(간섭 없음 조건)}
$$

### 4.5.5 통합 검증 함수

```python
"""
기어 쌍 통합 검증 함수: 잇수, 전위, 언더컷, 물림률, 이끝 간섭을 한 번에 검사합니다.
"""
import math

def compute_contact_ratio(m, z1, z2, x1=0.0, x2=0.0, alpha0_deg=20.0):
    """기어 쌍의 물림률을 계산합니다."""
    alpha0 = math.radians(alpha0_deg)
    r01, r02 = m*z1/2, m*z2/2
    rb1, rb2 = r01*math.cos(alpha0), r02*math.cos(alpha0)

    # 물림 압력각
    inv_aw = safe_inv(alpha0) + 2*(x1+x2)*math.tan(alpha0)/(z1+z2)
    alpha_w = inv_involute(inv_aw)

    # 중심 거리
    a_w = m*(z1+z2)*math.cos(alpha0)/(2*math.cos(alpha_w))

    # 이끝원
    ra1 = r01 + m*(1+x1)
    ra2 = r02 + m*(1+x2)

    # 물림 길이
    g = (math.sqrt(max(0, ra1**2 - rb1**2))
         + math.sqrt(max(0, ra2**2 - rb2**2))
         - a_w*math.sin(alpha_w))

    # 기초 피치
    pb = math.pi * m * math.cos(alpha0)
    epsilon = g / pb

    return epsilon, math.degrees(alpha_w), a_w

def full_gear_check(z1, z2, m, x1=0.0, x2=0.0, alpha0_deg=20.0):
    """기어 쌍 전체 검증을 실행합니다."""
    alpha0 = math.radians(alpha0_deg)
    results = []

    # 1. 잇수 범위
    for z, x, label in [(z1, x1, '기어1'), (z2, x2, '기어2')]:
        if z < 5:
            results.append(f"[ERROR] {label}: z={z} < 5 (실용 하한 미만)")
        elif z < 17:
            x_min = (17 - z) / 17
            if x < x_min:
                results.append(f"[WARN] {label}: z={z}, x={x:.2f} < x_min={x_min:.2f} (언더컷)")
            else:
                results.append(f"[OK] {label}: z={z}, x={x:.2f} >= x_min={x_min:.2f}")
        else:
            results.append(f"[OK] {label}: z={z} (언더컷 없음)")

    # 2. 물림률
    try:
        eps, aw_deg, a_w = compute_contact_ratio(m, z1, z2, x1, x2, alpha0_deg)
        if eps < 1.0:
            results.append(f"[ERROR] 물림률 eps={eps:.3f} < 1.0 (연속 물림 불가)")
        elif eps < 1.2:
            results.append(f"[WARN] 물림률 eps={eps:.3f} < 1.2 (소음 위험)")
        else:
            results.append(f"[OK] 물림률 eps={eps:.3f} (양호)")
        results.append(f"  물림 압력각={aw_deg:.3f}도, 중심거리={a_w:.3f}mm")
    except Exception as e:
        results.append(f"[ERROR] 물림률 계산 실패: {e}")

    return results

# --- 사용 예시 ---
print("=== 예시 1: 표준 기어 쌍 ===")
for line in full_gear_check(z1=20, z2=40, m=3.0):
    print(f"  {line}")

print("\n=== 예시 2: 소잇수 + 전위 ===")
for line in full_gear_check(z1=12, z2=40, m=3.0, x1=0.4, x2=-0.1):
    print(f"  {line}")

print("\n=== 예시 3: 소잇수 + 전위 없음 ===")
for line in full_gear_check(z1=10, z2=30, m=2.0, x1=0.0, x2=0.0):
    print(f"  {line}")
```

> **결과 해석**: 통합 검증 함수는 잇수, 전위, 물림률을 한 번에 확인합니다. 예시 1은 정상, 예시 2는 소잇수를 전위로 보정한 경우, 예시 3은 전위 없이 소잇수를 사용하여 언더컷 경고가 발생하는 경우입니다.

물림률 계산 도해: 작용선 위의 물림 구간을 시각화합니다.

> **결과 해석**: 녹색 화살표가 물림 길이 $g_\alpha$이며, 파란 점선이 기초 피치 $p_b$ 간격입니다. 물림률은 물림 길이를 기초 피치로 나눈 값입니다. $\varepsilon > 1$이면 항상 1쌍 이상의 이가 물려 있어 연속 전동이 보장됩니다.

> **핵심 정리**
> - 물림률: $\varepsilon = (\sqrt{r_{a1}^2 - r_{b1}^2} + \sqrt{r_{a2}^2 - r_{b2}^2} - a_w\sin\alpha_w) / (\pi m \cos\alpha_0)$
> - 판정: $\varepsilon \geq 1.2$ 양호, $< 1.0$ 불가
> - 통합 검증: 잇수, 전위, 언더컷, 물림률, 이끝 간섭을 한 번에 확인

## 4.6 단위 변환

> **이 섹션에서 배우는 것**
> - Module(mm) -- Diametral Pitch(inch) 변환을 정확히 수행합니다
> - UnitConverter 유틸리티를 활용합니다

### 4.6.1 변환 공식

| 변환 방향 | 수식 |
|-----------|------|
| Module --> DP | $DP = 25.4 / m$ |
| DP --> Module | $m = 25.4 / DP$ |
| Module --> 원호 피치(mm) | $p = \pi m$ |
| DP --> 원호 피치(inch) | $p = \pi / DP$ |

### 4.6.2 UnitConverter 유틸리티

```python
"""
기어 단위 변환 유틸리티 클래스입니다.
"""
import math

class UnitConverter:
    """Module(mm) -- Diametral Pitch(inch) 변환 유틸리티"""
    MM_PER_INCH = 25.4

    _ISO_MODULES = [1, 1.25, 1.5, 2, 2.5, 3, 4, 5, 6, 8, 10, 12, 16, 20, 25, 32, 40, 50]
    _AGMA_DPS = [1, 1.25, 1.5, 1.75, 2, 2.5, 3, 4, 5, 6, 8, 10, 12, 14, 16, 20, 24, 32, 48, 64]

    @staticmethod
    def module_to_dp(module_mm):
        """Module(mm) --> Diametral Pitch"""
        return 25.4 / module_mm

    @staticmethod
    def dp_to_module(dp):
        """Diametral Pitch --> Module(mm)"""
        return 25.4 / dp

    @classmethod
    def nearest_standard_module(cls, module_mm):
        """가장 가까운 ISO 표준 모듈을 반환합니다."""
        return min(cls._ISO_MODULES, key=lambda m: abs(m - module_mm))

    @classmethod
    def nearest_standard_dp(cls, dp):
        """가장 가까운 AGMA 표준 DP를 반환합니다."""
        return min(cls._AGMA_DPS, key=lambda p: abs(p - dp))

# --- 사용 예시 ---
uc = UnitConverter()
print(f"m=2mm --> DP = {uc.module_to_dp(2):.4f}")
print(f"DP=8  --> m  = {uc.dp_to_module(8):.4f} mm")
print(f"m=3.2mm 가장 가까운 표준 모듈: {uc.nearest_standard_module(3.2)} mm")
print(f"DP=9 가장 가까운 표준 DP: {uc.nearest_standard_dp(9)}")

# 변환 테이블
print("\n=== Module -- DP 변환 테이블 (일부) ===")
print(f"{'Module [mm]':>12} | {'DP [teeth/inch]':>16} | {'원호 피치 [mm]':>14}")
print("-" * 50)
for m_val in [1, 2, 2.5, 3, 4, 5, 6, 8, 10]:
    dp = uc.module_to_dp(m_val)
    cp = math.pi * m_val
    print(f"{m_val:12.2f} | {dp:16.4f} | {cp:14.4f}")
```

> **핵심 정리**
> - Module -- DP 변환: $DP = 25.4/m$, $m = 25.4/DP$
> - 내부 계산: 항상 mm/rad 사용
> - 혼용 방지: 입력 즉시 내부 단위로 변환, 출력 시 역변환

## 핵심 수식 정리

| 수식 | 이름 | 설명 |
|------|------|------|
| $z_{min} = 2/\sin^2(\alpha_0)$ | 최소 잇수 | 언더컷 없는 최소 잇수 (20도에서 17) |
| $x_{min} = (z_{min} - z)/z_{min}$ | 최소 전위 | 언더컷 방지 최소 전위 계수 |
| $\text{inv}(\alpha_w) = \text{inv}(\alpha_0) + 2(x_1+x_2)\tan\alpha_0/(z_1+z_2)$ | 물림 압력각 | 전위 기어 쌍의 실제 압력각 |
| $a_w = m(z_1+z_2)\cos\alpha_0/(2\cos\alpha_w)$ | 물림 중심 거리 | 전위 기어 쌍의 실제 축간 거리 |
| $\text{inv}(\alpha) \approx \alpha^3/3$ | 소각도 근사 | 테일러 전개 (소각도 안정성) |
| $\alpha_{n+1} = \alpha_n - (\text{inv}(\alpha_n)-C)/\tan^2(\alpha_n)$ | Newton-Raphson | inv 역함수 수치 해법 |
| $\varepsilon = g_\alpha / p_b$ | 물림률 | 동시 접촉 이 평균 수 |
| $DP = 25.4/m$ | 단위 변환 | Module -- Diametral Pitch |
