## 2.1 모듈과 잇수

> **이 섹션에서 배우는 것**
> - 모듈(module) $m$의 정의와 의미를 이해합니다
> - 인치 계열의 Diametral Pitch와의 관계를 배웁니다
> - 단위 변환 방법을 익힙니다

### 2.1.1 모듈의 정의

**왜 중요한가**: 모듈(module)은 기어 크기를 결정하는 가장 기본적인 매개변수입니다. 모듈이 같은 기어끼리만 맞물릴 수 있으므로, 기어 설계의 첫 번째 결정은 모듈 선택입니다.

**수학적 정의**:

$$
m = \frac{d_0}{z}
$$

여기서:
- $m$: 모듈 [mm]
- $d_0$: 기준원(pitch circle) 지름 [mm]
- $z$: 잇수 (정수)

직관적으로, 모듈은 "기어 이 하나에 해당하는 기준원 지름의 몫"입니다. 모듈이 클수록 이가 크고 튼튼하며, 작을수록 이가 작고 정밀합니다.

**ISO 표준 모듈값 (ISO 54)**:

1, 1.25, 1.5, 2, 2.5, 3, 4, 5, 6, 8, 10, 12, 16, 20, 25, 32, 40, 50 (mm)

실제 설계에서는 이 표준값 중에서 선택합니다.

### 2.1.2 Diametral Pitch와의 관계

인치 계열에서는 모듈 대신 **Diametral Pitch (DP)**를 사용합니다.

$$
DP = \frac{z}{d_0 \text{[inch]}} = \frac{25.4}{m}
$$

여기서:
- $DP$: Diametral Pitch [teeth/inch]
- 25.4: mm/inch 변환 상수

**변환 공식**:

| 방향 | 수식 |
|------|------|
| Module --> DP | $DP = 25.4 / m$ |
| DP --> Module | $m = 25.4 / DP$ |

**예시**: $m = 2$ mm --> $DP = 25.4 / 2 = 12.7$ teeth/inch

**AGMA 표준 DP값**: 1, 1.25, 1.5, 1.75, 2, 2.5, 3, 4, 5, 6, 8, 10, 12, 14, 16, 20, 24, 32, 48, 64

주의: 국제 설계에서는 반드시 단위계를 확인해야 합니다. 모듈과 DP를 혼용하면 치명적인 오류가 발생합니다. --> 단위 변환의 상세 구현은 [M04: 전위 및 검증] S4.6에서 다룹니다.

> **핵심 정리**
> - 모듈 $m = d_0/z$: 기어 크기의 기본 척도
> - Diametral Pitch: $DP = 25.4/m$ (인치 계열)
> - 맞물리는 기어 쌍은 반드시 같은 모듈을 가져야 함

## 2.2 기준원 관련 원의 체계

> **이 섹션에서 배우는 것**
> - 기어의 4개 주요 원(피치원, 기초원, 이끝원, 이뿌리원)의 관계를 이해합니다
> - 이높이 매개변수를 계산할 수 있습니다
> - 전위 계수의 영향을 파악합니다

### 2.2.1 4개 주요 원

기어의 단면을 보면 4개의 동심원이 핵심적인 역할을 합니다.

$$
\begin{aligned}
d_0 &= m \cdot z & &\text{기준원(pitch circle) 지름} \\
d_b &= d_0 \cos(\alpha_0) = mz\cos(\alpha_0) & &\text{기초원(base circle) 지름} \\
d_a &= m(z + 2 + 2x) & &\text{이끝원(addendum circle) 지름} \\
d_f &= m(z - 2.5 + 2x) & &\text{이뿌리원(dedendum circle) 지름}
\end{aligned}
$$

여기서:
- $d_0$: 기준원 지름 [mm] -- 두 기어가 "접촉"하는 기준이 되는 가상의 원
- $d_b$: 기초원 지름 [mm] -- 인볼류트 곡선이 시작되는 원 (M01에서 배운 것)
- $d_a$: 이끝원 지름 [mm] -- 이의 꼭대기가 닿는 원
- $d_f$: 이뿌리원 지름 [mm] -- 이 사이의 골이 닿는 원
- $\alpha_0$: 기준 압력각 [rad] (표준: 20도)
- $x$: 전위 계수(profile shift coefficient) [무차원] (표준 기어: $x = 0$)

**전위 없는 표준 기어** ($x = 0$):

$$
d_a = m(z + 2), \quad d_f = m(z - 2.5)
$$

**예시 계산**: $m = 3$ mm, $z = 20$, $\alpha_0 = 20°$, $x = 0$:

| 원 | 수식 | 값 |
|----|------|----|
| 기준원 | $d_0 = 3 \times 20$ | 60 mm |
| 기초원 | $d_b = 60 \times \cos(20°)$ | 56.38 mm |
| 이끝원 | $d_a = 3 \times (20 + 2)$ | 66 mm |
| 이뿌리원 | $d_f = 3 \times (20 - 2.5)$ | 52.5 mm |

### 2.2.2 이높이 매개변수

$$
\begin{aligned}
h_a &= m(1 + x) & &\text{어덴덤(addendum): 기준원 위 이높이} \\
h_f &= m(1.25 - x) & &\text{디덴덤(dedendum): 기준원 아래 이높이} \\
c &= 0.25m & &\text{클리어런스(clearance): 이뿌리 여유} \\
h &= h_a + h_f = 2.25m & &\text{전체 이높이}
\end{aligned}
$$

여기서:
- $h_a$: 어덴덤 [mm] -- 기준원에서 이끝원까지의 거리
- $h_f$: 디덴덤 [mm] -- 기준원에서 이뿌리원까지의 거리
- $c$: 클리어런스 [mm] -- 맞물리는 기어의 이끝과 이뿌리 사이 간격
- $h$: 전체 이높이 [mm]

클리어런스 계수 0.25는 ISO 54 및 AGMA 표준의 기본값입니다. 이 값은 랙 커터의 팁 반경(tip radius)에 의해 결정되며, 정밀 기어나 고하중 적용에서는 0.20~0.30으로 조정될 수 있습니다.

표준 기어($x = 0$)에서: $h_a = m$, $h_f = 1.25m$

> **시각화**: 4개 원의 관계를 동심원 도해로 확인합니다.

```python
"""
기어의 4개 주요 원(기준원, 기초원, 이끝원, 이뿌리원)을 동심원으로 표시합니다.
m=3, z=20 예시입니다.
"""
import numpy as np
import matplotlib.pyplot as plt

# --- 매개변수 설정 ---
m = 3           # 모듈 [mm]
z = 20          # 잇수
alpha_0 = np.radians(20)  # 압력각 [rad]
x = 0.0         # 전위 계수 (표준)

# --- 원 반지름 계산 ---
r_0 = m * z / 2                        # 기준원
r_b = r_0 * np.cos(alpha_0)            # 기초원
r_a = m * (z + 2 + 2*x) / 2            # 이끝원
r_f = m * (z - 2.5 + 2*x) / 2          # 이뿌리원

# --- 인볼류트 치형 (2개 이만 표시) ---
def involute_tooth(r_b, r_a, r_f, r_0, alpha_0, x, z, n_pts=80):
    """단일 이(tooth)의 양쪽 플랭크 좌표를 반환합니다."""
    t_start = max(0, np.sqrt(max(0, (max(r_f, r_b)/r_b)**2 - 1)))
    t_tip = np.sqrt((r_a/r_b)**2 - 1)
    inv_a0 = np.tan(alpha_0) - alpha_0
    theta_offset = np.pi/(2*z) + inv_a0 + 2*x*np.tan(alpha_0)/z

    t = np.linspace(t_start, t_tip, n_pts)
    x_inv = r_b * (np.cos(t) + t * np.sin(t))
    y_inv = r_b * (np.sin(t) - t * np.cos(t))

    # 오른쪽 플랭크 (회전)
    x_r = x_inv * np.cos(theta_offset) - y_inv * np.sin(theta_offset)
    y_r = x_inv * np.sin(theta_offset) + y_inv * np.cos(theta_offset)

    # 왼쪽 플랭크 (Y축 미러)
    x_l = x_r
    y_l = -y_r

    return x_r, y_r, x_l, y_l

# --- 시각화 ---
fig, ax = plt.subplots(figsize=(9, 9))

# 각 원 그리기
theta = np.linspace(0, 2*np.pi, 360)
circles = [
    (r_a, '이끝원 (addendum)', '#e74c3c', '-'),
    (r_0, '기준원 (pitch)', '#3498db', '--'),
    (r_b, '기초원 (base)', '#2ecc71', ':'),
    (r_f, '이뿌리원 (dedendum)', '#9b59b6', '-.'),
]

for r, name, color, ls in circles:
    ax.plot(r * np.cos(theta), r * np.sin(theta),
            ls, color=color, linewidth=2, label=f'{name}: r={r:.1f}mm')

# 이높이 표시 (화살표)
angle_mark = np.radians(45)
for r, name, color in [(r_a, '$r_a$', '#e74c3c'), (r_0, '$r_0$', '#3498db'),
                         (r_b, '$r_b$', '#2ecc71'), (r_f, '$r_f$', '#9b59b6')]:
    ax.plot(r*np.cos(angle_mark), r*np.sin(angle_mark), 'o', color=color, markersize=6)
    ax.annotate(f'{name}={r:.1f}',
                (r*np.cos(angle_mark), r*np.sin(angle_mark)),
                textcoords="offset points", xytext=(10, 5), fontsize=10, color=color)

# 3개 이 치형 표시
for k in range(3):
    angle_k = k * 2 * np.pi / z
    xr, yr, xl, yl = involute_tooth(r_b, r_a, r_f, r_0, alpha_0, x, z)
    c_k, s_k = np.cos(angle_k), np.sin(angle_k)
    ax.plot(xr*c_k - yr*s_k, xr*s_k + yr*c_k, 'k-', linewidth=1.2)
    ax.plot(xl*c_k - yl*s_k, xl*s_k + yl*c_k, 'k-', linewidth=1.2)

# 이높이 치수선
angle_dim = np.radians(150)
ax.annotate('', xy=(r_a*np.cos(angle_dim), r_a*np.sin(angle_dim)),
            xytext=(r_0*np.cos(angle_dim), r_0*np.sin(angle_dim)),
            arrowprops=dict(arrowstyle='<->', color='gray'))
ax.text((r_a+r_0)/2*np.cos(angle_dim)+1, (r_a+r_0)/2*np.sin(angle_dim),
        f'$h_a$={m:.0f}', fontsize=10, color='gray')

ax.annotate('', xy=(r_0*np.cos(angle_dim), r_0*np.sin(angle_dim)),
            xytext=(r_f*np.cos(angle_dim), r_f*np.sin(angle_dim)),
            arrowprops=dict(arrowstyle='<->', color='gray'))
ax.text((r_0+r_f)/2*np.cos(angle_dim)+1, (r_0+r_f)/2*np.sin(angle_dim)-2,
        f'$h_f$={1.25*m:.2f}', fontsize=10, color='gray')

ax.set_aspect('equal')
ax.set_title(f'기어 4개 동심원 (m={m}, z={z}, $\\alpha_0$=20°)', fontsize=14)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.legend(fontsize=10, loc='lower left')
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 4개 원이 동심으로 배치됩니다. 기초원(녹색 점선)은 인볼류트가 시작되는 원이며, 기준원(파란 대시선) 안쪽에 위치합니다. 이끝원(빨간 실선)과 이뿌리원(보라 점쇄선) 사이의 거리가 전체 이높이($2.25m$)입니다. 검은색 곡선은 인볼류트 치형입니다.

> **핵심 정리**
> - 4개 원: 기준원($d_0 = mz$), 기초원($d_b = d_0\cos\alpha_0$), 이끝원($d_a$), 이뿌리원($d_f$)
> - 이높이: 어덴덤 $h_a = m(1+x)$, 디덴덤 $h_f = m(1.25-x)$, 클리어런스 $c = 0.25m$
> - 전위 계수 $x$가 이끝원/이뿌리원 크기를 변화시킴

## 2.3 피치와 이두께

> **이 섹션에서 배우는 것**
> - 원주 피치와 기초원 피치의 관계를 이해합니다
> - 기준원 위의 이두께와 이틈을 계산할 수 있습니다
> - 백래시 개념을 파악합니다

### 2.3.1 원주 피치

**왜 중요한가**: 피치(pitch)는 인접한 이 사이의 간격을 나타내는 기본 치수입니다. 맞물리는 기어 쌍의 피치가 같아야 원활한 물림이 가능합니다.

**원주 피치(circular pitch)** -- 기준원 위에서 인접한 이의 같은 위치 사이의 호 길이:

$$
p = \pi m
$$

**기초원 피치(base pitch)** -- 기초원 위에서의 피치:

$$
p_b = \pi m \cos(\alpha_0)
$$

기초원 피치는 작용선 위에서 측정한 인접 이 사이의 거리와 같습니다. 이 값은 물림률(contact ratio) 계산에 핵심적으로 사용됩니다.

두 피치의 관계:

$$
p_b = p \cos(\alpha_0)
$$

### 2.3.2 이두께와 이틈

**기준원 위의 이두께(tooth thickness)** $s_0$:

$$
s_0 = m\left(\frac{\pi}{2} + 2x\tan(\alpha_0)\right)
$$

여기서:
- $s_0$: 기준원 위 이두께(원호 길이) [mm]
- $x$: 전위 계수 [무차원]

표준 기어($x = 0$): $s_0 = \pi m / 2 = p / 2$, 즉 이두께와 이틈이 정확히 절반씩입니다.

**이틈(space width)** $e_0$:

$$
e_0 = p - s_0
$$

표준 기어에서: $e_0 = \pi m / 2 = s_0$

### 2.3.3 임의 반지름에서의 이두께

기준원이 아닌 임의 반지름 $r$ (지름 $d$)의 원에서 이두께 $s$:

$$
s = d\left(\frac{s_0}{d_0} + \text{inv}(\alpha_0) - \text{inv}(\alpha_r)\right)
$$

여기서 $\alpha_r = \arccos(r_b / r)$은 반지름 $r$에서의 압력각입니다 (M01에서 배운 공식).

이 수식은 이끝원에서의 이두께를 구할 때 특히 중요합니다. 이끝 이두께가 너무 작으면 이가 뾰족해져서 깨지기 쉽습니다 (--> M04에서 상세히 다룸).

### 2.3.4 백래시

**백래시(backlash)**: 맞물린 기어 쌍에서 이와 이 사이의 의도적인 틈새입니다.

이론적으로 이두께 $s_0 = p/2$이면 백래시가 0이지만, 실제로는:
- 열팽창 보상
- 윤활유 통로 확보
- 조립 공차 수용

을 위해 약간의 백래시를 둡니다.

> **핵심 정리**
> - 원주 피치: $p = \pi m$ (기준원 위)
> - 기초원 피치: $p_b = \pi m \cos(\alpha_0)$ (작용선 위)
> - 이두께: $s_0 = m(\pi/2 + 2x\tan\alpha_0)$
> - 백래시: 맞물린 기어 이 사이의 의도적 틈새

## 2.4 물림 기본 개념

> **이 섹션에서 배우는 것**
> - 중심 거리를 계산할 수 있습니다
> - 물림률(contact ratio)의 개념을 이해합니다
> - 작용선과 물림 호의 관계를 파악합니다

### 2.4.1 중심 거리

**왜 중요한가**: 중심 거리(center distance)는 두 기어 축 사이의 거리로, 기어박스 설계의 핵심 치수입니다.

**표준 중심 거리** ($x_1 = x_2 = 0$):

$$
a_0 = \frac{m(z_1 + z_2)}{2}
$$

여기서:
- $a_0$: 표준 중심 거리 [mm]
- $z_1, z_2$: 각 기어의 잇수

**전위 기어 쌍의 실제 중심 거리**:

전위가 적용된 기어 쌍에서는 물림 압력각 $\alpha_w$이 변하고, 중심 거리도 달라집니다.

$$
\text{inv}(\alpha_w) = \text{inv}(\alpha_0) + \frac{2(x_1 + x_2)\tan(\alpha_0)}{z_1 + z_2}
$$

$$
a_w = \frac{m(z_1 + z_2)\cos(\alpha_0)}{2\cos(\alpha_w)}
$$

여기서:
- $\alpha_w$: 물림 압력각(working pressure angle) [rad]
- $a_w$: 실제 중심 거리 [mm]
- $x_1, x_2$: 각 기어의 전위 계수

$\text{inv}(\alpha_w)$ 값을 알면 $\alpha_w$를 구해야 하는데, inv 함수의 역함수는 해석적으로 존재하지 않으므로 수치적으로 풀어야 합니다 (--> M04 S4.4에서 상세히 다룸).

### 2.4.2 물림률 개념

**물림률(contact ratio)** $\varepsilon$: 동시에 맞물려 있는 이의 평균 개수입니다.

- $\varepsilon = 1.0$: 항상 정확히 1쌍의 이만 접촉 (최소 조건)
- $\varepsilon > 1.0$: 대부분의 시간에 2쌍 이상이 접촉 (더 부드러운 전동)
- $\varepsilon \geq 1.2$: 권장 최소값 (소음, 진동 최소화)

물림률의 정확한 수식은 --> [M04: 전위 및 검증] S4.5에서 다룹니다.

### 2.4.3 작용선과 물림 호

두 기어가 맞물릴 때 접촉점은 **작용선(line of action)** 위를 이동합니다.

- **작용선**: 두 기초원의 공통 내접선
- **물림 호(arc of action)**: 접촉이 시작되는 점부터 끝나는 점까지의 구간
- **접근 호(arc of approach)**: 피치점 이전의 물림 구간
- **이탈 호(arc of recess)**: 피치점 이후의 물림 구간

작용선의 길이(물림 길이)를 기초원 피치 $p_b$로 나누면 물림률이 됩니다.

> **시각화**: 기어 쌍의 물림 관계를 도해합니다.

```python
"""
기어 쌍의 물림 도해: 두 기어의 기준원, 기초원, 작용선을 보여줍니다.
"""
import numpy as np
import matplotlib.pyplot as plt

# --- 매개변수 설정 ---
m = 3           # 모듈 [mm]
z1, z2 = 20, 30 # 잇수
alpha_0 = np.radians(20)  # 압력각 [rad]

# --- 기어 원 계산 ---
r01 = m * z1 / 2  # 피니언 기준원
r02 = m * z2 / 2  # 기어 기준원
rb1 = r01 * np.cos(alpha_0)
rb2 = r02 * np.cos(alpha_0)
ra1 = r01 + m
ra2 = r02 + m
a = r01 + r02  # 중심 거리

# --- 시각화 ---
fig, ax = plt.subplots(figsize=(12, 8))
theta = np.linspace(0, 2*np.pi, 360)

# 피니언 (왼쪽, 원점)
for r, ls, lbl in [(ra1, '-', f'이끝원 r={ra1:.1f}'),
                     (r01, '--', f'기준원 r={r01:.1f}'),
                     (rb1, ':', f'기초원 r={rb1:.1f}')]:
    ax.plot(r*np.cos(theta), r*np.sin(theta), ls, color='#3498db', alpha=0.6)
ax.plot(0, 0, 'b+', markersize=12)
ax.text(-3, -5, f'피니언\nz={z1}', fontsize=11, color='#3498db', ha='center')

# 기어 (오른쪽, 중심거리만큼 이동)
for r, ls, lbl in [(ra2, '-', f'이끝원 r={ra2:.1f}'),
                     (r02, '--', f'기준원 r={r02:.1f}'),
                     (rb2, ':', f'기초원 r={rb2:.1f}')]:
    ax.plot(a + r*np.cos(theta), r*np.sin(theta), ls, color='#e74c3c', alpha=0.6)
ax.plot(a, 0, 'r+', markersize=12)
ax.text(a-3, -5, f'기어\nz={z2}', fontsize=11, color='#e74c3c', ha='center')

# 피치점 P
P_x = r01  # 기준원 위 접촉점 (중심거리 직선 위)
ax.plot(P_x, 0, 'ko', markersize=10, zorder=5)
ax.annotate('P (피치점)', (P_x, 0), textcoords="offset points",
            xytext=(5, 15), fontsize=11, fontweight='bold')

# 작용선 (두 기초원의 공통 접선)
# 작용선은 피치점을 지나고 alpha_0 각도로 기울어짐
line_len = 40
ax.plot([P_x - line_len*np.cos(alpha_0), P_x + line_len*np.cos(alpha_0)],
        [-line_len*np.sin(alpha_0), line_len*np.sin(alpha_0)],
        'g-', linewidth=2.5, alpha=0.7, label=f'작용선 ($\\alpha_0={20}°$)')

# 중심거리 표시
ax.annotate('', xy=(a, -r02-8), xytext=(0, -r02-8),
            arrowprops=dict(arrowstyle='<->', color='gray', lw=1.5))
ax.text(a/2, -r02-12, f'중심거리 a = {a:.0f} mm', fontsize=11,
        ha='center', color='gray')

ax.set_aspect('equal')
ax.set_title(f'기어 쌍 물림 도해 (m={m}, z1={z1}, z2={z2})', fontsize=14)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.legend(fontsize=11, loc='upper left')
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 파란색 원이 피니언, 빨간색 원이 기어입니다. 두 기준원(대시선)이 피치점 P에서 만나며, 녹색 작용선이 피치점을 지나 $\alpha_0 = 20°$로 기울어져 있습니다. 작용선은 두 기초원(점선)에 접합니다. 이 작용선 위에서 기어 이의 접촉이 일어납니다.

### 2.4.4 모듈별 기어 크기 비교

> **시각화**: 같은 잇수에서 모듈에 따른 기어 크기 변화를 비교합니다.

```python
"""
모듈별 기어 크기 비교: 동일 잇수(z=20)에서 m=1, 2, 3, 5의 기어 크기를 비교합니다.
"""
import numpy as np
import matplotlib.pyplot as plt

# --- 매개변수 설정 ---
z = 20
alpha_0 = np.radians(20)
modules = [1, 2, 3, 5]
colors = ['#3498db', '#2ecc71', '#e74c3c', '#9b59b6']

# --- 시각화 ---
fig, ax = plt.subplots(figsize=(10, 10))
theta = np.linspace(0, 2*np.pi, 360)

for m_val, color in zip(modules, colors):
    r_a = m_val * (z + 2) / 2
    r_0 = m_val * z / 2
    r_f = m_val * (z - 2.5) / 2

    ax.plot(r_a*np.cos(theta), r_a*np.sin(theta),
            '-', color=color, linewidth=2,
            label=f'm={m_val}: $d_0$={2*r_0:.0f}, $d_a$={2*r_a:.0f}mm')
    ax.plot(r_f*np.cos(theta), r_f*np.sin(theta),
            '--', color=color, linewidth=1, alpha=0.5)

ax.set_aspect('equal')
ax.set_title(f'모듈별 기어 크기 비교 (z={z}, 실선=이끝원, 점선=이뿌리원)', fontsize=13)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.legend(fontsize=11, loc='lower left')
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 잇수는 같지만 모듈이 커지면 기어 전체 크기가 비례하여 커집니다. $m = 5$인 기어는 $m = 1$인 기어보다 지름이 5배 큽니다. 이 비교를 통해 모듈이 "기어 스케일의 척도"임을 직관적으로 확인할 수 있습니다.

> **핵심 정리**
> - 표준 중심 거리: $a_0 = m(z_1 + z_2)/2$
> - 물림 압력각: $\text{inv}(\alpha_w) = \text{inv}(\alpha_0) + 2(x_1+x_2)\tan(\alpha_0)/(z_1+z_2)$
> - 전위 중심 거리: $a_w = m(z_1+z_2)\cos(\alpha_0) / (2\cos(\alpha_w))$
> - 물림률 $\varepsilon \geq 1.2$ 권장
> - 작용선: 접촉점이 이동하는 경로 = 두 기초원의 공통 접선
