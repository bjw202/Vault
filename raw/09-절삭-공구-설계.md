## 9.1 포락선(Envelope) 이론

> **이 섹션에서 배우는 것**
> - 포락선의 수학적 정의와 기어 절삭에서의 역할
> - 맞물림 방정식(equation of meshing)의 유도
> - 이산화 시뮬레이션의 원리

### 9.1.1 왜 포락선 이론이 중요한가

기어 이(tooth)를 만드는 모든 절삭 공정의 핵심 원리가 바로 **포락선(envelope)** 이론입니다. 공구가 일정한 운동을 하면서 기어 블랭크를 깎아낼 때, 공구의 여러 위치에서의 형상들이 겹쳐서 최종적으로 남는 윤곽선이 곧 기어 치형이 됩니다. 이 윤곽선이 바로 곡선족의 포락선입니다.

직관적으로 비유하자면, 공원에서 스프링클러가 회전하며 물을 뿌릴 때, 물이 닿는 가장 바깥 경계선이 포락선입니다. 절삭 공구도 마찬가지로 여러 위치에서 깎은 궤적의 가장 바깥 경계가 기어 치형이 됩니다.

### 9.1.2 포락선의 수학적 정의

시간 파라미터 $t$에 따라 변하는 **곡선족(family of curves)** $F(x, y, t) = 0$이 있을 때, 포락선은 다음 두 방정식의 연립해입니다:

$$F(x, y, t) = 0 \quad \text{와} \quad \frac{\partial F}{\partial t}(x, y, t) = 0$$

여기서:
- $F(x, y, t) = 0$: 파라미터 $t$에서의 공구 형상
- $\frac{\partial F}{\partial t} = 0$: 곡선이 접하는 조건 (포락 조건)

3차원 곡면족으로 확장하면, 공구 표면 $\mathbf{r}_2(u, v, \phi)$가 기어 프레임에서의 좌표일 때, 포락선 조건은 야코비안(Jacobian)의 행렬식이 0이 되는 것입니다 [Litvin, 1994]:

$$\det\!\left[\frac{\partial \mathbf{r}_2}{\partial u},\ \frac{\partial \mathbf{r}_2}{\partial v},\ \frac{\partial \mathbf{r}_2}{\partial \phi}\right] = 0$$

### 9.1.3 맞물림 방정식

위의 포락 조건은 다음과 같은 물리적 의미로 재표현됩니다:

$$\mathbf{N}_2 \cdot \mathbf{v}_{\text{rel}}^{(12)} = 0$$

여기서:
- $\mathbf{N}_2$: 공구 표면의 법선 벡터(normal vector)
- $\mathbf{v}_{\text{rel}}^{(12)}$: 공구와 기어의 상대 속도 벡터

이것이 바로 **맞물림 방정식(equation of meshing)**입니다. 물리적으로는 "접촉점에서 공통 법선 방향의 상대 속도가 0"이라는 뜻으로, 접촉점에서 공구와 기어가 서로 파고들지도, 벌어지지도 않는다는 조건입니다.

### 9.1.4 이산화 시뮬레이션

포락선을 해석적으로 구하기 어려울 때는 **이산화 시뮬레이션(discretized simulation)**을 사용합니다:

1. 기어 블랭크를 2D 격자(비트맵)로 표현합니다 (재료 있음 = True)
2. 공구를 충분히 작은 회전 단계 $\Delta\phi$로 이동합니다
3. 각 단계에서 공구 영역에 해당하는 격자 셀을 False로 변경합니다 (부울 차집합)
4. 최종 격자의 True/False 경계가 기어 치형입니다

> **시각화**: 포락선 이론의 핵심 개념 -- 운동하는 곡선 가족과 그 포락선

```python
"""
[이 코드가 보여주는 것] 포락선 생성 과정: 원이 직선 위를 구르면서 만드는 포락선
"""
import numpy as np
import matplotlib.pyplot as plt

# --- 매개변수 설정 ---
n_positions = 12   # 원의 위치 개수
R = 15.0           # 구르는 원의 반경 [mm]
r_cutter = 5.0     # 커터(작은 원) 반경 [mm]

# --- 계산 ---
fig, ax = plt.subplots(figsize=(10, 6))

# 큰 원(기어 블랭크) 위를 작은 원(커터)이 굴러감
theta_gear = np.linspace(0, 2 * np.pi, 200)

# 기어 블랭크 (큰 원)
ax.plot(R * np.cos(theta_gear), R * np.sin(theta_gear),
        'b-', linewidth=2, label='기어 블랭크')

# 커터의 여러 위치
colors = plt.cm.Reds(np.linspace(0.3, 0.9, n_positions))
for i in range(n_positions):
    phi = 2 * np.pi * i / n_positions  # 커터 위치각
    cx = (R + r_cutter) * np.cos(phi)  # 커터 중심 x
    cy = (R + r_cutter) * np.sin(phi)  # 커터 중심 y
    
    theta_c = np.linspace(0, 2 * np.pi, 100)
    ax.plot(cx + r_cutter * np.cos(theta_c),
            cy + r_cutter * np.sin(theta_c),
            '-', color=colors[i], alpha=0.5, linewidth=0.8)

# 포락선 (이 경우 동심원)
env_r = R + 2 * r_cutter  # 외접 포락선
ax.plot(env_r * np.cos(theta_gear), env_r * np.sin(theta_gear),
        'r--', linewidth=2, label='포락선 (envelope)')

# --- 시각화 ---
ax.set_aspect('equal')
ax.set_title('포락선 개념: 커터 궤적의 포락선이 기어 치형을 결정', fontsize=13)
ax.legend(fontsize=11)
ax.grid(True, alpha=0.3)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
plt.tight_layout()
plt.show()
```

> **결과 해석**: 빨간 파선이 포락선으로, 여러 위치의 커터(원) 궤적들이 만드는 가장 바깥 경계선입니다. 실제 기어 절삭에서는 커터가 인볼류트 치형을 가지며, 포락선이 기어 이(tooth)의 형상을 결정합니다.

> **핵심 정리**
> - 기어 치형은 공구 운동 궤적의 **포락선**으로 정의됩니다
> - 맞물림 방정식 $\mathbf{N}_2 \cdot \mathbf{v}_{\text{rel}} = 0$이 접촉점을 결정합니다
> - 해석적 풀이가 어려우면 **이산화 시뮬레이션**으로 치형을 생성합니다

## 9.2 호브(Hob) 설계

> **이 섹션에서 배우는 것**
> - 호브의 기본 구조와 기어 절삭 원리
> - 리드각(lead angle) 계산
> - 호브 기준 프로파일과 3D 좌표 방정식
> - 호빙 인덱싱 수학

### 9.2.1 왜 호브가 중요한가

**호브(hob)**는 기어 대량 생산에서 가장 널리 사용되는 절삭 공구입니다. 호브는 본질적으로 "절삭 날이 달린 웜(worm)"으로, 나선형으로 배치된 랙 치형(rack tooth profile)의 집합체입니다. 호브와 기어 블랭크가 **연속적으로 동기 회전**하면서 기어 이를 깎아냅니다.

### 9.2.2 호브-기어 회전 동기 관계

호브와 기어 블랭크의 회전 속도 비는 다음과 같습니다:

$$\frac{\dot{\phi}_w}{\dot{\phi}_h} = \frac{N_o}{z}$$

여기서:
- $\dot{\phi}_w$: 공작물(기어 블랭크) 회전 속도
- $\dot{\phi}_h$: 호브 회전 속도
- $N_o$: 호브 스레드(thread) 수
- $z$: 기어 잇수

예를 들어, 잇수 $z=32$인 기어를 단선(single-start, $N_o=1$) 호브로 가공하면, 호브가 32번 회전할 때 기어가 1번 회전합니다.

### 9.2.3 리드각(Lead Angle) 계산

호브 리드각은 호브 나선의 기울기를 결정하는 핵심 매개변수입니다:

$$\gamma_o = \arcsin\!\left(\frac{N_o \cdot m_{no}}{d_o}\right)$$

여기서:
- $\gamma_o$: 호브 리드각
- $N_o$: 호브 스레드 수
- $m_{no}$: 호브 법선 모듈(normal module) [mm]
- $d_o$: 호브 피치원 직경 [mm]

**피치 값**(나선 1회전당 축 방향 이동 거리):

$$p = \pi \cdot m_{no}$$

### 9.2.4 스위블각(Swivel Angle)

헬리컬 기어를 호빙 가공할 때, 호브를 기울여야 합니다. 이 기울임 각도를 **스위블각** $\eta$이라 합니다:

$$\eta = \gamma_o \pm \beta$$

여기서:
- $\beta$: 기어의 나선각(helix angle)
- 동일 방향 나선: $-$ (뺄셈)
- 반대 방향 나선: $+$ (덧셈)
- **스퍼 기어의 경우**: $\eta = \gamma_o$ (리드각만큼 틸트)

### 9.2.5 호브 기준 프로파일

호브의 법선 단면(normal section)은 기본 **랙(rack) 치형**입니다. 피치선을 원점으로 한 좌표는 다음과 같습니다:

| 구간 | X 좌표 | Y 좌표 | 설명 |
|------|--------|--------|------|
| 플랭크 (직선) | $\pm(h_f - t) \tan\alpha_n$ | $h_f - t$ | $t$: 피치선에서 거리 |
| 이끝 필릿 | $x_f + r_f \sin\theta$ | $y_f + r_f \cos\theta$ | $r_f$: 필릿 반경 |
| 이끝 평탄부 | $x_t$ | $h_a$ | 상수 |

여기서 $\alpha_n$은 법선 압력각, $h_a$는 어덴덤(addendum), $h_f$는 디덴덤(dedendum)입니다.

### 9.2.6 호브 3D 좌표 파라메트릭 방정식

호브 이면의 3D 좌표는 법선 단면 프로파일을 나선으로 배치하여 얻습니다:

$$\mathbf{r}_{hob}(u, \phi_h) = \begin{pmatrix}
\left(\frac{d_o}{2} - u\right) \cos\phi_h \\
\left(\frac{d_o}{2} - u\right) \sin\phi_h \\
u \tan\alpha_n \sin\gamma_o + \phi_h \cdot \frac{p}{2\pi} \cos\gamma_o
\end{pmatrix}$$

여기서:
- $u$: 법선 단면에서의 반경 방향 파라미터, $u \in [-h_f, h_a]$
- $\phi_h$: 호브 회전각

### 9.2.7 호빙 인덱싱

헬리컬 기어 호빙에서는 기본 인덱스 비율에 나선 보정항이 추가됩니다:

$$\frac{n_{gear}}{n_{hob}} = \frac{N_o}{z} \pm \frac{v_{feed} \cdot N_o}{\pi \cdot m_n \cdot z \cdot \tan\beta}$$

여기서:
- 우변 첫째 항: 기본 인덱스 비율
- 우변 둘째 항: 나선 가공을 위한 **차동(differential) 보정**
- $v_{feed}$: 호브 축 방향 이송 속도
- $\beta$: 기어 나선각

**변화 기어(change gear) 선택**:

$$\frac{a}{b} = \frac{K \cdot N_o}{z}$$

여기서 $K$는 머신 상수(통상 90 또는 40)이며, 정수비로 근사합니다.

> **시각화**: 호브 3D 형상 (헬리컬 홈 포함)

```python
"""
[이 코드가 보여주는 것] 호브의 3D 형상 — 랙 치형이 나선을 따라 배치된 구조
"""
import numpy as np
import matplotlib.pyplot as plt

# --- 매개변수 설정 ---
m = 3.0             # 모듈 [mm]
alpha_n = np.radians(20)  # 법선 압력각
d_o = 60.0          # 호브 직경 [mm]
N_o = 1             # 스레드 수
h_a = m             # 어덴덤
h_f = 1.25 * m      # 디덴덤
p = np.pi * m       # 피치
gamma_o = np.arcsin(N_o * m / d_o)  # 리드각

# --- 계산: 호브 단면 프로파일 (랙 치형) ---
n_pts = 40
u_vals = np.linspace(-h_f, h_a, n_pts)
# 플랭크 좌표 (직선)
x_profile = u_vals * np.tan(alpha_n)
y_profile = u_vals

# --- 3D 나선 배치 ---
n_theta = 200
n_turns = 3
phi_h = np.linspace(-n_turns * np.pi, n_turns * np.pi, n_theta)

fig = plt.figure(figsize=(10, 8))
ax = fig.add_subplot(111, projection='3d')

# 여러 회전 위치에서 랙 프로파일 표시
for i in range(0, n_theta, 10):
    ph = phi_h[i]
    r_outer = d_o / 2 - u_vals  # 반경 방향
    x_3d = r_outer * np.cos(ph)
    y_3d = r_outer * np.sin(ph)
    z_3d = x_profile * np.sin(gamma_o) + ph * p / (2 * np.pi) * np.cos(gamma_o)
    ax.plot(x_3d, y_3d, z_3d, 'b-', alpha=0.3, linewidth=0.5)

# 나선 경로 (기준원)
r_ref = d_o / 2
x_helix = r_ref * np.cos(phi_h)
y_helix = r_ref * np.sin(phi_h)
z_helix = phi_h * p / (2 * np.pi) * np.cos(gamma_o)
ax.plot(x_helix, y_helix, z_helix, 'r-', linewidth=1.5, label='기준 나선')

# --- 시각화 ---
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.set_zlabel('Z [mm]')
ax.set_title('호브 3D 형상 (랙 치형의 나선 배치)', fontsize=13)
ax.legend()
ax.view_init(elev=20, azim=45)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 파란 선들이 호브의 절삭 날 프로파일(랙 치형)이며, 나선을 따라 배치되어 있습니다. 빨간 선은 기준 나선(reference helix)입니다. 호브가 회전하면서 이 랙 치형들이 기어 블랭크에 인볼류트 치형을 깎아냅니다.

> **핵심 정리**
> - 호브는 나선으로 배치된 랙 치형의 집합체입니다
> - 리드각 $\gamma_o = \arcsin(N_o \cdot m_{no} / d_o)$
> - 호브-기어 회전비: $\dot{\phi}_w / \dot{\phi}_h = N_o / z$
> - 헬리컬 기어 가공 시 스위블각 $\eta = \gamma_o \pm \beta$ 적용

## 9.3 피니언 커터 (Fetvaci 6-영역 모델)

> **이 섹션에서 배우는 것**
> - 피니언 커터의 기본 원리 (기어 쌍과 동일한 수학)
> - Fetvaci (2010) 6-영역 모델의 각 영역
> - 좌표 변환 행렬 $\mathbf{M}_{gc}$ (Fetvaci Eq.12)
> - 맞물림 방정식과 에피트로코이드 필릿

### 9.3.1 왜 피니언 커터가 중요한가

**피니언 커터(pinion cutter / shaper cutter)**는 절삭 날을 가진 기어로, 커터와 공작물이 마치 기어 쌍처럼 맞물리며 치형을 깎습니다. 호브로는 가공할 수 없는 **내접 기어**를 만들 수 있다는 점에서 특히 중요합니다.

커터-공작물 쌍은 수학적으로 평기어 쌍과 동일하게 동작합니다:

$$\frac{\phi_g}{\phi_c} = \frac{N_c}{N_g}$$

여기서 $\phi_c$는 커터 회전각, $\phi_g$는 기어 회전각, $N_c$와 $N_g$는 각각 커터와 기어의 잇수입니다.

### 9.3.2 6-영역 커터 치형 모델

Fetvaci (2010)는 커터 치형을 6개 구간(region)으로 나누었습니다:

| 영역 (Region) | 형태 | 생성하는 기어 부위 |
|:---:|------|:---:|
| 1, 6 | 인볼류트 곡선 | 기어 플랭크 |
| 2, 5 | 원호(circular arc) | 기어 필릿 |
| 3, 4 | 직선 (topland) | 기어 이뿌리 평탄부 |

**인볼류트 구간(Region 1)의 위치 벡터** (커터 좌표계 $S_c$):

$$\mathbf{R}_{c}^{1} = \begin{pmatrix}
r_b\cos(\delta - \psi) - r_b\,\delta\sin(\delta - \psi) \\
r_b\sin(\delta - \psi) + r_b\,\delta\cos(\delta - \psi)
\end{pmatrix}$$

여기서:
- $r_b = r_c \cos\alpha$: 커터 기초원 반지름
- $\delta$: 인볼류트 파라미터, $\delta \in [0, \delta_{max}]$
- $\psi$: 기초원 위 이두께 반각

**필릿 구간(Region 2)의 위치 벡터**:

$$\mathbf{R}_{c}^{2} = \begin{pmatrix}
x_A + r_f(\sin(\mu + \mu_0) - \sin\mu_0) \\
y_A - r_f(\cos(\mu + \mu_0) - \cos\mu_0)
\end{pmatrix}$$

여기서:
- $(x_A, y_A)$: 인볼류트 구간 끝점 좌표
- $r_f$: 커터 이끝 필릿 반경
- $\mu$: 필릿 파라미터

### 9.3.3 좌표 변환 행렬 $\mathbf{M}_{gc}$

커터 좌표계($S_c$)에서 기어 좌표계($S_g$)로의 변환은 **Fetvaci (2010) Eq.12**를 사용합니다[^1]:

$$\mathbf{M}_{gc} = \begin{pmatrix}
\cos(\phi_g + \phi_c) & \sin(\phi_g + \phi_c) & r_c\sin\phi_g - r_g\sin\phi_c \\
-\sin(\phi_g + \phi_c) & \cos(\phi_g + \phi_c) & -r_c\cos\phi_g + r_g\cos\phi_c \\
0 & 0 & 1
\end{pmatrix}$$

여기서:
- $\phi_g = (N_c / N_g) \cdot \phi_c$: 롤링 구속 조건
- $r_c = m \cdot N_c / 2$: 커터 피치원 반경
- $r_g = m \cdot N_g / 2$: 기어 피치원 반경

기어 치형의 궤적은 다음과 같이 계산됩니다:

$$\mathbf{R}_g^i(\delta, \phi_c) = \mathbf{M}_{gc}(\phi_c) \cdot \mathbf{R}_c^i(\delta)$$

[^1]: [참고] 소스 문서에는 두 가지 변환 행렬이 제시되어 있으나, 프로젝트 표준에 따라 Fetvaci Eq.12 (정규 버전)만 사용합니다. 첫 번째 행렬에는 오류가 있습니다.

### 9.3.4 맞물림 방정식 (커터 좌표계 기준)

창성된 기어 표면은 두 조건을 동시에 만족해야 합니다:

1. **궤적 방정식**: $\mathbf{R}_g^i = \mathbf{M}_{gc} \cdot \mathbf{R}_c^i$
2. **맞물림 방정식**: 접촉점에서 공통 법선이 피치점(I)을 통과

$$n_{cx}^i \cdot (Y_c^I - y_c^i) - n_{cy}^i \cdot (X_c^I - x_c^i) = 0$$

여기서:
- $(X_c^I, Y_c^I) = (r_c\cos\phi_c,\ r_c\sin\phi_c)$: 피치점 I의 좌표
- $(x_c^i, y_c^i)$: 커터 표면 좌표
- $(n_{cx}^i, n_{cy}^i)$: 커터 법선 벡터 성분

파라미터 $\delta$와 $\phi_c$에 대해 이 두 방정식을 연립 풀면 기어 치형 좌표를 얻습니다. 수치적으로는 이분법(bisection) 또는 Newton-Raphson 반복법을 사용합니다.

### 9.3.5 에피트로코이드 필릿

커터 이끝의 원형 모서리가 그리는 **에피트로코이드(epitrochoid)** 곡선이 기어 필릿을 결정합니다.

**1차 트로코이드** (커터 이끝 원호 중심 $E$의 궤적):

$$\begin{pmatrix} x_T \\ y_T \end{pmatrix} = \begin{pmatrix}
(r_c + r_g)\cos\phi_g - r_c\cos\!\left(\frac{r_c + r_g}{r_c}\phi_c + \phi_c\right) + x_E\cos(\phi_g + \phi_c) - y_E\sin(\phi_g + \phi_c) \\
(r_c + r_g)\sin\phi_g - r_c\sin\!\left(\frac{r_c + r_g}{r_c}\phi_c + \phi_c\right) + x_E\sin(\phi_g + \phi_c) + y_E\cos(\phi_g + \phi_c)
\end{pmatrix}$$

**2차 트로코이드** (실제 필릿 — 1차 트로코이드의 오프셋 곡선):

$$\begin{pmatrix} x_F \\ y_F \end{pmatrix} = \begin{pmatrix} x_T \\ y_T \end{pmatrix} + r_f \cdot \frac{(\dot{y}_T, -\dot{x}_T)}{\sqrt{\dot{x}_T^2 + \dot{y}_T^2}}$$

여기서 $r_f$는 이끝 필릿 반경, $(\dot{x}_T, \dot{y}_T) = d(x_T, y_T)/d\phi_c$입니다.

> **시각화**: Fetvaci 6-영역 커터 프로파일 (영역별 색상 구분)

```python
"""
[이 코드가 보여주는 것] Fetvaci 6-영역 피니언 커터 치형 프로파일
"""
import numpy as np
import matplotlib.pyplot as plt

# --- 매개변수 설정 ---
m = 3.0               # 모듈 [mm]
N_c = 20              # 커터 잇수
alpha_0 = np.radians(20)  # 압력각

r_c = m * N_c / 2     # 커터 피치원 반경
r_bc = r_c * np.cos(alpha_0)  # 커터 기초원 반경
r_ac = r_c + m        # 커터 이끝원 반경
r_fc = r_c - 1.25 * m # 커터 이뿌리원 반경
r_f = 0.38 * m        # 필릿 반경

# 이두께 반각
inv_alpha = np.tan(alpha_0) - alpha_0
psi_c = np.pi / (2 * N_c) + inv_alpha

# --- Region 1: 인볼류트 플랭크 (우측) ---
delta_max = np.sqrt(max(0, (r_ac / r_bc)**2 - 1))
delta = np.linspace(0, delta_max, 50)
angle = delta - psi_c
x_inv = r_bc * (np.cos(angle) - delta * np.sin(angle))
y_inv = r_bc * (np.sin(angle) + delta * np.cos(angle))

# --- Region 6: 인볼류트 플랭크 (좌측, 대칭) ---
x_inv_l = x_inv
y_inv_l = -y_inv

# --- Region 3, 4: 이뿌리 직선 (topland) ---
theta_top = np.linspace(-np.pi/(2*N_c)*0.5, np.pi/(2*N_c)*0.5, 20)
x_top = r_fc * np.cos(theta_top + np.pi/(2*N_c))
y_top = r_fc * np.sin(theta_top + np.pi/(2*N_c))

# --- Region 2: 필릿 (우측) ---
mu_range = np.linspace(0, np.pi/2 - alpha_0, 20)
x_A, y_A = x_inv[-1], y_inv[-1]
mu_0 = 0.0
x_fillet = x_A + r_f * (np.sin(mu_range + mu_0) - np.sin(mu_0))
y_fillet = y_A - r_f * (np.cos(mu_range + mu_0) - np.cos(mu_0))

# --- 시각화 ---
fig, ax = plt.subplots(figsize=(8, 8))

# 각 원 표시
theta_full = np.linspace(0, 2*np.pi, 200)
ax.plot(r_c * np.cos(theta_full), r_c * np.sin(theta_full), 
        'g--', alpha=0.3, label=f'피치원 r={r_c:.1f}')
ax.plot(r_bc * np.cos(theta_full), r_bc * np.sin(theta_full), 
        'b--', alpha=0.3, label=f'기초원 r={r_bc:.1f}')
ax.plot(r_ac * np.cos(theta_full), r_ac * np.sin(theta_full), 
        'r--', alpha=0.3, label=f'이끝원 r={r_ac:.1f}')
ax.plot(r_fc * np.cos(theta_full), r_fc * np.sin(theta_full), 
        'm--', alpha=0.3, label=f'이뿌리원 r={r_fc:.1f}')

# 영역별 플롯
ax.plot(x_inv, y_inv, 'b-', linewidth=2.5, label='Region 1: 인볼류트 (우)')
ax.plot(x_inv_l, y_inv_l, 'c-', linewidth=2.5, label='Region 6: 인볼류트 (좌)')
ax.plot(x_fillet, y_fillet, 'r-', linewidth=2.5, label='Region 2: 필릿')
ax.plot(x_top, y_top, 'k-', linewidth=2.5, label='Region 3-4: 이뿌리 직선')

ax.set_aspect('equal')
ax.set_title('Fetvaci 6-영역 피니언 커터 치형', fontsize=13)
ax.legend(fontsize=9, loc='lower left')
ax.grid(True, alpha=0.3)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')

# 확대 영역
ax.set_xlim(r_fc - 2, r_ac + 2)
ax.set_ylim(-15, 15)
plt.tight_layout()
plt.show()
```

> **핵심 정리**
> - 피니언 커터는 기어 쌍과 동일한 맞물림 원리로 작동합니다
> - Fetvaci (2010) 6-영역 모델: 인볼류트 + 원호 필릿 + 이뿌리 직선
> - 좌표 변환 $\mathbf{M}_{gc}$ (Eq.12)로 커터 치형을 기어 좌표계로 변환합니다
> - 에피트로코이드 필릿: 커터 이끝 코너의 궤적이 기어 이뿌리 형상을 결정합니다

## 9.4 피니언 커터에 의한 기어 프로파일 생성

> **이 섹션에서 배우는 것**
> - 피니언 커터 창성 운동의 구현 알고리즘
> - 이산화 포락선 엔진의 원리와 구현
> - 맞물림 방정식의 수치 해법

### 9.4.1 창성 운동 스캔 알고리즘

피니언 커터로 기어 치형을 생성하는 알고리즘은 다음 5단계로 구성됩니다:

1. **커터 파라미터 계산**: 기초원, 이끝원, 이뿌리원 반경
2. **$\phi_c$ 범위 결정**: 한 이 피치각 $\pm(\pi/N_g + \pi/N_c)$ 구간
3. **각 $\phi_c$에서 맞물림 방정식 풀기**: $\delta$에 대해 이분법으로 접촉점 탐색
4. **기어 좌표 변환**: 해당 $(\delta, \phi_c)$ 쌍을 $\mathbf{M}_{gc}$로 변환
5. **필릿 구간**: 커터 필릿 원호의 에피트로코이드 스캔

> **시각화**: 피니언 커터 창성 운동으로 생성된 기어 치형

```python
"""
[이 코드가 보여주는 것] 피니언 커터 창성 운동: M_gc 변환으로 기어 치형 생성
"""
import numpy as np
import matplotlib.pyplot as plt
import math

# --- 매개변수 설정 ---
m = 2.0               # 모듈 [mm]
N_c = 20              # 커터 잇수
N_g = 40              # 기어 잇수
alpha_0 = np.radians(20)  # 압력각

r_c = m * N_c / 2     # 커터 피치원 반경
r_g = m * N_g / 2     # 기어 피치원 반경
r_bc = r_c * np.cos(alpha_0)  # 커터 기초원 반경
r_ac = r_c + m        # 커터 이끝원 반경

# 이두께 반각
inv_alpha = math.tan(alpha_0) - alpha_0
psi_c = math.pi / (2 * N_c) + inv_alpha

# --- M_gc 변환 함수 ---
def M_gc(phi_c):
    """Fetvaci Eq.12 변환 행렬"""
    phi_g = (N_c / N_g) * phi_c
    c = math.cos(phi_g + phi_c)
    s = math.sin(phi_g + phi_c)
    tx = r_c * math.sin(phi_g) - r_g * math.sin(phi_c)
    ty = -r_c * math.cos(phi_g) + r_g * math.cos(phi_c)
    return np.array([[c, s, tx], [-s, c, ty], [0, 0, 1]])

# --- 맞물림 방정식 풀이 ---
def meshing_eq(delta, phi_c):
    """맞물림 방정식 값"""
    angle = delta - psi_c
    x_c = r_bc * (math.cos(angle) - delta * math.sin(angle))
    y_c = r_bc * (math.sin(angle) + delta * math.cos(angle))
    n_cx = -math.sin(angle)
    n_cy = math.cos(angle)
    X_I = r_c * math.cos(phi_c)
    Y_I = r_c * math.sin(phi_c)
    return n_cx * (Y_I - y_c) - n_cy * (X_I - x_c)

# --- 기어 치형 생성 ---
delta_max = math.sqrt(max(0, (r_ac / r_bc)**2 - 1))
phi_c_half = math.pi / N_c + math.pi / N_g
phi_c_values = np.linspace(-phi_c_half, phi_c_half, 300)

gear_points = []
for phi_c in phi_c_values:
    # 이분법으로 맞물림 방정식 풀기
    try:
        f_lo = meshing_eq(0.001, phi_c)
        f_hi = meshing_eq(delta_max, phi_c)
        if f_lo * f_hi > 0:
            continue
        lo, hi = 0.001, delta_max
        for _ in range(50):
            mid = (lo + hi) / 2
            if meshing_eq(mid, phi_c) * f_lo < 0:
                hi = mid
            else:
                lo = mid
        delta_contact = (lo + hi) / 2
        
        # 커터 좌표 계산
        angle = delta_contact - psi_c
        x_c = r_bc * (math.cos(angle) - delta_contact * math.sin(angle))
        y_c = r_bc * (math.sin(angle) + delta_contact * math.cos(angle))
        
        # 기어 좌표 변환
        M = M_gc(phi_c)
        h = np.array([x_c, y_c, 1.0])
        result = M @ h
        gear_points.append(result[:2])
    except Exception:
        continue

gear_pts = np.array(gear_points) if gear_points else np.array([]).reshape(0, 2)

# --- 시각화 ---
fig, axes = plt.subplots(1, 2, figsize=(14, 7))

# 왼쪽: 커터와 기어 전체 배치
ax1 = axes[0]
theta_full = np.linspace(0, 2*np.pi, 200)
ax1.plot(r_c * np.cos(theta_full), r_c * np.sin(theta_full), 'g--', alpha=0.3)
ax1.plot(r_g * np.cos(theta_full), r_g * np.sin(theta_full), 'b--', alpha=0.3)

# 기어 치형
if len(gear_pts) > 0:
    ax1.plot(gear_pts[:, 0], gear_pts[:, 1], 'b.', markersize=1, label='생성된 기어 치형')

ax1.set_aspect('equal')
ax1.set_title('피니언 커터 창성 — 기어 치형 생성', fontsize=12)
ax1.legend()
ax1.grid(True, alpha=0.3)
ax1.set_xlabel('X [mm]')
ax1.set_ylabel('Y [mm]')

# 오른쪽: 치형 확대
ax2 = axes[1]
if len(gear_pts) > 0:
    radii = np.sqrt(gear_pts[:, 0]**2 + gear_pts[:, 1]**2)
    ax2.plot(gear_pts[:, 0], gear_pts[:, 1], 'b.', markersize=2)
    
    # 기어 각 원
    r_bg = r_g * np.cos(alpha_0)
    r_ag = r_g + m
    r_fg = r_g - 1.25 * m
    for r, name, c in [(r_bg, '기초원', 'b'), (r_g, '피치원', 'g'),
                         (r_ag, '이끝원', 'r'), (r_fg, '이뿌리원', 'm')]:
        ax2.plot(r * np.cos(theta_full), r * np.sin(theta_full), 
                f'{c}--', alpha=0.3, label=name)
    
    ax2.set_xlim(r_fg - 2, r_ag + 2)
    ax2.set_ylim(-10, 10)

ax2.set_aspect('equal')
ax2.set_title('생성된 기어 치형 (확대)', fontsize=12)
ax2.legend(fontsize=8)
ax2.grid(True, alpha=0.3)
ax2.set_xlabel('X [mm]')
ax2.set_ylabel('Y [mm]')

plt.tight_layout()
plt.show()
```

> **결과 해석**: 왼쪽 그래프에서 파란 점들이 창성 운동으로 생성된 기어 치형 좌표입니다. 오른쪽 확대 그래프에서 인볼류트 플랭크가 기초원과 이끝원 사이에 정확히 위치하는 것을 확인할 수 있습니다.

### 9.4.2 이산화 포락선 엔진

범용적인 절삭 시뮬레이션을 위해 **이산화 포락선 엔진**을 사용할 수 있습니다. 이 방식은 해석적 해가 없는 복잡한 공구 형상에도 적용 가능합니다.

알고리즘:
1. 기어 블랭크를 2D 격자(`grid_size x grid_size`)로 표현
2. 공구를 `n_phi` 단계로 회전하면서 각 위치에서 공구 영역을 격자에서 제거
3. 격자의 True/False 경계를 추출하여 치형 좌표 반환
4. 공구 영역 판별에는 **레이 캐스팅(Ray casting)** 알고리즘 사용

> **핵심 정리**
> - 피니언 커터 창성은 $\phi_c$ 스캔 + 맞물림 방정식 풀이로 구현합니다
> - 이산화 포락선 엔진은 모든 공구 유형에 범용적으로 적용 가능합니다
> - 해석적 방법이 있으면 우선 사용하고, 없으면 이산화로 fallback하는 전략이 최적입니다

## 9.5 랙 커터 (Rack Cutter)

> **이 섹션에서 배우는 것**
> - 랙 커터 프로파일의 수학
> - 랙-기어 창성 운동학
> - 전위 가공의 수학적 의미

### 9.5.1 왜 랙 커터가 중요한가

**랙(rack)**은 피치 반지름이 무한대인 기어입니다. 따라서 랙 커터의 치형은 가장 단순합니다 — **직선 플랭크 + 원호 필릿**입니다. 전위(profile shift)의 수학적 의미도 랙 커터를 통해 가장 명확하게 이해할 수 있습니다.

### 9.5.2 랙 커터 프로파일

**플랭크 (2D 좌표)**:

$$\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix}
\pm(h_f - t)\tan\alpha_n \\
h_f - t
\end{pmatrix}, \quad t \in [0, h_a + h_f]$$

**필릿 구간** (이뿌리 전환부):

$$\begin{pmatrix} x_f \\ y_f \end{pmatrix} = \begin{pmatrix}
x_{\text{fillet}} + r_{f0}\sin\theta \\
-h_f + r_{f0}(1 - \cos\theta)
\end{pmatrix}, \quad \theta \in [0, \pi/2 - \alpha_n]$$

여기서 $r_{f0} \approx 0.38m$은 이뿌리 필릿 반경입니다.

### 9.5.3 랙-기어 창성 운동학

랙의 직선 이동과 기어의 회전이 **롤링 조건**을 만족합니다:

$$v_{\text{rack}} = r_0 \cdot \dot{\phi}$$

여기서 $v_{\text{rack}}$은 랙의 이동 속도, $r_0 = mz/2$는 기어 피치원 반경, $\dot{\phi}$는 기어 회전 각속도입니다.

**창성된 기어 치형 좌표** (기어 고정 프레임):

$$\begin{pmatrix} x_g \\ y_g \end{pmatrix} = \begin{pmatrix}
\cos\phi & -\sin\phi \\
\sin\phi & \cos\phi
\end{pmatrix}
\begin{pmatrix}
x_{\text{rack}}(u) - r_0\phi \\
y_{\text{rack}}(u) - r_0
\end{pmatrix}$$

**맞물림 조건**:

$$n_{\text{rack},x} \cdot (x_{\text{rack}} - r_0\phi) + n_{\text{rack},y} \cdot y_{\text{rack}} = 0$$

### 9.5.4 전위 가공의 수학적 의미

전위 계수 $x$를 도입하면, 랙 커터를 $x \cdot m$만큼 외측으로 이동시킵니다. 이것은 기하학적으로 매우 직관적입니다:

- **양의 전위** ($x > 0$): 랙이 기어에서 멀어짐 → 이가 두꺼워짐, 언더컷 방지
- **음의 전위** ($x < 0$): 랙이 기어에 가까워짐 → 이가 얇아짐

**전위 후 이두께** (피치원 위):

$$s = \frac{\pi m}{2} + 2xm\tan\alpha$$

**언더컷 방지를 위한 최소 전위 계수**:

$$x_{\min} = \frac{z_{\min} - z}{z_{\min}}, \quad z_{\min} = \frac{2}{\sin^2\alpha} \approx 17 \quad (\alpha = 20°)$$

예: $z = 10$이면 $x_{\min} \approx (17 - 10)/17 \approx 0.41$

> **시각화**: 랙 커터 창성 운동 과정

```python
"""
[이 코드가 보여주는 것] 랙 커터의 여러 위치에서의 기어 좌표계 내 궤적과 포락선
"""
import numpy as np
import matplotlib.pyplot as plt
import math

# --- 매개변수 설정 ---
m = 3.0               # 모듈 [mm]
z = 20                 # 잇수
alpha_0 = np.radians(20)  # 압력각
r_0 = m * z / 2        # 피치원 반경
r_f = r_0 - 1.25 * m   # 이뿌리원 반경
r_a = r_0 + m          # 이끝원 반경

# --- 랙 프로파일 생성 ---
h_a = m                # 어덴덤
h_f = 1.25 * m         # 디덴덤
n_pts = 30

# 랙 플랭크 좌표 (한쪽)
y_rack = np.linspace(-h_f, h_a, n_pts)
x_rack_right = (h_f - y_rack) * np.tan(alpha_0)  # 우측 플랭크

# --- 여러 phi 위치에서 랙을 기어 좌표계로 변환 ---
fig, ax = plt.subplots(figsize=(10, 10))

# 기어 각 원 표시
theta_full = np.linspace(0, 2*np.pi, 200)
ax.plot(r_0 * np.cos(theta_full), r_0 * np.sin(theta_full), 
        'g--', alpha=0.4, label='피치원')
ax.plot(r_a * np.cos(theta_full), r_a * np.sin(theta_full), 
        'r--', alpha=0.3, label='이끝원')
ax.plot(r_f * np.cos(theta_full), r_f * np.sin(theta_full), 
        'm--', alpha=0.3, label='이뿌리원')

n_positions = 15
phi_range = np.linspace(-0.3, 0.3, n_positions)
colors = plt.cm.Blues(np.linspace(0.3, 0.9, n_positions))

for i, phi in enumerate(phi_range):
    # 랙 좌표 → 글로벌 좌표
    pts_global_x = x_rack_right - r_0 * phi
    pts_global_y = y_rack - r_0
    
    # 기어 회전 역변환
    c, s = np.cos(-phi), np.sin(-phi)
    x_gear = c * pts_global_x - s * pts_global_y
    y_gear = s * pts_global_x + c * pts_global_y
    
    ax.plot(x_gear, y_gear, '-', color=colors[i], alpha=0.5, linewidth=0.8)

ax.set_aspect('equal')
ax.set_title('랙 커터 창성 과정: 여러 위치의 랙 궤적', fontsize=13)
ax.legend(fontsize=10)
ax.grid(True, alpha=0.3)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.set_xlim(r_f - 5, r_a + 5)
ax.set_ylim(-15, 15)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 파란색 선들이 랙 커터의 여러 위치에서의 궤적입니다. 이 궤적들의 포락선이 인볼류트 치형이 됩니다. 각 위치에서 랙의 직선 플랭크가 기어 회전에 의해 변환된 것을 볼 수 있습니다.

> **핵심 정리**
> - 랙 커터는 직선 플랭크 + 원호 필릿의 가장 단순한 구조입니다
> - 롤링 조건: $v_{\text{rack}} = r_0 \cdot \dot{\phi}$
> - 전위 = 랙의 기준선을 $xm$만큼 이동
> - 언더컷 방지 최소 전위: $x_{\min} = (17 - z) / 17$ ($\alpha = 20°$일 때)
