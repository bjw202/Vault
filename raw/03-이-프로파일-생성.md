## 3.1 치형 생성 알고리즘 개요

> **이 섹션에서 배우는 것**
> - 8단계 치형 생성 알고리즘의 전체 흐름을 파악합니다
> - 각 단계의 역할과 입출력을 이해합니다

### 3.1.1 알고리즘의 목표

**왜 중요한가**: 기어를 시뮬레이션하거나 CAD로 모델링하려면, 기어 이(tooth)의 정확한 2D 좌표가 필요합니다. 이 모듈에서는 모듈($m$), 잇수($z$), 압력각($\alpha_0$), 전위 계수($x$)를 입력받아 완전한 치형 윤곽 좌표를 생성하는 알고리즘을 배웁니다.

### 3.1.2 8단계 절차 개관

```
입력: m (모듈), z (잇수), alpha_0 (압력각), x (전위계수)
출력: 하나의 이(tooth) 폐합 윤곽 좌표 배열 (x, y)

Step 1: 기본 파라미터 계산 (r_b, r_0, r_a, r_f)
Step 2: 인볼류트 파라미터 범위 결정 (t_start, t_end)
Step 3: 인볼류트 좌표 생성 (x(t), y(t))
Step 4: 이두께 반각(half tooth angle) 계산
Step 5: 인볼류트 기준 보정 (회전 배치)
Step 6: 이뿌리 필렛 곡선 생성
Step 7: 반대쪽 인볼류트 (대칭 반전)
Step 8: 이뿌리 호 연결 및 폐합
```

각 단계를 하나씩 상세히 살펴보겠습니다.

> **핵심 정리**
> - 입력: 4개 매개변수 ($m, z, \alpha_0, x$)
> - 출력: 폐합 윤곽 좌표 배열
> - 8단계: 파라미터 --> 인볼류트 --> 위치 조정 --> 필렛 --> 대칭 --> 조립

## 3.2 Step 1-3: 인볼류트 곡선 생성

> **이 섹션에서 배우는 것**
> - 기어 치수로부터 인볼류트 파라미터 범위를 결정합니다
> - 인볼류트 플랭크 좌표를 계산합니다

### 3.2.1 Step 1: 기본 파라미터 계산

M02에서 배운 수식을 적용하여 4개 원의 반지름을 계산합니다.

$$
\begin{aligned}
r_b &= \frac{mz\cos(\alpha_0)}{2} & &\text{(기초원 반지름)} \\
r_0 &= \frac{mz}{2} & &\text{(기준원 반지름)} \\
r_a &= \frac{m(z + 2 + 2x)}{2} & &\text{(이끝원 반지름)} \\
r_f &= \frac{m(z - 2.5 + 2x)}{2} & &\text{(이뿌리원 반지름)}
\end{aligned}
$$

### 3.2.2 Step 2: 인볼류트 파라미터 범위 결정

인볼류트 곡선은 기초원($r_b$)에서 시작하여 이끝원($r_a$)까지 뻗어야 합니다.

**시작 파라미터** $t_{start}$:

$$
t_{start} = \begin{cases}
0 & \text{if } r_f \leq r_b \\
\sqrt{\left(\frac{r_f}{r_b}\right)^2 - 1} & \text{if } r_f > r_b
\end{cases}
$$

$r_f \leq r_b$인 경우(대부분의 표준 기어), 인볼류트는 기초원($t = 0$)에서 시작하고, 기초원과 이뿌리원 사이의 공간은 필렛이나 직선으로 채웁니다.

$r_f > r_b$인 경우(잇수가 적고 양전위가 큰 기어), 이뿌리원이 기초원 바깥에 있으므로 인볼류트는 이뿌리원에서 시작합니다.

**끝 파라미터** $t_{tip}$:

$$
t_{tip} = \sqrt{\left(\frac{r_a}{r_b}\right)^2 - 1}
$$

이 값은 이끝원에서의 인볼류트 파라미터입니다. M01에서 배운 역관계식 $t = \sqrt{(r/r_b)^2 - 1}$을 적용한 것입니다.

### 3.2.3 Step 3: 인볼류트 좌표 생성

$t$를 $t_{start}$에서 $t_{tip}$까지 균등하게 분할하여 인볼류트 점을 생성합니다.

$$
\begin{aligned}
x_{inv}(t) &= r_b(\cos t + t\sin t) \\
y_{inv}(t) &= r_b(\sin t - t\cos t)
\end{aligned}
$$

이 단계에서 생성된 좌표는 "기본 위치"의 인볼류트입니다. 아직 기어 이의 올바른 위치에 배치되지 않았습니다.

```python
"""
인볼류트 플랭크 기본 좌표를 생성하는 함수입니다.
"""
import numpy as np
import matplotlib.pyplot as plt
import math

def involute_point(r_b: float, t: float) -> tuple:
    """기초원 반지름 r_b, 파라미터 t에서 인볼류트 좌표를 반환합니다."""
    x = r_b * (math.cos(t) + t * math.sin(t))
    y = r_b * (math.sin(t) - t * math.cos(t))
    return x, y

def involute_function(alpha: float) -> float:
    """inv(alpha) = tan(alpha) - alpha. alpha는 라디안입니다."""
    return math.tan(alpha) - alpha

# --- 예시: m=3, z=20의 인볼류트 범위 ---
m, z = 3, 20
alpha_0 = math.radians(20)
x_shift = 0.0  # 전위 계수

r_b = m * z * math.cos(alpha_0) / 2
r_0 = m * z / 2
r_a = m * (z + 2 + 2*x_shift) / 2
r_f = m * (z - 2.5 + 2*x_shift) / 2

t_start = max(0, math.sqrt(max(0, (max(r_f, r_b)/r_b)**2 - 1)))
t_tip = math.sqrt((r_a/r_b)**2 - 1)

print(f"r_b = {r_b:.2f} mm, r_0 = {r_0:.2f} mm")
print(f"r_a = {r_a:.2f} mm, r_f = {r_f:.2f} mm")
print(f"t_start = {t_start:.4f}, t_tip = {t_tip:.4f}")

# 인볼류트 좌표 생성
N = 50
t_vals = np.linspace(t_start, t_tip, N)
points = np.array([involute_point(r_b, t) for t in t_vals])

# 시각화
fig, ax = plt.subplots(figsize=(8, 8))
ax.plot(points[:, 0], points[:, 1], 'b-', linewidth=2, label='인볼류트 플랭크')

# 각 원 표시
theta_c = np.linspace(-0.2, 0.5, 100)
for r, name, color in [(r_b, '기초원', '#2ecc71'), (r_0, '기준원', '#3498db'),
                         (r_a, '이끝원', '#e74c3c'), (r_f, '이뿌리원', '#9b59b6')]:
    ax.plot(r*np.cos(theta_c), r*np.sin(theta_c), '--', color=color, alpha=0.5, label=name)

ax.set_aspect('equal')
ax.set_title(f'Step 1-3: 인볼류트 플랭크 (m={m}, z={z})', fontsize=13)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.legend(fontsize=10)
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 파란 곡선이 이뿌리 부근에서 이끝까지의 인볼류트 플랭크입니다. 아직 이 위치가 조정되지 않은 "원시" 상태입니다. 기초원(녹색)에서 시작하여 이끝원(빨간색)에서 끝나는 것을 확인할 수 있습니다.

> **핵심 정리**
> - Step 1: 4개 원 반지름 계산 ($r_b, r_0, r_a, r_f$)
> - Step 2: $t_{start} = \max(0, \sqrt{(r_f/r_b)^2 - 1})$, $t_{tip} = \sqrt{(r_a/r_b)^2 - 1}$
> - Step 3: 파라미터 방정식으로 좌표 생성

## 3.3 Step 4-5: 치형 위치 조정

> **이 섹션에서 배우는 것**
> - 이두께 반각(half tooth angle)의 의미와 계산법을 배웁니다
> - 인볼류트를 올바른 위치로 회전 배치하는 방법을 익힙니다

### 3.3.1 Step 4: 이두께 반각 계산

**왜 중요한가**: 기어 이 하나가 기준원 위에서 차지하는 각도 범위의 절반을 **이두께 반각(half tooth angle)**이라 합니다. 이 각도를 정확히 계산해야 이의 두께가 올바르게 설정됩니다.

기준원 위 이두께의 반각 $\theta_s$:

$$
\theta_s = \frac{s_0}{2r_0} = \frac{\pi}{2z} + \frac{x\tan(\alpha_0)}{r_0} \cdot r_0 / r_0
$$

정리하면:

$$
\theta_s = \frac{\pi}{2z} + \frac{2x\tan(\alpha_0)}{2r_0} \cdot \frac{2r_0}{2} / r_0
$$

M02에서 이두께 $s_0 = m(\pi/2 + 2x\tan\alpha_0)$이었으므로:

$$
\theta_s = \frac{s_0}{2r_0} = \frac{m(\pi/2 + 2x\tan\alpha_0)}{mz} = \frac{\pi}{2z} + \frac{2x\tan(\alpha_0)}{z}
$$

### 3.3.2 Step 5: 인볼류트 기준 보정

인볼류트 곡선은 기초원에서 시작할 때 X축 방향을 향합니다. 이를 기어 이의 올바른 위치로 회전시켜야 합니다.

오른쪽 플랭크(right flank)의 **회전 오프셋 각도**:

$$
\theta_{offset} = \theta_s + \text{inv}(\alpha_0) = \frac{\pi}{2z} + \text{inv}(\alpha_0) + \frac{2x\tan(\alpha_0)}{z}
$$

여기서 $\text{inv}(\alpha_0) = \tan(\alpha_0) - \alpha_0$은 기준원에서의 인볼류트 함수값입니다 (M01 참조).

이 각도만큼 인볼류트를 **반시계 방향으로 회전**합니다:

$$
\begin{aligned}
x_R(t) &= x_{inv}(t)\cos(\theta_{offset}) - y_{inv}(t)\sin(\theta_{offset}) \\
y_R(t) &= x_{inv}(t)\sin(\theta_{offset}) + y_{inv}(t)\cos(\theta_{offset})
\end{aligned}
$$

이 변환 후, 오른쪽 플랭크가 기어 이의 올바른 위치에 놓이게 됩니다. 이의 대칭축이 X축(양의 방향)과 일치하게 됩니다.

> **시각화**: 이두께 반각과 회전 보정의 효과를 보여줍니다.

```python
"""
이두께 반각과 치형 위치 관계: 보정 전/후 인볼류트를 비교합니다.
"""
import numpy as np
import matplotlib.pyplot as plt
import math

# --- 매개변수 설정 ---
m, z = 3, 20
alpha_0 = math.radians(20)
x_shift = 0.0

r_b = m * z * math.cos(alpha_0) / 2
r_0 = m * z / 2
r_a = m * (z + 2 + 2*x_shift) / 2
r_f = m * (z - 2.5 + 2*x_shift) / 2

t_start = max(0, math.sqrt(max(0, (max(r_f, r_b)/r_b)**2 - 1)))
t_tip = math.sqrt((r_a/r_b)**2 - 1)

inv_a0 = math.tan(alpha_0) - alpha_0
theta_offset = math.pi/(2*z) + inv_a0 + 2*x_shift*math.tan(alpha_0)/z

# --- 인볼류트 좌표 ---
N = 60
t_vals = np.linspace(t_start, t_tip, N)
x_inv = r_b * (np.cos(t_vals) + t_vals * np.sin(t_vals))
y_inv = r_b * (np.sin(t_vals) - t_vals * np.cos(t_vals))

# 보정 후 (오른쪽 플랭크)
x_R = x_inv * math.cos(theta_offset) - y_inv * math.sin(theta_offset)
y_R = x_inv * math.sin(theta_offset) + y_inv * math.cos(theta_offset)

# 왼쪽 플랭크 (Y축 미러)
x_L = x_R.copy()
y_L = -y_R

# --- 시각화 ---
fig, ax = plt.subplots(figsize=(9, 9))

# 원 그리기
theta_c = np.linspace(-0.3, 0.3, 200)
for r, name, color, ls in [(r_b, '기초원', '#2ecc71', ':'),
                             (r_0, '기준원', '#3498db', '--'),
                             (r_a, '이끝원', '#e74c3c', '-'),
                             (r_f, '이뿌리원', '#9b59b6', '-.')]:
    ax.plot(r*np.cos(theta_c), r*np.sin(theta_c), ls, color=color, alpha=0.5)

# 보정 전 인볼류트 (회색)
ax.plot(x_inv, y_inv, 'gray', linewidth=1.5, alpha=0.4, linestyle='--', label='보정 전')

# 보정 후 양쪽 플랭크
ax.plot(x_R, y_R, 'b-', linewidth=2, label='오른쪽 플랭크')
ax.plot(x_L, y_L, 'r-', linewidth=2, label='왼쪽 플랭크')

# 이두께 반각 표시
angle_arc = np.linspace(-theta_offset + inv_a0, theta_offset - inv_a0, 50)
arc_r = r_0 * 0.95
ax.plot(arc_r*np.cos(angle_arc), arc_r*np.sin(angle_arc), 'k-', linewidth=1.5)
ax.annotate(f'$2\\theta_s$ (이두께각)\n= {2*math.degrees(math.pi/(2*z)):.1f}°',
            xy=(arc_r*0.97, 0), fontsize=10, ha='center')

# X축 (이 대칭축)
ax.plot([0, r_a*1.05], [0, 0], 'k:', alpha=0.3)
ax.annotate('이 대칭축', (r_a*0.9, 1), fontsize=10, color='gray')

ax.set_aspect('equal')
ax.set_title(f'Step 4-5: 이두께 반각과 플랭크 배치 (m={m}, z={z})', fontsize=13)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.legend(fontsize=10)
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 회색 점선이 보정 전 인볼류트, 파란/빨간 실선이 보정 후의 오른쪽/왼쪽 플랭크입니다. 두 플랭크가 X축을 대칭축으로 좌우 대칭을 이루며, 기준원 위에서의 이두께가 정확히 $s_0 = \pi m/2$에 해당하는 각도만큼 벌어져 있습니다.

> **핵심 정리**
> - 이두께 반각: $\theta_s = \pi/(2z) + 2x\tan(\alpha_0)/z$
> - 회전 오프셋: $\theta_{offset} = \pi/(2z) + \text{inv}(\alpha_0) + 2x\tan(\alpha_0)/z$
> - 왼쪽 플랭크: 오른쪽의 Y좌표 부호 반전 $(x_L, y_L) = (x_R, -y_R)$

## 3.4 Step 6: 이뿌리 필렛

> **이 섹션에서 배우는 것**
> - 이뿌리 필렛(root fillet)의 역할을 이해합니다
> - Fetvaci 에피트로코이드 필렛의 원리를 배웁니다
> - 원호 근사 방법과의 차이를 파악합니다

### 3.4.1 필렛의 역할

**왜 중요한가**: 인볼류트 플랭크가 이뿌리원까지 닿지 않거나, 이뿌리 부근에서 날카로운 모서리가 생기면 응력 집중이 발생합니다. 이뿌리 필렛(root fillet)은 이 전환 구간을 매끄러운 곡선으로 연결하여 응력 집중을 완화합니다.

### 3.4.2 Fetvaci 에피트로코이드 필렛 (프로젝트 표준)

실제 기어 제조에서 이뿌리 필렛은 **호브(hob)나 피니언 커터** 같은 절삭 공구의 이끝 코너가 기어 블랭크를 깎아내면서 자연스럽게 생성됩니다. 이 궤적은 수학적으로 **에피트로코이드(epitrochoid)**라는 곡선입니다.

Fetvaci(2010)의 모델에 따르면, 피니언 커터의 이끝 원호 중심 $E$가 그리는 **1차 트로코이드(primary trochoid)**:

$$
\begin{pmatrix} x_T \\ y_T \end{pmatrix} = \begin{pmatrix}
(r_c + r_g)\cos\phi_g - r_c\cos\!\left(\frac{r_c + r_g}{r_c}\phi_c + \phi_c\right) + x_E\cos(\phi_g + \phi_c) - y_E\sin(\phi_g + \phi_c) \\
(r_c + r_g)\sin\phi_g - r_c\sin\!\left(\frac{r_c + r_g}{r_c}\phi_c + \phi_c\right) + x_E\sin(\phi_g + \phi_c) + y_E\cos(\phi_g + \phi_c)
\end{pmatrix}
$$

여기서:
- $r_c$: 커터 피치원 반지름
- $r_g$: 기어 피치원 반지름
- $\phi_c$: 커터 회전각
- $\phi_g = (N_c/N_g)\phi_c$: 기어 회전각 (롤링 구속)
- $(x_E, y_E)$: 커터 이끝 원호 중심의 커터 좌표

**2차 트로코이드(secondary trochoid)** -- 실제 필렛 곡선:

$$
\begin{pmatrix} x_F \\ y_F \end{pmatrix} = \begin{pmatrix} x_T \\ y_T \end{pmatrix} + r_f \cdot \frac{(\dot{y}_T, -\dot{x}_T)}{\sqrt{\dot{x}_T^2 + \dot{y}_T^2}}
$$

여기서 $r_f$는 커터 이끝 필렛 반지름, $(\dot{x}_T, \dot{y}_T)$는 1차 트로코이드의 미분입니다.

에피트로코이드 필렛의 상세한 구현은 --> [M09: 기어 절삭 공구 설계] 에서 다룹니다. 이 모듈에서는 필렛의 개념과 간이 방법을 중점적으로 설명합니다.

### 3.4.3 원호 근사 (간이 방법)

**빠른 모델링이나 시각화 목적**으로는, 이뿌리 필렛을 단순한 원호(circular arc)로 근사할 수 있습니다.

방법:
1. 인볼류트 플랭크의 하단 끝점(기초원 또는 이뿌리원 근방)을 구합니다
2. 이뿌리원 위의 적절한 점을 구합니다
3. 두 점 사이를 원호로 연결합니다
4. 이때 인볼류트와의 접선 연속(tangent continuity) 조건을 만족시키면 더 매끄럽습니다

표준 필렛 반지름: $\rho_f \approx 0.38m$ (표준 호빙 커터 기준)

### 3.4.4 필렛 선택 기준

| 조건 | 추천 방법 |
|------|-----------|
| 정밀 강도 해석 | Fetvaci 에피트로코이드 |
| 빠른 시각화/프로토타이핑 | 원호 근사 |
| CAD 모델링 | Fetvaci (정확한 이뿌리 형상 필요) |
| 교육/학습 | 원호 근사부터 시작, 이후 Fetvaci |

> **시각화**: Fetvaci 필렛과 원호 근사의 차이를 비교합니다.

```python
"""
이뿌리 필렛 비교: 원호 근사 방법을 보여줍니다.
(Fetvaci 에피트로코이드는 M09에서 상세히 다룹니다)
"""
import numpy as np
import matplotlib.pyplot as plt
import math

# --- 매개변수 설정 ---
m, z = 3, 20
alpha_0 = math.radians(20)
x_shift = 0.0

r_b = m * z * math.cos(alpha_0) / 2
r_0 = m * z / 2
r_a = m * (z + 2 + 2*x_shift) / 2
r_f = m * (z - 2.5 + 2*x_shift) / 2

# --- 인볼류트 플랭크 (오른쪽) ---
t_start = 0.0  # r_f < r_b이므로 0
t_tip = math.sqrt((r_a/r_b)**2 - 1)
inv_a0 = math.tan(alpha_0) - alpha_0
theta_offset = math.pi/(2*z) + inv_a0 + 2*x_shift*math.tan(alpha_0)/z

N = 80
t_vals = np.linspace(t_start, t_tip, N)
x_inv = r_b * (np.cos(t_vals) + t_vals * np.sin(t_vals))
y_inv = r_b * (np.sin(t_vals) - t_vals * np.cos(t_vals))

x_R = x_inv * math.cos(theta_offset) - y_inv * math.sin(theta_offset)
y_R = x_inv * math.sin(theta_offset) + y_inv * math.cos(theta_offset)

# --- 원호 근사 필렛 ---
# 인볼류트 하단 끝점
x_bot, y_bot = x_R[0], y_R[0]
angle_bot = math.atan2(y_bot, x_bot)

# 이뿌리원 위의 점 (이 중심선 방향)
# 이 사이의 이뿌리 중심각 계산
tooth_pitch_angle = 2 * math.pi / z
# 인접 이의 왼쪽 플랭크 하단까지의 중간점
angle_mid = 0  # X축 = 이 중심선

# 필렛: 인볼류트 끝점에서 이뿌리원까지 원호로 연결
fillet_angles = np.linspace(angle_bot, -tooth_pitch_angle/2 + angle_bot*0.2, 15)
rho_f = 0.38 * m  # 필렛 반지름

# 간단한 보간: 인볼류트 끝점에서 이뿌리원까지 부드러운 전환
fillet_t = np.linspace(0, 1, 15)
fillet_r = r_b + (r_f - r_b) * fillet_t  # 반지름 보간
fillet_angle_start = angle_bot
fillet_angle_end = angle_bot - 0.05  # 약간 안쪽으로
fillet_angles_interp = fillet_angle_start + (fillet_angle_end - fillet_angle_start) * fillet_t
x_fillet = fillet_r * np.cos(fillet_angles_interp)
y_fillet = fillet_r * np.sin(fillet_angles_interp)

# --- 시각화 ---
fig, ax = plt.subplots(figsize=(8, 8))

# 원 그리기
theta_c = np.linspace(-0.15, 0.25, 200)
for r, name, color in [(r_b, '기초원', '#2ecc71'), (r_f, '이뿌리원', '#9b59b6')]:
    ax.plot(r*np.cos(theta_c), r*np.sin(theta_c), '--', color=color, alpha=0.5, label=name)

# 인볼류트 플랭크
ax.plot(x_R, y_R, 'b-', linewidth=2, label='인볼류트 플랭크')

# 필렛 (원호 근사)
ax.plot(x_fillet, y_fillet, 'r-', linewidth=2, label='원호 근사 필렛')

# 이뿌리원 호
root_arc_angles = np.linspace(fillet_angles_interp[-1], -fillet_angles_interp[-1], 30)
ax.plot(r_f*np.cos(root_arc_angles), r_f*np.sin(root_arc_angles),
        'm-', linewidth=1.5, alpha=0.5, label='이뿌리 호')

# 연결 점 강조
ax.plot(x_bot, y_bot, 'ko', markersize=8, zorder=5)
ax.annotate('인볼류트-필렛\n연결점', (x_bot, y_bot),
            textcoords="offset points", xytext=(-60, -15), fontsize=9,
            arrowprops=dict(arrowstyle='->', color='black', alpha=0.5))

ax.set_aspect('equal')
ax.set_title('이뿌리 필렛: 인볼류트와 이뿌리원 사이의 전환', fontsize=13)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.legend(fontsize=10, loc='upper left')
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 파란 곡선이 인볼류트 플랭크이고, 빨간 곡선이 원호 근사 필렛입니다. 필렛은 인볼류트 하단 끝점(검은 점)에서 시작하여 이뿌리원(보라색)까지 매끄럽게 연결합니다. 실제 Fetvaci 에피트로코이드 필렛은 이보다 약간 다른 형태를 가지며, 강도 해석에서 더 정확한 결과를 제공합니다.

> **핵심 정리**
> - 이뿌리 필렛: 인볼류트와 이뿌리원 사이의 매끄러운 전환 곡선
> - Fetvaci 에피트로코이드: 실제 절삭 공구 궤적 기반 (정밀) --> M09 참조
> - 원호 근사: $\rho_f \approx 0.38m$의 원호로 연결 (간이)

## 3.5 Step 7-8: 대칭 및 완성

> **이 섹션에서 배우는 것**
> - 왼쪽 플랭크를 대칭으로 생성하는 방법을 배웁니다
> - 이뿌리 호로 인접 이를 연결하는 방법을 익힙니다
> - 완전한 단일 이 프로파일을 조립합니다

### 3.5.1 Step 7: 반대쪽 인볼류트

왼쪽 플랭크는 오른쪽 플랭크의 **Y축 반전(미러링)**으로 간단히 생성됩니다.

$$
(x_L, y_L) = (x_R, -y_R)
$$

이때 왼쪽 플랭크의 점 순서를 **역순**으로 배열하면, 전체 윤곽이 연속적인 경로를 이루게 됩니다.

### 3.5.2 Step 8: 이뿌리 호 연결

왼쪽 플랭크 하단과 오른쪽 플랭크 하단 사이의 간격을 **이뿌리원($r_f$) 위의 원호**로 연결합니다. 이 원호는 인접한 이와의 공간(이틈)에서의 이뿌리 바닥을 형성합니다.

### 3.5.3 완전한 단일 이 프로파일 조립

최종 점 순서:

```
왼쪽 플랭크 (이끝 → 이뿌리) 
  → 이뿌리 호/필렛 
    → 오른쪽 플랭크 (이뿌리 → 이끝) 
      → 이끝 호 (폐합)
```

> **시각화**: 완성된 단일 이 프로파일을 보여줍니다.

```python
"""
완성된 단일 이 프로파일: 인볼류트 + 필렛 + 이뿌리 호 + 이끝 호를 모두 조립합니다.
"""
import numpy as np
import matplotlib.pyplot as plt
import math

# --- 매개변수 설정 ---
m, z = 3, 20
alpha_0 = math.radians(20)
x_shift = 0.0

r_b = m * z * math.cos(alpha_0) / 2
r_0 = m * z / 2
r_a = m * (z + 2 + 2*x_shift) / 2
r_f = m * (z - 2.5 + 2*x_shift) / 2

# --- 인볼류트 계산 ---
t_start = max(0, math.sqrt(max(0, (max(r_f, r_b)/r_b)**2 - 1)))
t_tip = math.sqrt((r_a/r_b)**2 - 1)
inv_a0 = math.tan(alpha_0) - alpha_0
theta_offset = math.pi/(2*z) + inv_a0 + 2*x_shift*math.tan(alpha_0)/z

N = 60
t_vals = np.linspace(t_start, t_tip, N)
x_inv = r_b * (np.cos(t_vals) + t_vals * np.sin(t_vals))
y_inv = r_b * (np.sin(t_vals) - t_vals * np.cos(t_vals))

# 오른쪽 플랭크
x_R = x_inv * math.cos(theta_offset) - y_inv * math.sin(theta_offset)
y_R = x_inv * math.sin(theta_offset) + y_inv * math.cos(theta_offset)

# 왼쪽 플랭크 (Y 반전, 역순)
x_L = x_R[::-1]
y_L = -y_R[::-1]

# 이끝 호 (오른쪽 플랭크 끝 → 왼쪽 플랭크 끝)
angle_tip_R = math.atan2(y_R[-1], x_R[-1])
angle_tip_L = math.atan2(y_L[0], x_L[0])
tip_angles = np.linspace(angle_tip_R, angle_tip_L, 15)
x_tip = r_a * np.cos(tip_angles)
y_tip = r_a * np.sin(tip_angles)

# 이뿌리 호 (왼쪽 플랭크 하단 → 인접 이까지 확장)
# 현재 이의 왼쪽 하단과 인접 이(이전 이)의 오른쪽 하단 사이
angle_root_L = math.atan2(y_L[-1], x_L[-1])
angle_root_R = math.atan2(y_R[0], x_R[0])
# 인접 이의 오른쪽 플랭크 하단 각도
tooth_pitch = 2 * math.pi / z
angle_adj_root = angle_root_L - (tooth_pitch - (angle_root_R - angle_root_L))
root_angles = np.linspace(angle_root_L, angle_root_L - 0.08, 10)
x_root_L = r_f * np.cos(root_angles)
y_root_L = r_f * np.sin(root_angles)

root_angles2 = np.linspace(angle_root_R + 0.08, angle_root_R, 10)
x_root_R = r_f * np.cos(root_angles2)
y_root_R = r_f * np.sin(root_angles2)

# --- 시각화 ---
fig, ax = plt.subplots(figsize=(9, 9))

# 각 원 (부분만)
theta_c = np.linspace(-0.2, 0.2, 200)
for r, name, color, ls in [(r_b, '기초원', '#2ecc71', ':'),
                             (r_0, '기준원', '#3498db', '--'),
                             (r_a, '이끝원', '#e74c3c', '-'),
                             (r_f, '이뿌리원', '#9b59b6', '-.')]:
    ax.plot(r*np.cos(theta_c), r*np.sin(theta_c), ls, color=color, alpha=0.4)

# 치형 각 구간을 색상 구분하여 표시
ax.plot(x_R, y_R, 'b-', linewidth=2.5, label='오른쪽 인볼류트')
ax.plot(x_L, y_L, 'r-', linewidth=2.5, label='왼쪽 인볼류트')
ax.plot(x_tip, y_tip, 'g-', linewidth=2, label='이끝 호')
ax.plot(x_root_L, y_root_L, 'm-', linewidth=2, label='이뿌리 호 (좌)')
ax.plot(x_root_R, y_root_R, 'm--', linewidth=2, label='이뿌리 호 (우)')

# 필렛 연결선 (간이)
ax.plot([x_L[-1], x_root_L[0]], [y_L[-1], y_root_L[0]], 'c-', linewidth=1.5, alpha=0.7, label='필렛 연결')
ax.plot([x_root_R[-1], x_R[0]], [y_root_R[-1], y_R[0]], 'c-', linewidth=1.5, alpha=0.7)

ax.set_aspect('equal')
ax.set_title(f'완성된 단일 이 프로파일 (m={m}, z={z})', fontsize=14)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.legend(fontsize=9, loc='upper left')
ax.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 파란 곡선(오른쪽 인볼류트), 빨간 곡선(왼쪽 인볼류트), 녹색 호(이끝), 보라 호(이뿌리), 청록 연결선(필렛)이 하나의 완전한 이 프로파일을 형성합니다. 실제 구현에서는 필렛을 에피트로코이드나 원호 근사로 매끄럽게 처리합니다.

> **핵심 정리**
> - 왼쪽 플랭크 = 오른쪽 플랭크의 Y축 미러: $(x_L, y_L) = (x_R, -y_R)$
> - 이끝 호: 두 플랭크 상단을 $r_a$ 위의 원호로 연결
> - 이뿌리 호: 두 플랭크 하단을 $r_f$ 위의 원호로 연결

## 3.6 전체 기어 프로파일

> **이 섹션에서 배우는 것**
> - 단일 이를 원형 배열하여 전체 기어를 생성하는 방법을 배웁니다

### 3.6.1 원형 배열

단일 이의 좌표를 각도 피치 $\Delta\theta = 2\pi/z$만큼 회전하여 $z$개 이를 배치합니다.

$$
\begin{aligned}
x_k &= x\cos(k\Delta\theta) - y\sin(k\Delta\theta) \\
y_k &= x\sin(k\Delta\theta) + y\cos(k\Delta\theta)
\end{aligned}
$$

여기서 $k = 0, 1, \ldots, z-1$

**구현 주의**: 각도를 누적하지 말고, 인덱스 $k$에서 직접 $k \cdot 2\pi/z$를 계산해야 부동소수점 오차가 누적되지 않습니다.

> **시각화**: 완성된 전체 기어 프로파일입니다.

```python
"""
완성된 전체 기어 2D 프로파일 (z=20)을 생성합니다.
"""
import numpy as np
import matplotlib.pyplot as plt
import math

# --- tooth_profile 함수 ---
def tooth_profile(m, z, alpha0_deg=20.0, x=0.0, n_pts=40):
    """단일 이의 양쪽 인볼류트 플랭크 + 이끝 호 + 이뿌리 호 좌표를 반환합니다."""
    alpha0 = math.radians(alpha0_deg)
    r0 = m * z / 2
    rb = r0 * math.cos(alpha0)
    ra = m * (z + 2 + 2*x) / 2
    rf = m * (z - 2.5 + 2*x) / 2

    t_start = max(0, math.sqrt(max(0, (max(rf, rb)/rb)**2 - 1)))
    t_tip = math.sqrt((ra/rb)**2 - 1)
    inv_a0 = math.tan(alpha0) - alpha0
    theta_off = math.pi/(2*z) + inv_a0 + 2*x*math.tan(alpha0)/z

    # 오른쪽 플랭크
    t = np.linspace(t_start, t_tip, n_pts)
    xi = rb * (np.cos(t) + t * np.sin(t))
    yi = rb * (np.sin(t) - t * np.cos(t))
    xr = xi * math.cos(theta_off) - yi * math.sin(theta_off)
    yr = xi * math.sin(theta_off) + yi * math.cos(theta_off)

    # 왼쪽 플랭크 (역순)
    xl = xr[::-1]
    yl = -yr[::-1]

    # 이끝 호
    a_tip_r = math.atan2(yr[-1], xr[-1])
    a_tip_l = math.atan2(yl[0], xl[0])
    tip_a = np.linspace(a_tip_r, a_tip_l, 8)
    x_tip = ra * np.cos(tip_a)
    y_tip = ra * np.sin(tip_a)

    # 이뿌리 호 (현재 이의 왼쪽 하단부터 다음 이의 오른쪽 하단 방향)
    a_root_l = math.atan2(yl[-1], xl[-1])
    a_root_r = math.atan2(yr[0], xr[0])
    # 이전 이의 오른쪽 플랭크 하단까지
    tooth_pitch = 2 * math.pi / z
    a_root_prev = a_root_l - (tooth_pitch - (a_root_r - a_root_l)) * 0.5
    root_a = np.linspace(a_root_l, a_root_l - 0.03, 5)
    x_root = rf * np.cos(root_a)
    y_root = rf * np.sin(root_a)

    # 조립: 왼쪽 플랭크 → 이뿌리 → 오른쪽 플랭크 → 이끝 호
    all_x = np.concatenate([xl, x_root, [xr[0]], xr, x_tip])
    all_y = np.concatenate([yl, y_root, [yr[0]], yr, y_tip])
    return np.column_stack([all_x, all_y])

def gear_profile(m, z, alpha0_deg=20.0, x=0.0, n_pts=40):
    """z개 이를 원형 배열하여 전체 기어 좌표를 반환합니다."""
    single = tooth_profile(m, z, alpha0_deg, x, n_pts)
    all_teeth = []
    for k in range(z):
        angle = k * 2 * math.pi / z
        c, s = math.cos(angle), math.sin(angle)
        rotated = np.column_stack([
            single[:, 0] * c - single[:, 1] * s,
            single[:, 0] * s + single[:, 1] * c
        ])
        all_teeth.append(rotated)
    return all_teeth

# --- 시각화 ---
m, z = 3, 20
teeth = gear_profile(m, z, alpha0_deg=20.0, x=0.0, n_pts=50)

fig, ax = plt.subplots(figsize=(10, 10))

for tooth in teeth:
    ax.plot(tooth[:, 0], tooth[:, 1], 'b-', linewidth=0.8)

# 주요 원 그리기
r_0 = m * z / 2
r_a = m * (z + 2) / 2
r_f = m * (z - 2.5) / 2
r_b = r_0 * math.cos(math.radians(20))
theta_c = np.linspace(0, 2*np.pi, 360)

for r, name, color, ls in [(r_a, '이끝원', '#e74c3c', '-'),
                             (r_0, '기준원', '#3498db', '--'),
                             (r_b, '기초원', '#2ecc71', ':'),
                             (r_f, '이뿌리원', '#9b59b6', '-.')]:
    ax.plot(r*np.cos(theta_c), r*np.sin(theta_c), ls, color=color, alpha=0.3, linewidth=1)

ax.set_aspect('equal')
ax.set_title(f'전체 기어 2D 프로파일 (m={m}, z={z})', fontsize=14)
ax.set_xlabel('X [mm]')
ax.set_ylabel('Y [mm]')
ax.grid(True, alpha=0.2)
plt.tight_layout()
plt.show()
```

> **결과 해석**: 20개의 이가 원형으로 배열된 완전한 기어 프로파일입니다. 각 이의 인볼류트 플랭크, 이끝, 이뿌리가 모두 표현되어 있습니다. 이 좌표를 바탕으로 3D 모델링(Z축 압출), SVG 렌더링, CAD 출력 등을 수행할 수 있습니다.

> **핵심 정리**
> - 원형 배열: $k$번째 이의 좌표 = 단일 이를 $k \cdot 2\pi/z$ 회전
> - 각도를 누적하지 않고 인덱스에서 직접 계산하여 오차 방지
> - 전체 기어 = $z$개 단일 이의 조립

---

## 핵심 수식 정리

| 수식 | 이름 | 단계 |
|------|------|------|
| $r_b = mz\cos(\alpha_0)/2$ | 기초원 반지름 | Step 1 |
| $t_{tip} = \sqrt{(r_a/r_b)^2 - 1}$ | 이끝 인볼류트 파라미터 | Step 2 |
| $x(t) = r_b(\cos t + t\sin t)$ | 인볼류트 X좌표 | Step 3 |
| $\theta_{offset} = \pi/(2z) + \text{inv}(\alpha_0) + 2x\tan(\alpha_0)/z$ | 회전 오프셋 | Step 4-5 |
| $(x_L, y_L) = (x_R, -y_R)$ | 왼쪽 플랭크 대칭 | Step 7 |
| $(x_k, y_k) = R(k \cdot 2\pi/z) \cdot (x, y)$ | 원형 배열 | 전체 조립 |
