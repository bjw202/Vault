# Query

wiki/에서 관련 지식을 수집하고, 질문에 답한다.

## 실행 절차

### 1. 인덱스 읽기

`wiki/index.md`를 읽는다. 질문과 관련된 페이지를 **모두** 식별한다.
관련성 판단 기준: 페이지 제목, 설명 텍스트, 소속 섹션(Sources/Concepts/Syntheses).

### 2. 초기 페이지 읽기

Step 1에서 식별한 페이지를 모두 읽는다.
읽은 페이지를 `방문 목록`에 기록한다.

### 3. 링크 추출 및 재귀 탐색

읽은 각 페이지 본문에서 `[[wiki links]]`를 추출한다.
추출한 링크 중:
- `방문 목록`에 이미 있는 페이지 → 스킵
- `방문 목록`에 없는 페이지 → 읽고 `방문 목록`에 추가

이 과정을 **1회 더 반복**한다 (최대 깊이 2).

### 4. 페이지 수 제한

`방문 목록`이 **15개를 초과**하면, 질문과의 관련도가 낮은 페이지부터 제외하여 15개 이하로 줄인다.

### 5. 답변 작성

수집한 페이지들의 내용을 종합하여 질문에 답한다.

답변 규칙:
1. 근거가 되는 페이지를 `[[wiki links]]`로 인용한다.
2. wiki에 근거가 있는 내용과 LLM 추론을 구분한다.
3. 모순되는 정보가 있으면 양쪽 모두 제시한다.

### 6. Synthesis 제안 (선택)

답변이 여러 source/concept를 통합한 분석이면, 사용자에게 synthesis 페이지로 저장할지 묻는다.
사용자가 동의하면 `wiki/syntheses/`에 저장하고 `wiki/index.md`를 갱신한다.
