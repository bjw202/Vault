## 4. 성능 지뢰: compile 스케일링 문제

`CLAUDE.md:224-238`의 compile workflow는:

```md
1. Read `_compile_log.md`.
2. Scan `raw/`.
3. Identify: new files / changed files
4. For each relevant source:
   - create or update wiki/sources/
   - connect to existing concepts
   - create new concept pages
   - update synthesis pages
   - update .system/ indexes
   - append to _compile_log.md
```

raw 파일 N개에 대해 **매 파일마다 전체 concept 목록을 스캔**해서 중복 확인해야 한다. 이건 O(N × C) where C = concept 수. concept 인덱스에 구조화된 lookup이 없으므로, 50개 raw 파일 × 30개 concept이면 1,500번 파일 읽기가 필요하다.
